  - Fullscreen should be an optional Player Mode focus state, not the default entry and not a simple canvas maximize.

  - Default three-column command table remains better for first-time comprehension, target scanning, command discovery, and diagnostics reachability.
  - Immersive mode is for actual play: the world becomes the first subject, while command and diagnostics stay one step away.
- Proposed layout model:
  - Main: pixel-world canvas fills the viewport / focus container.
  - Top narrow HUD: world/stage identity, Objective, Next Move, Blocker state.
  - Bottom or lower-right overlay: Action Receipt / current execution feedback.
  - Left lightweight target rail: active agent, selected target, key route; not the full targets panel.
  - Right command drawer: collapsed by default; opens command, chat, and target details.
  - Separate diagnostics drawer: collapsed by default; renderer/runtime/raw DTO/test controls do not mix with player command drawer.
- Always visible in focus mode:
  - Objective.
  - Next Move or primary command hint.
  - Blocker or no-blocker state.
  - Latest Action Receipt / no-receipt state.
  - Active agent / selected target marker.
  - Key route, hotspot, or blocker highlight.
  - Stable controls for exit focus mode, open command drawer, open diagnostics.
- Move behind drawer / overlay:
  - Full target list.
  - Command/chat detail.
  - Long recent event list.
  - Renderer status, raw DTO, provider/auth/governance metadata.
  - Camera/debug/test controls.
- Data-honesty items that must not disappear:
  - Fallback/degraded renderer label.
  - Derived position/source label.
  - Disabled command reason.
  - No-receipt state.

  2. HUD/overlay slice: adapt objective, next action, blocker, and receipt into focus-mode overlays using current data sources.
  3. Drawer slice: command drawer, diagnostics drawer, target rail, with keyboard and mobile open/close behavior.
  4. Browser evidence slice: desktop/mobile/fallback/action-receipt screenshots plus overflow/focus checks.

  - No-receipt state: ambient activity is not presented as player progress.
  - Fallback renderer state: degraded reason remains visible and world summary/relationships remain usable.
  - Diagnostics collapsed by default: available but visually below world/command.
