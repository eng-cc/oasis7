# 小红书关键词策略 (Keyword Strategy)

本文提供编辑启发式，不是平台官方搜索权重或效果保证。词长、标签数和出现频率仅供起草时参考；实际搜索量、竞争、转化与推荐结果需要相应数据，未验证时标为未知。

## 关键词类型

### 1. 核心关键词 (Core Keywords)
描述主题的主要词汇；实际流量和竞争程度需数据验证

**特征**:
- 1-3个字
- 搜索量待数据验证
- 竞争程度待数据验证

**示例**: 护肤、穿搭、减肥、美妆、旅游

### 2. 长尾关键词 (Long-tail Keywords)
更具体的搜索词；是否低竞争或高转化需数据验证

**特征**:
- 4-10个字
- 搜索量待数据验证
- 用户意图明确
- 转化率待数据验证

**示例**: 
- 核心词"护肤" → 长尾词"油皮夏天护肤步骤"
- 核心词"穿搭" → 长尾词"小个子梨形身材穿搭"

### 3. 场景关键词 (Scenario Keywords)
描述使用场景的词汇

**示例**: 约会、通勤、旅游、居家、上班

### 4. 人群关键词 (Audience Keywords)
描述目标人群的词汇

**示例**: 学生党、上班族、宝妈、新手、敏感肌

### 5. 修饰关键词 (Modifier Keywords)
增加描述的词汇

**示例**: 平价、大牌、小众、百元、高性价比

## 关键词布局策略

### 人工检查顺序（非平台权重）

```
1. 标题：主题是否清楚
2. 首段：是否交代读者需要的信息
3. 正文小标题：是否便于浏览
4. 正文内容：是否自然、准确
5. 标签：是否与内容相关
6. 图片文字：是否与正文一致且易读
```

### 布局草案（按内容调整）

```
标题: [核心关键词] + [修饰词] + [吸引词]
      例: "油皮护肤｜平价好用的夏日护肤清单"

首段: 包含核心关键词 + 1-2个长尾关键词
      例: "作为一个油皮，夏天护肤真的太难了，
          出油、毛孔、闷痘...今天分享我的油皮夏日护肤心得"

正文: 每200字自然出现1次关键词变体
      例: "这款控油精华"、"适合油皮的XX"

标签: 5-10个，覆盖不同类型关键词
      例: #油皮护肤 #夏日护肤 #控油 #平价护肤 #学生党护肤
```

## 标签策略

### 标签数量
- 可先尝试 5-10 个相关标签，再按内容删减；不是平台最佳值或最低要求。
- 实际数量限制以发布界面和适用官方规则为准，不从本文推断。

### 标签组合公式

```
2-3个 核心词标签: #护肤 #美妆
2-3个 长尾词标签: #油皮护肤 #夏日护肤推荐  
1-2个 场景词标签: #通勤妆容 #约会穿搭
1-2个 人群词标签: #学生党 #新手化妆
1-2个 热门话题标签: #好物分享 #我的日常
```

### 标签注意事项

✅ **正确做法**:
- 标签与内容高度相关
- 混合大词和小词
- 使用平台热门话题标签

❌ **错误做法**:
- 堆砌不相关热门标签
- 只用大词不用长尾词
- 标签与内容不符（影响推荐精准度）

## 关键词密度

### 字符占比参考
以下区间仅用于人工编辑时检查重复，不是已验证的平台最优值或推荐门槛。
- **核心关键词**: 可用 2-3% 字符占比作为检查起点，不等于每100字出现2-3次
- **长尾关键词**: 每个出现1-2次即可

### 检查方法
```
关键词字符占比 = (关键词非重叠出现次数 × 关键词字符数) ÷ 正文字符数 × 100%
```

按同一正文范围计数：不含标题、标签和空白，中文、字母、数字、标点均按字符计，不按分词结果计。例：100字符正文中，两字词“护肤”出现3次，占比为 3×2÷100=6%；出现1次才是2%。

### 重复检查提示（非平台判定）

| 密度 | 问题 | 解决方案 |
|------|------|----------|
| <1% | 检查主题是否表达清楚 | 必要时自然补充，不为比例堆词 |
| 2-3% | 可作人工检查起点 | 仍需核对语义和可读性 |
| >5% | 留意重复是否影响阅读 | 按上下文删减，不机械替换 |

## 关键词挖掘方法

### 1. 小红书搜索框
- 输入核心词，查看下拉推荐词
- 这些可作为选词线索，不能据此断言真实搜索量或用户意图分布

### 2. 相关笔记分析
- 查看同类爆款笔记使用的关键词和标签
- 分析评论区用户使用的词汇

### 3. 关键词组合矩阵

```
核心词 × 人群词 = 长尾词
护肤 × 油皮 = 油皮护肤
护肤 × 学生党 = 学生党护肤
护肤 × 敏感肌 = 敏感肌护肤

核心词 × 场景词 = 长尾词
穿搭 × 通勤 = 通勤穿搭
穿搭 × 约会 = 约会穿搭

核心词 × 修饰词 = 长尾词
护肤 × 平价 = 平价护肤
护肤 × 大牌 = 大牌护肤
```
