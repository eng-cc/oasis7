## Pages

1. Cover
   - Main title: `AI会带来经济繁荣，还是萧条？`
   - Subtitle: `到2035年，更可能是“先分化，后扩散”`
   - Key framing: `不是单边繁荣，也不是机械复制大萧条`

2. Core judgment
   - Main judgment: `不是单边繁荣，也不是1929重演`
   - Key framing: `中间路径：先分化，后扩散，强烈依赖政策与制度设计`

3. Adoption
   - Main judgment: `采用很快，但宏观扩散仍不充分`
   - Data:
     - OECD企业AI使用率：2023 8.7% -> 2025 20.2%
     - 美国企业使用AI：17%—20%
     - 欧盟大型企业：55.03%
     - 中国生成式AI用户：6.02亿

4. Productivity
   - Main judgment: `生产率确实上来了，但主要仍是局部增益`
   - Data:
     - 客服场景：首月+14%，三个月后约+25%
     - 写作/咨询/管理任务：约25%—40%
     - 总体劳动生产率潜在提升：约1.1%—1.2%
     - 2035前宏观额外贡献：约0.2—0.6个百分点/年

5. Jobs and Distribution
   - Main judgment: `总量未崩，结构先变`
   - Data:
     - AI影响全球近40%就业，先进经济体约60%
     - 高自动化潜力职业岗位发布下降17%
     - 高增强潜力职业岗位发布上升22%
     - 22—25岁高AI暴露职业就业相对下降16%

6. Scenario Table
   - Main judgment: `基准情景不是单边繁荣，而是技术红利与分配摩擦并存`
   - Data:
     - 乐观：25%—35%，全球3.2%—3.8%，中国4.5%—5.2%
     - 中性：45%—55%，全球2.6%—3.2%，中国3.8%—4.6%
     - 悲观：15%—25%，全球1.8%—2.5%，中国2.8%—3.8%

7. Distribution Mechanism
   - Main judgment: `真正的分水岭是分配机制`
   - Cards:
     - 培训与转岗
     - 收入传导
     - 竞争政策
     - 社保与公共服务

8. Conclusion
   - Main judgment: `问题不只是AI会不会更强，而是收益由谁拿走`
   - Conditions:
     - 培训与转岗是否跟上
     - 社保与收入传导是否托住需求
     - 竞争政策是否防止红利过度集中
