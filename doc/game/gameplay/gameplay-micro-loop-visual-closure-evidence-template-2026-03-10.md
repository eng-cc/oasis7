# Gameplay 微循环视觉收口证据模板（2026-03-10）

## 目的
- 为 `TASK-GAME-018` / `TASK-GAMEPLAY-MLF-008` 提供统一的视觉收口证据包格式。
- 将 `MLF-005/006/007/008` 的截图、录屏、控制台状态与结论收敛到一份可直接进入发布评审的模板中。
- 证明视觉反馈对应一条真实可执行、可观察且能驱动下一步行动的玩法微循环，避免仅凭画面改善判定玩法收口。

## 使用说明
- 每轮视觉优化完成后复制本模板并回填真实路径。
- 证据包至少包含：baseline、改动后截图、必要时录屏、结论摘要。
- 若总结论为 `pass`，至少回填 1 条有真实 runtime 证据的端到端玩法循环；不能只以截图或视觉评估代替玩家动作与状态变化证据。
- `失败 / 恢复` 仅在该动作不存在失败分支时可填 `N/A`，并在同一单元格说明理由。
- 若 `MLF-007` 未完成，证据包结论不得标记为“世界可读性已收口”。
