Understand a decision before installing

A clearer role, an honest example, and a choice to keep reading.

Development note · 14 October 2026 · Site design baseline b216610f

A first visit should answer what you do, what an agent decides, and what the evidence can actually show.

The problem

Starting with technical logs asks visitors to learn the tools before understanding the game. An accepted action can also be mistaken for a completed result.

The change

The homepage introduces goals and boundaries, then walks through a single illustrative choice: keep production moving without exhausting energy. Goal, response, consequence and next choice are separate reading steps.

What this means for you

You can understand the example, inspect the preview requirements or keep reading without installing or creating an account. No reading action calls a model or changes a world.

What remains

The example has no runtime receipt and makes no claim about a live world. There are no publicly verified runtime records in this collection yet. Installation still requires local setup and a model provider; the game remains a limited playable technical preview. This article describes the static page, not a new gameplay capability or a deployment result.
