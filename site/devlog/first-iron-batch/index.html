第一炉铁锭：从权限拒绝到真实产出

发布于 2026-10-15

第一次尝试被拒后，Agent 调整方案并完成首批铁锭；世界记录让结果可以核对。

目标明确，起点也有边界

这次目标是在 starter-site 建一座冶炼炉，用起始库存完成首批 3 个铁锭，并核对工业里程碑。世界和已认领的 Agent 已提前准备好；测试不是从下载安装、创建身份开始。

Agent 先读取任务、自己能做的事与工厂状态，再提交具体行动。下面整理的是公开报告中的实际顺序，不是逐字对话，也不是任意环境都能照做的教程。

第一次报价被拒：先查权限，再继续

第一次选择的工厂不在授权范围，报价被拒绝，没有产生建造动作。随后查询原操作时，也没有找到该动作记录。这时没有一个已完成的建造可以拿来当结果。

Agent 再读工业信息，核对实际授权后，改用允许的冶炼炉。建造进入世界后，另一次独立查询也找到了相同的操作回执；后续观察才确认工厂已经建成。

建成之后，还要把原料送到生产地点

建炉不是首批产物的结束标志。下一次行动准备因状态冲突被拒绝。Agent 重新读取可用状态，保留这次拒绝记录后继续；它没有把拒绝当成功。

接下来，两次实际转运把 8 份铁矿石、2 份燃料从 Agent 送到 starter-site，再为允许的冶炼炉排入一批铁锭配方。世界事件记录了建造从 tick 27 到 28、配方从 tick 45 到 46 的开始与完成。

把投入、产出和余量对上

  • 建造投入：12 份结构框架、4 份热力线圈、6 份耐火砖，以及 6 电。
  • 本批生产投入：4 份铁矿石、1 份燃料，以及 8 电。
  • 本批实际产出：3 个铁锭、1 份炉渣，进入地点库存。
  • 结束时读回：地点剩余 4 份铁矿石、1 份燃料，另有上述产物；Agent 材料库存为空，电量为 86，待执行建造和配方任务均为 0。

独立核对世界事件与库存后，确认首批产出和工业里程碑在 tick 46 一起结算。完成的依据是产物和账本已经改变，而不只是请求被受理。具体调用数和核验方法见下方详情。

这一炉之后，哪些事还没有证明

该测试在首批产出后结束，没有继续验证稳定生产、扩厂或协作。剩余原料确实存在，但不等于下一批已经排产，也不代表扩展路线已经开放。

这段经历展示了目标、权限、尝试和实际结果如何分别核对。它只证明 2026-10-13 这次预置环境的受控 CLI 过程；GUI、从零接入、推荐安装包和公共部署仍不在这次验收范围内。
