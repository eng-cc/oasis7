# 互联网打工人苦难与梗备用素材库 v0.1

调研日期：2026-05-30

适用范围：第一卷及后续章节的互联网行业共同记忆、轻梗、反差性暖心素材。本文只作为素材库，不直接改变 canon。

## 调研问题

1. 当下“互联网打工人苦难”主要被哪些真实案例、制度压力和网络梗承载。
2. 哪些梗能让年轻读者会心，哪些会把正文写成职场吐槽或苦难消费。
3. 如何把旧互联网行业痛点转译成《绿洲 2076》里的温柔反转：不催、不吓、不排名、不追责、不把人当耗材。

## 使用边界

- 这些素材只用于理解现实情绪，不直接复刻到正文。
- 正文不写成 AI 反叛、公司阴谋、老人苦难、资源竞技、赛博黑暗风。
- 极端事故只作为“为什么绿洲必须保护休息和边界”的背景，不改写成角色悲剧。
- 热词优先转成物件、流程和一句人话，不让“班味、牛马、PIP、福报、996”等词成为作品口吻。

## 发现

### 1. 996 / 007 / 大小周：核心痛点是“时间被吞掉”

`996.ICU` 把“工作制”和健康风险捆在一起，成为互联网行业最强的反加班符号之一。人社部和最高法的超时加班典型案例也说明，社会已经把超时加班作为劳动权益议题讨论，而不只是年轻人抱怨。

大小周材料更复杂：取消大小周被视为休息权回归，但不少员工也担心收入下降。这说明苦难并不只是“工作太多”，还包括“休息权被收入结构绑架”。

对《绿洲》的备用转译：

- 不写“996”本词，写“维护窗口到点关闭”。
- 不写“奋斗到凌晨”，写“Agent 拒绝高耗方案，理由是保护下一次维修”。
- 不写“多干多得”，写“休息不扣位置，退出后仍保留队列”。

### 2. 极端过劳事件：只能做边界警示，不能做剧情消费

拼多多员工猝死、字节员工离世等报道曾让互联网加班文化被重新讨论。这类事件情绪强烈，但放进《绿洲》会破坏当前基调，容易滑向苦难叙事或公司阴谋。

对《绿洲》的备用转译：

- 只保留“为什么绿洲不能鼓励透支”的制度反面。
- 可转成设备和公共规则：低功耗提示、强制休息窗口、维护窗口不许跳过、夜间只开放旁听。
- 不把任何老人写成“被大厂伤害过所以来绿洲疗伤”的苦难模板。

### 3. 35岁危机 / 中年危机：最适合反转成“旧经验仍有位置”

央视网和界面新闻都讨论过互联网行业年龄焦虑。现实语境中，35岁常被当作职业分水岭，背后是高薪资、高淘汰、组织年轻化和技能更新焦虑。

《绿洲》的设定天然具有反差：主角群不是 35+，而是 80+。他们不再被问“还值不值”，而是在绿洲用旧经验重新参与生产和生活。

对《绿洲》的备用转译：

- “年龄红线”反转为“旧经验标签”。
- 不说“老员工价值”，写具体动作：老前端调入口提示，老运维保留回滚路线，老产品写“不修什么”，老运营删掉自我介绍。
- 可用短句：`这次不按年龄清队列。`

### 4. 裁员 / 毕业 / 优化 / 降本增效：痛点是“坏消息被包装成好词”

裁员报道中常见“优化名额”“协商离职”“PIP”等中性或管理化词汇。PIP 原本是绩效改进计划，但在许多打工人语境中，它会被理解为裁员前奏。这里的创伤不是某个词本身，而是人被流程和话术处理掉。

对《绿洲》的备用转译：

- 不用“优化、毕业、淘汰”等词处理人。
- 失败件不叫报废，等待不叫延期，拒绝不叫权限不足。
- 公共账本只写“等待理由”和“下一次回应时间”，不写“低绩效者”。

### 5. KPI / OKR / 周报日报 / 埋点：痛点是“人被量化成指标”

互联网工作流里，指标原本用于对齐目标和发现问题，但在打工人语境中，常被体验为压力、排名和表演。第一章 v0.8 的“今天先不数人”正是这个方向的轻反转。

对《绿洲》的备用转译：

- 可用“统计折到第二层”“不显示贡献排名”“只显示下一次时间”。
- 不写“今日活跃人数”，写“今天谁能安全退出”。
- 不写增长术语，写“有没有人以为自己掉线了”。

### 6. 需求变更 / 背锅 / 甩锅 / 线上事故：痛点是“模糊需求被转嫁成个人责任”

产品经理、程序员、运营、测试之间的相互吐槽，本质常来自需求不清、临时变更、上线压力和事故追责。梗图和社区文章里反复出现“需求变了”“让开发背锅”“线上出事谁负责”等情境。

对《绿洲》的备用转译：

- 需求卡先写“不修什么”，避免承诺过满。
- 事故复盘先保留事实，不追“谁慢了半拍”。
- 回滚不是失败，是给下一次留路。
- 可用短句：`这次不找背锅人，先找撤回点。`

### 7. 打工人 / 牛马 / 班味 / 去班味：痛点是“自嘲背后的倦怠”

“打工人”早期带苦中作乐，“牛马”更强调被压榨感，“班味”则把工作压力变成身体和气质上的痕迹。“去班味”流行，说明年轻人想从通勤、会议、报表、加班的流程里重新找回生活。

对《绿洲》的备用转译：

- 正文不直接说“班味很重”，改写为动作：老人删掉欢迎致辞，关掉统计栏，把出口灯先打开。
- “去班味”不写成旅行、消费或逃离，而写成绿洲里的新仪式：门口灯、安静退出、可旁听、下一次回应时间。
- 可用短句：`今天先把会议味散一散。`

### 8. 发疯工牌 / 工位文学：痛点是“没法公开说的话，绕成玩笑说出来”

发疯工牌的传播说明，职场人会把难以直说的疲惫和荒诞，转成可展示、可二创、可互认的轻型梗。它适合为《绿洲》提供“物件化表达”的方法，但不适合直接照搬疯话。

对《绿洲》的备用转译：

- 工牌反转成绿洲里的交接标签、门口小牌、暂存盒标签。
- 不写“发疯”，写“把不能催的话贴在下一班伸手就能看见的位置”。
- 备用物件：不催表态标签、低亮度门牌、旧螺栓小盒、暂存盒卡片。

### 9. 摸鱼 / 精神离职：痛点是“休息只能偷偷发生”

“摸鱼”不只是偷懒，也常被理解为对过度加班和边界消失的柔性反抗。远程办公研究里的 007 语境说明，家庭和工作边界一旦被打穿，人会更难真正下线。

对《绿洲》的备用转译：

- 休息不需要伪装成工作。
- 旁听、门口、稍后、安静退出都应被系统承认为合法参与。
- 可用短句：`不用假装在线，稍后也算在场。`

### 10. 咖啡 / 续命水 / 牛马咖啡：痛点是“靠消费维持透支”

“续命水”“牛马咖啡”类梗把城市白领的疲惫压缩成一个日常消费动作。它可用作氛围参考，但如果直接写，会有当下热梗味。

对《绿洲》的备用转译：

- 不写咖啡梗，写地球端半份饭、温水、药盒、晚饭铃声。
- 把“靠咖啡续命”反转为“系统提醒吃饭仍保留”。
- 第一章已有“半份，仍保留”，可继续作为反透支锚点。

## 可备用的《绿洲》内部短句

这些句子不是要求直接写进正文，而是提供语感方向：

1. `这次不按在线时长排。`
2. `下线不是掉队，是保留下一次。`
3. `今天只写等什么，不写谁慢。`
4. `别把拒绝写成权限不足，写为什么要等。`
5. `这张卡先别写成功，写还能从哪里接。`
6. `不用把夜熬完才算尽力。`
7. `入口先开，统计晚点再看。`
8. `先给出口灯，不急着给舞台灯。`
9. `这次不找背锅人，先找撤回点。`
10. `能回来的，都算在场。`
11. `先把会议味散一散。`
12. `稍后也算一个选择。`

## 对后续章节的写作约束

1. 第一章 v0.8 已经有足够轻梗，不宜继续追加。后续章节每章最多选一个互联网痛点做温柔反转。
2. 第二章如果使用“大小周 / 休息权”素材，应该落在低风险班次、休息格、维护窗口，不写加班控诉。
3. 第二章如果使用“PIP / 绩效”素材，应该落在“打印队列不按名字排”“普通维护件不选高光对象”，不写裁员。
4. 第三章可以使用“摸鱼 / 精神离职”素材，但要转成“旁听也能产生轻微影响”，不写偷懒。
5. 卷末娱乐设施试运营可以使用“统计折到后台”素材，强调公共快乐不是活动 KPI。

## 不采纳项

1. 不直接写真实公司名、真实事故或真实裁员案例进入正文。
2. 不让角色用“牛马、班味、福报、PIP、毕业、降本增效”等词做高频对白。
3. 不把互联网产品 / 开发 / 运营 / 算法 / 市场写成彼此攻击的段子。
4. 不把老人写成被职场创伤击垮后才进入绿洲的人。
5. 不把绿洲币写成新的绩效工资或加班补贴。
6. 不把“摸鱼”写成道德评判；在绿洲里，休息和退出是正当制度。

## 结论

互联网打工人苦难的高频母题不是某一个梗，而是“人被时间、指标、流程、年龄和话术吞掉”。《绿洲 2076》最适合做的不是复刻苦难，而是把这些旧流程重新用途化：让排期变成回应时间，让工单变成等待理由，让复盘变成保留失败痕迹，让统计退到后台，让退出也被系统承认为在场的一种方式。
