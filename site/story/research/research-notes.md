## 调研问题

这些设定是否能回应当下年轻人在现实生活中缺失的情感需求和憧憬：

- 老人用养老金建设绿洲。
- 地球老人通过量子通信接入小行星带 Agent 机器身体。
- Agent 像伙伴、电子宠物和半自主分身。
- 第一卷通过采矿、冶炼、零件 3D 打印和维修坞实现初步自给。
- 第一座低重力星光剧场 / 活动厅作为情感胜利。

## 调研发现

### 1. 年轻人需要“有边界但稳定”的陪伴

复旦相关报告提出“溏心蛋社交”：年轻人并不只想要浅层“搭子”，也不总是愿意进入高负担亲密关系，而是需要介于二者之间的固定聊天、稳定陪伴和情绪承接。报告中，“固聊”话题活跃度增长，分享快乐、吐槽生活、失恋安慰等情感需求中选择固聊的比例接近七成。

央视网 / 中青报调查同样显示，年轻人追求简单、纯粹、低负担的社交，但过度轻量化会带来缺少知心人、关系淡漠和难以建立长期亲密关系等担忧。

对《绿洲 2076》的启发：

- “纯粹友情、没有利益冲突、慢慢的人文关怀”是强匹配。
- 低重力星光剧场 / 活动厅应写成稳定重逢的公共场所，而不是一次性庆典。
- 老人和 Agent 的关系不能只有指挥与服从，还要有可重复的问候、等待、记忆和小习惯。

### 2. 年轻人仍渴望亲密，但拒绝低质量关系

复旦相关报告显示，单身青年网民中有很高比例表达恋爱意愿，但同时“低质量的恋爱，不如高质量的单身”也获得大量参与。尚未脱单的重要原因包括社交圈单一、难遇三观契合对象、不擅长交流。

对《绿洲 2076》的启发：

- 小说不必写恋爱主线，也能回应亲密需求：重点写“可靠、尊重边界、无需自我消耗的关系”。
- Agent 作为伙伴和半自主分身，适合承接“被理解、被陪伴、但不被吞没”的需求。
- 需要避免把 Agent 写成完美情绪替代品。更好的写法是：Agent 帮老人进入人与人的关系，而不是把人从关系中替换掉。

### 3. 孤独和缺少社会支持是真实痛点

CDC 将孤独定义为感觉孤单、断开连接或不亲近他人；其数据页指出，最近 2021-2023 数据中，美国青年只有约 3/5 觉得自己得到了所需的社会和情感支持。CDC 另一个页面提到，美国成年人约 1/3 感到孤独、约 1/4 缺少社会和情感支持，且年轻成年人也是更容易受到孤独影响的群体之一。

Harvard Youth Poll Spring 2025 也显示，18-29 岁美国年轻人中，不到一半感到有社区感，只有 17% 报告深度社会连接。

对《绿洲 2076》的启发：

- “绿洲”最强的吸引力不是太空，而是社区：一个仍然允许人慢慢连接、慢慢被记住的地方。
- 第一卷情感胜利不该只是建成设施，而应是“大家第一次在设施里形成共同记忆”。
- 需要把社区支持系统写成可见结构：固定活动、公共排程、共同维护、庆祝仪式、低压力参与入口。

### 4. 年轻人需要可持续的未来感，而不是继续内卷

Deloitte 2026 Gen Z and Millennial Survey 显示，Gen Z 和千禧一代更重视稳定、技能和幸福感，而不是快速增长；超过一半受访者因财务状况推迟重大人生决定。Harvard Youth Poll Spring 2025 显示，超过四成 30 岁以下年轻人表示财务上“勉强过得去”，且对社区和未来有明显压力。

对《绿洲 2076》的启发：

- “老人用养老金建绿洲”能回应年轻人对长期安全感的渴望：不是今天赢，而是五十年后仍有一个可参与的未来。
- 采矿建厂主线应写成“共同把未来变得可持续”，而不是工业 KPI。
- 自给自足目标要带出希望：自产零件让 Agent 能继续陪伴，维修坞让承诺不被一次故障打断，剧场让生产结果回到生活。

### 5. AI 陪伴已经进入情感生活，但风险在于替代真实关系

Common Sense Media 2025 调研显示，接近四分之三美国青少年使用过 AI companion，半数经常使用；相当一部分人会把 AI companion 用于社交互动、严肃对话或分享个人信息。该机构同时认为当前未成年人使用 AI companion 的风险大于收益。

Frontiers in Public Health 2025 对 1379 名大学生的研究显示，抑郁与使用对话式 AI 寻求陪伴呈正相关，孤独在其中起中介作用。虚拟宠物综述也指出，虚拟宠物不只是娱乐，还可涉及情绪健康、学习、生产力与目的感的重新理解，但也需要警惕消费主义设计和伦理问题。

对《绿洲 2076》的启发：

- Agent 的“电子宠物 + 分身 + 伙伴”设定高度贴合当代情感技术想象。
- 必须保留 Agent 的成本、限制和弱独立人格，避免它成为廉价的全天候完美陪伴。
- 最好的叙事策略是：Agent 不是人际关系的替代品，而是老人重新进入社区、共同生产和公共娱乐的媒介。

### 6. 年轻人需要自然、运动、线下活动和具身感

复旦相关报告提到，学习、分享和运动是年轻人应对情绪的主要方式；“到户外去，到大自然里去”是最让年轻人感到治愈的选项之一；参加线下活动、运动和户外项目的年轻人幸福感较高。

对《绿洲 2076》的启发：

- 绿洲不能只像一个远程控制后台或纯虚拟世界。
- 温室、低重力活动厅、矿场晨光、金属冶炼的热、维修坞的手感，都要写出具身体验。
- 老人虽然在地球，但通过 Agent 获得“身体重新进入世界”的感觉，这是打动年轻读者的关键。

## 适配判断

当前设定能够较好满足年轻人现实生活中缺失的四类需求：

1. 稳定但不窒息的陪伴：老人、Agent、公共活动厅可以形成“固聊式”的长期默契。
2. 非功利关系：无利益冲突、无贡献排名、不用表现才配被照护，回应了对纯粹关系的向往。
3. 未来可持续感：养老金、工业自给、维修坞和剧场共同构成“晚年仍能创造未来”的希望。
4. AI 时代的温柔媒介：Agent 满足电子宠物、分身和智能伙伴想象，但需要服务于人和人的重新连接。

最大风险：

- 如果写得太顺，会显得空泛乌托邦。
- 如果采矿建厂写成效率竞赛，会违背情感需求。
- 如果 Agent 太像完美伴侣，会落入 AI 替代真人关系的风险。
- 如果老人主题只停留在“养老”，年轻读者可能觉得离自己太远；需要把它写成“我也希望自己五十年后仍然被世界需要”的未来投射。

## 写作建议

1. 第一卷要让年轻读者看到“未来仍有位置”：老人不是被年轻时代抛弃后的余生，而是人生后半段继续建设世界的主体。
2. 低重力星光剧场 / 活动厅要承担固定社交功能：故事会、游戏、安静连线、舞会、纪念仪式、维修成果发布会。
3. Agent 要有小习惯和弱人格：能建议、能记得、会误解、会等待，但不会成为万能情绪替身。
4. 工业线要回到生活：每一次冶炼、打印和维修，都要落到某个具体关系被保住、某次活动能如期举行。
5. 保持“慢”：不要用爽文式升级替代修复、等待、协商和共同承担。
