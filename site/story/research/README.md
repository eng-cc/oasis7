# 调研

本目录用于存放支撑长篇可信度的调研笔记和问题清单。旧版调研内容已清空，当前已开始重建。

- `research-notes.md`: 当前调研笔记主文件，包含年轻人情感需求与《绿洲 2076》设定适配判断。
- `volume-01-chapter-01-research.md`: 第一卷第一章口味调研，覆盖 `CH-001` 到 `CH-012` 的社会口味、AI 陪伴、互联网行业共同记忆和 cozy / hopeful 科幻适配判断。
- `volume-01-chapter-02-research.md`: 第一卷第二章口味调研，覆盖 `CH-013` 到 `CH-020` 的第二天稳定连接、低风险复采、队列不排名、普通维护和剧场窗口保留。
- `internet-worker-hardship-meme-bank.md`: 互联网打工人苦难案例与梗备用素材库，用于把现实职场痛点转译成绿洲里的温柔反差。

章节正文写作前，应按 `../draft/chapter-writing-sop.md` 的“社会口味调研”环节更新或确认调研结论。调研用于校准当下读者的情感需求、审美警惕、社会语境和互联网行业共同记忆，不直接替代 canon。

## 写回规则

- 调研文字必须落到本目录文件里；聊天摘要不算正式调研结果。
- 跨章节或短篇幅调研写入 `research-notes.md`。
- 单章专项调研较长时，新建 `volume-XX-chapter-YY-research.md`，并在本 README 的文件列表中登记。
- 每条调研至少包含：调研问题、来源、发现、对正文的写作约束、不采纳项。
- 调研如果改变 canon，必须另行同步到对应 canon 文件；本目录只保存调研依据和判断过程。
