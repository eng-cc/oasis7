# 《绿洲 2076》第一卷第四章试写 v0.2

试写范围：`CH-029` 到 `CH-036`。

## 开场条件先问维修坞

罗衡在公共账本上写下“今晚开门”四个字，又停住。

笔画已经落成，字却像还没有资格站稳。剧场门口的灯在另一块屏上亮着，宋清岚把入口扶手、出口灯和安静连线的条件放到一侧，小穹在旁边等着，光标一闪一闪。

“先问维修坞。”罗衡说。

榫七把排程台展开。维护预备料，空维修位，可撤回方案。三项被放到节目单前面，像三只不太好看的小钉子，先把地面钉住。

程望川看了一眼后台：“今晚不能占满维修坞。至少留一格。”

梁季白把方案拆成三栏：不开门，半扇门，最低试运营。每一栏后面都写着能留下多少余量。宋清岚看见“不开门”那一栏时，指尖动了一下，却没有删。

小穹提示：可以只开启最小灯光、安静连线和退出路线。

顾微明原本写好的公告在屏角亮着：即将开幕。罗衡还没开口，他已经把那四个字删掉，改成：

条件核对中。

宋清岚看了很久，说：“不满足就不开门。”

她把“留灯”留在公告最下方。不是为了安慰谁，也不是为了把等待写得好看。只是不开门的那一天，门口也不能像什么都没有发生过。

罗衡这才在账本下补了一行：

开门前先问维修坞。不满足，灯也留着。

## 第四炉不为开场加速

第四炉提示亮着的时候，剧场门口的灯也亮着。

许映舟知道很多人在等那扇门真正打开。安静连线里偶尔有一点细小的声音，像有人把杯子放回桌面，又赶紧静下来。她听见那种等待，反而更不敢快。

暂存台上缺一批普通维护预备料。数量不多，只够让维修坞的应急包不空着，也够让门口那盏黄灯少闪一次。

有人问：“如果等完整冷却，会不会晚半天？”

俞澄怀没有抬头：“热的时候别逞强。”

蒲晓岑把墙上的“剧场延后”删掉，改成“等待冷却”。想了想，又把旁边那盏催人的黄灯关小一点。

砾光站在低风险标线后，只读样本来源，把一份边缘样本标出来。许映舟看完记录，把它移出本炉列表。那份样本看起来也许能用，但“也许”两个字太轻，托不起明天的灯。

白若临在趋势图旁写：风险较低，不能替代复验。

第四炉出料时，没有人鼓掌。浅灰色材料颗粒落进小盒，边缘仍有粗粒，颜色也不整齐。韩树宁把这一炉和前两炉的差异记下，只写条件，不写哪个班次更稳。

周砚屏让应声只留三行：

维护预备料补齐。

仍需复验。

试运营不加速。

许映舟看着“补齐”两个字，没有觉得满。它只是刚好够用，像一盏灯下的窄路，窄归窄，但没有让人闭着眼睛走。

## 最后一个系留扣先给退出路线

林问秋拿起第一枚系留扣时，下意识看向入口。

入口最亮，也最像一个开始。刚打印出来的扣件还带着一点温热，边缘没有装饰纹，只留着低负载标记。安全件箱里还有扶手端帽、出口灯固定片和备用限位件，每一格都浅浅卡住，不让它们在低重力里飘散。

盛小满把最低验收范围念了一遍。方其远把装配按钮旁的说明改成“安全件”，不写“剧场件”。莫听澜检查完公差，只说这批扣件只能做低负载引导，不能扩展成更复杂的座席。

林问秋点头，把第一枚扣件拿到入口位置。

叶简初却指了指旁边那条不太显眼的退出路线：“先给这里吧。”

林问秋停住。

“入口没人会漏看。”叶简初说，“万一有人想走，最好一伸手就在。”

谢观澜用自己的对应 Agent 试了一遍退出动作。手扶住扣件时，低重力回弹被轻轻带住，没有把身体甩向门框。小穹把退出路径上的灯压得很低，不抢入口的光，却足够让手找到位置。

尺素把需求卡翻到背面，补了一行：

进入要看见，退出也要被接住。

夏青岑给安全件箱贴交接标签。标签歪了一点，不漂亮，但林问秋没有重贴。她把第一枚系留扣装到退出路线，听见卡榫合上的声音，很轻，像有人终于承认半路离开也需要一只手。

## 维修坞空出一张床

程望川看着那张空维修床，手指在排程上停了很久。

它空着，就像今天还有一件事没做完。

维修坞里没有多余的热闹。基础维护包 A 放在应急架上，新补的预备料分在小盒里，线缆夹、垫片和备用限位件各自占着窄格。戴若素核对了两遍，秦有则把剧场入口、安静连线和维修坞同时运行时的依赖关系画成一条短链。

“如果这里也排满，小故障就没有地方落。”秦有则说。

石听雨把状态墙上的“空闲”删掉，改成“应急位保留”。

程望川还是看向队列。里面有一台对应 Agent 已经等了很久，只差一次普通复检。等待的人没有催，只在安静说明窗口亮着一个小点。

卢向安已经把话发过去：复检不取消，试运营后第一时间接上。她没有写太长，也没有让对方表达理解。

榫七确认应急位结束后回到普通复检队列。许映舟和砾光站在旁边，砾光低声说：“当初我也是被一张排程接住。”

程望川把那张床留空。

罗衡后来路过维修坞，在账本里看见“未使用”三个字。他没有把它划掉，只在后面补了一句：

未使用，也算兑现。

那张床仍旧空着。白色床面干净得有些突兀，可突兀本身让人安心。它像门后有人没睡，等着接住任何一次不该发生的小意外。

## 旧螺栓不放在正中央

旧螺栓放在记忆墙正中央时，陈照野觉得画面很稳。

它暗，边缘有细小磨痕，旁边接上第一炉异常曲线和退炉残片影像，确实能让人一眼看见绿洲不是顺顺当当走到这里的。留帧把低重力轨迹放慢，矿尘像细雪一样从画面里落下来。

许映舟却一直没有说话。

陈照野转头看她，才发现她看的不是墙，而是砾光。砾光站在门侧，旧臂螺栓的影像亮起来时，它的光圈安静收了一点。

小穹把陈列槽往门侧移开：“这里也能看见。想停的人可以停，不想停的人可以直接进去。”

姚初白删掉说明文里的漂亮词，只留下来源、时间和当时的处理结果。谢观澜把动画速度再降一档，让曲线像慢慢被人放下，而不是被推到眼前。闵存真确认原始记录已经备份，公共播放只取短段。

砾光说：“普通维护包 A 的交接卡，也放进去吧。”

陈照野怔了一下。

砾光没有解释。它只是看着那枚旧螺栓。旁边还有推料盒的对应 Agent 记录、换过限位件的值勤记录，还有那些没有名字放在第一排的垫片和线缆夹。

陈照野把旧螺栓移到门侧。留帧把普通维护记录放进同一组影像里，位置不高，也不低。有人经过时能看见；不想看，也可以直接走进灯下。

他忽然觉得，门侧比正中央更像记忆该在的地方。

## 入口演练只走半圈

那位老人只走了半圈。

他的对应 Agent 在扶手旁停住，系留扣轻轻回弹。周砚屏看见反馈屏上跳出“退出成功”，立刻皱了一下眉。

旁听席安静了一瞬，有人小声问：“是不是失败了？”

小穹没有催促，也没有把门口灯调亮。灯只是保持在最低亮度，照着退出路线和那只刚松开的扣件。

梁明玥今天只安排了少量值守者和两位旁听者，没有开放报名。叶简初确认过进入、旁听和退出三个入口，孟行远确认安静连线不会自动点名。可“退出成功”四个字一跳出来，所有准备都像短了一口气。

“成功这个词，好像在说他完成了什么任务。”周砚屏说。

应声停了停：“沿用旧任务文案。”

演练暂停二十分钟。任舒同把“退出原因”字段删掉，只保留一行反馈。她说：“不是每个人都要说明为什么只走半圈。”

周砚屏没有接话。她想起第一天那些人等在静默加载里，误以为自己掉线。原来世界回一句话，也可能把人推远。

二十分钟后，那行字重新亮起：

已退出，位置保留。

冉书禾没有碰字号，只把这行提示挪到和进入提示同一侧，让两条路看起来一样正当。

宋清岚没有问对方为什么不走完。她只让小穹把门口灯继续留着。半圈的脚印停在扶手旁，没有被擦掉，也没有被解释成遗憾。

## 节目单删到只剩三件事

节目单删到第三遍时，宋清岚还是觉得多。

梁明玥看着被划掉的长节目和互动环节，小声说：“这两个大家会喜欢。”

“以后再喜欢。”宋清岚说。

她其实也舍不得。陈照野准备的星光动画只剩下短段，留帧的影像窗口被压到最轻。罗衡和榫七确认过，试运营期间只支撑最小灯光、安静连线和短时影像。卓宜年提醒节目越满，退出和休息越难。

庄可闻把公告从“首场活动”改成“第一次一起坐一会儿”。姚初白删掉“维修成果”的口吻，只留下门口灯、空维修床和短节目单。宋清岚看着那几行，忽然觉得它比一长串节目更像邀请。

最后节目单只剩三件事。

罗衡读一条短账本。

留帧放一段短记忆。

小穹留一段可坐可走的安静时间。

孟行远确认安静连线不显示在线名单。旁听的人可以只听，不用被看见，也不用在结束时说一句“我很感动”。

小穹问：“坐多久？”

宋清岚想了想：“坐到有人想走，也可以。”

她把两个自己最想看的节目划掉。空出来的时间留在那里，不闪，不响，也没有标题。像一排没有被填满的座位，终于不急着证明自己有用。

## 第一场低重力星光剧场

低重力星光剧场第一次真正开门时，灯并不亮得夸张。

它只是把入口照清楚，把退出路线照清楚，也把门侧那枚旧螺栓照得刚好能看见。叶简初确认入口反馈，小穹只开启排程允许的最低灯光、旁听和退出路径，没有碰那些还未排到的模块。

后台，榫七确认应急位保留。那张空维修床仍旧空着，基础维护包 A 和维护预备料都在应急架上。应声在入口边显示三行：

可进入。

可旁听。

可安静退出。

罗衡读了一条很短的账本。第四炉没有抢冷却窗口，维修坞还空着一张床，门侧那枚旧螺栓也没有被摆到正中央。他读到最后，停了一下，说：“今天不是产量日。”

安静连线里有人轻轻笑了一声。

留帧播放短记忆。矿尘轨迹、异常曲线、旧螺栓、普通维护包交接卡和门口灯一帧一帧过去。许映舟和砾光站在门侧，没有被推到中央。砾光低声请小穹把旧螺栓旁边的小灯压低一点，小穹照做，让它不刺眼。

那台一直负责搬料盒的对应 Agent 把一个浅灰料盒推到门侧，又退回队列。动作很短，像把自己的日常也交给大家看一眼。

中途有人退出。

周砚屏看见应声没有把那一行变灰，只写：已退出，位置保留。

有人只听不说。有人今天没有上线。下一次安排仍在灯旁静静亮着，安静连线没有自动亮出名单。宋清岚坐在入口边，听见小穹把灯光维持在最低，像一口很稳的呼吸。

快结束时，入口旁的提示从“试运营完成”改成“下一次已安排”。

宋清岚看见那几个字，忽然明白自己等的不是今天终于开门，而是这扇门不用只为今天开。

有人问：“明天还开吗？”

宋清岚看向小穹。

小穹回答：“明天也留灯。”

有人只是安静坐着，有人从退出路线离开，有人在线路另一端关了麦。门侧的旧螺栓被灯轻轻照着，空维修床没有被使用，短节目单已经结束。

灯还亮着。

它不催人留下些什么，也不追问谁为什么没有来。它只是照着入口和出口，照着明天也可能有人坐下来的地方。
