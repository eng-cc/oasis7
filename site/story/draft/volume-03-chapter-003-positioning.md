## 本章任务句

本章要让温室进入一次可撤回低水量动作，但不让照看变成资格。共同体写出可撤回浇灌令草案，拆开照看权限，让回砂只做边缘软刷复位，承认第一次浇灌暂停也是有效照看，把霉斑样本放进隔离托盘，删掉照看人资格栏，并继续让未命名种子袋不开；卷尾只允许一次低水量动作，不写长期权限、温室稳定、会养证明或关系复原。

## 本章最低推进

- 第一份浇灌令只写成可撤回草案，低水量、限窗口、人工复核。
- 照看拆成观察、刷尘、移托盘、开水雾、确认光照五层。
- 回砂只做温室门口软刷复位，不接旧承诺，不获得额外权限。
- 第一次浇灌因散热窗口不稳暂停，暂停记录为有效照看。
- 霉斑样本进入隔离托盘，标签只写来源和复核时间。
- “照看人资格”被删掉，改成“本轮可参与动作”。
- 未命名种子袋继续暂存，不打开、不命名、不进播种队列。
- 章末可撤回浇灌令只允许一次低水量动作，下一轮仍需重新问。

## 场景切分

### CH-095 / 可撤回浇灌令草案

- 推荐 POV：林问秋 / 尺素。
- 前台动作：第一份浇灌令写成可撤回草案。
- 场景边界：草案不进入长期权限，不成为正式制度。
- 主要物件：可撤回浇灌令草案、低水量标记、人工复核格。

### CH-096 / 照看权限分层

- 推荐 POV：尺素 / 盛小满。
- 前台动作：把照看拆成五层动作格。
- 场景边界：一层成立不带出全层权限。
- 主要物件：照看分层清单、五层动作格、铅笔条件页。

### CH-097 / 回砂只做边缘动作

- 推荐 POV：宋清岚 / 程望川旁证位。
- 前台动作：回砂只参与温室门口软刷复位。
- 场景边界：不接旧承诺，不恢复旧关系，不获得额外权限。
- 主要物件：温室门口软刷、复位小卡、边缘动作记录。

### CH-098 / 第一次浇灌被暂停

- 推荐 POV：罗衡 / 榫七。
- 前台动作：散热窗口不稳，第一次浇灌暂停。
- 场景边界：暂停不是失败，也不是事故。
- 主要物件：散热窗口、浇灌令草案、暂停记录。

### CH-099 / 隔离托盘接住样本

- 推荐 POV：陈照野 / 留帧。
- 前台动作：霉斑样本进入隔离托盘。
- 场景边界：托盘接住样本，不接住责任归属。
- 主要物件：隔离托盘、霉斑样本片、来源 / 复核时间标签。

### CH-100 / 不把会养写成资格

- 推荐 POV：宋清岚 / 小穹。
- 前台动作：删掉“照看人资格”，改成“本轮可参与动作”。
- 场景边界：参与动作不生成排名，不证明会养。
- 主要物件：参与动作栏、删除痕迹、提示维护页角。

### CH-101 / 未命名种子袋仍未打开

- 推荐 POV：陈照野 / 留帧。
- 前台动作：种子袋继续暂存，袋口灰尘和未开封状态被保留。
- 场景边界：种子袋不打开，不命名，不进入播种队列。
- 主要物件：未命名种子袋、半合暂存格、袋口灰尘。

### CH-102 / 浇灌令只通过一次

- 推荐 POV：林问秋 / 罗衡 / 宋清岚。
- 前台动作：可撤回浇灌令只允许一次低水量动作。
- 场景边界：不代表长期照看权限或温室稳定；下一轮重新问。
- 主要物件：可撤回浇灌令、低水量动作记录、下一轮暂停口令。

## 行业反差

本章主方向：revocable order / permission scopes / rollback-friendly action / no role promotion / one-time authorization。

转译要求：

- revocable order -> 可撤回浇灌令，不是长期制度。
- permission scopes -> 分层动作格，一层不带出全层。
- rollback-friendly action -> 暂停记录也是有效照看。
- no role promotion -> 本轮可参与动作，不是照看人资格。
- one-time authorization -> 只允许一次低水量动作，下一轮重新问。
