# 《绿洲 2076》第三卷后续第一章写前定位

## 范围

- 章节：第三卷后续第一章 / 暂定全书第十五章。
- 场次：`CH-119` 到 `CH-126`。
- 时间线：`TL-119` 到 `TL-126`。
- 章节卡：`site/story/chapter-cards/volume-03-followup-chapter-01-cards.md`。
- 调研：`site/story/research/volume-03-followup-route-research.md`。
- 状态：写前定位；不是正文。

## 本章任务句

本章要让 `CH-118` 后的第一夜长周期窗口发生，同时让共同体学会接住“没有变化”：苗床没有发芽，凝露很浅，曲线页空白，提醒被撤回，夜间巡检口令可撤回；章末只获得“无变化记录不是失败”的口径，不写温室常态、稳定照看、第一芽或成果。

## 本章最低推进

- 第一夜巡检只生成夜间无变化记录条。
- 晨前凝露刻度尺读数很浅，但不写成照看不足。
- 空白生长曲线页被保留，不自动生成趋势线。
- 照看提醒被撤回，系统不催促老人上线补做。
- 夜间巡检口令增加“可撤回”选项。
- 霉斑样本仍和无变化记录同页，风险不退出。
- 公共状态只写“本夜无新增 / 下一轮仍可暂停”。
- 章末收束在一条无变化记录和一页空白曲线。

## 场景切分

### CH-119 / 夜间无变化记录条

- 推荐 POV：周砚屏 / 应声。
- 前台动作：夜间无变化记录条生成。
- 场景边界：不写失败、不写补救、不写第一芽。
- 主要物件：夜间无变化记录条、下一轮暂停页角。

### CH-120 / 晨前凝露刻度尺

- 推荐 POV：周砚屏 / 罗衡。
- 前台动作：晨前凝露刻度尺读数很浅。
- 场景边界：浅痕不是照看不足，也不是稳定供水。
- 主要物件：晨前凝露刻度尺、浅水痕、低功率窗口窄条。

### CH-121 / 空白生长曲线页

- 推荐 POV：林问秋 / 尺素。
- 前台动作：空白曲线页被保留，不补趋势线。
- 场景边界：空白不是失败，不预测发芽。
- 主要物件：空白生长曲线页、未生成趋势线、铅笔页角。

### CH-122 / 未发送的照看提醒

- 推荐 POV：宋清岚 / 小穹。
- 前台动作：照看提醒被撤回，保持未发送。
- 场景边界：无变化不需要催促老人上线。
- 主要物件：未发送的照看提醒、撤回提示。

### CH-123 / 可撤回夜间巡检口令

- 推荐 POV：罗衡 / 榫七。
- 前台动作：夜间巡检口令增加“可撤回”。
- 场景边界：巡检不是值班义务，不写制度成立。
- 主要物件：可撤回夜间巡检口令、暂停页角。

### CH-124 / 霉斑样本仍在同页

- 推荐 POV：陈照野 / 留帧。
- 前台动作：霉斑样本和无变化记录同页保留。
- 场景边界：风险不退出，不写污染解决。
- 主要物件：霉斑样本片、同页复核夹。

### CH-125 / 本夜无新增

- 推荐 POV：周砚屏 / 景亭晚。
- 前台动作：公共状态改成“本夜无新增 / 下一轮仍可暂停”。
- 场景边界：无新增不等于失败，不用安慰口号。
- 主要物件：本夜无新增状态条、下一轮暂停页角。

### CH-126 / 第一夜收束

- 推荐 POV：林问秋 / 宋清岚。
- 前台动作：第一夜收束在无变化记录和空白曲线页。
- 场景边界：不写温室常态，不生成下一章成果期待。
- 主要物件：夜间无变化记录条、空白生长曲线页、未发送提醒。

## 行业反差

本章主方向：no-update status / alert suppression / empty chart / reversible night check。

转译要求：

- no-update status -> 本夜无新增，不是失败指标。
- alert suppression -> 未发送照看提醒，不是漏通知。
- empty chart -> 空白生长曲线页，不是数据缺失。
- reversible night check -> 可撤回夜间巡检口令，不是值班制度。

## 正文开头提醒

不要从“温室第一夜终于过去”开头。建议从夜间无变化记录条生成写起：

夜间无变化记录条生成得很慢。周砚屏先看见的不是苗床，而是记录条上没有失败词。它只写：本夜无新增。下一轮仍可暂停。

第一段就把后续路线压到“没有变化也被接住”，不要让读者期待发芽、惊喜或成果。

## 风险检查

- 是否写出失望？若是，改成记录条、提示词和人的停顿。
- 是否出现发芽、命名、稳定供水或温室常态？若是，删掉。
- 是否把无变化写成需要补救？若是，改成下一轮仍可暂停。
- 是否让系统催促老人上线？若是，改成未发送提醒。
- 是否把巡检写成值班？若是，保留可撤回口令。
- 是否把霉斑样本移走？若是，改为同页保留。
