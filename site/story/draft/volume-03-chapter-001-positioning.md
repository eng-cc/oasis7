## 本章任务句

本章要让温室议题成立，但不让希望抢跑。共同体先确认水、热、洁净、散热、维护窗口和低压力参与边界；卷尾只保留第一格空苗床，不播种、不发芽、不宣布生活循环成功。

## 本章最低推进

- 温室从愿望清单进入条件核对页，但只写“议题打开”。
- 第一格苗床保持为空，先登记条件，不放种子。
- 门口软刷把洁净要求变成低压力动作，不写成责备或资格筛选。
- 散热余量条进入公共排程，让温室和维修坞、剧场、低带宽陪伴共享真实代价。
- 未命名种子袋只暂存，不成为希望口号或宣传素材。
- 冷凝盘第一次空转，系统说明“还没发生”也可被接住。
- 只看条件的人不被催促报名或解释。
- 章末仍是空苗床；空不是失败，是慢下来的生活入口。

## 场景切分

### CH-079 / 温室议题被打开

- 推荐 POV：宋清岚 / 小穹。
- 前台动作：温室从愿望清单移到条件核对页。
- 场景边界：不写即将播种，不写开放日。
- 主要物件：温室条件核对页。

### CH-080 / 第一格空苗床

- 推荐 POV：林问秋 / 尺素。
- 前台动作：第一格苗床保持为空，先登记条件。
- 场景边界：空不是失败，也不是拖延。
- 主要物件：第一格空苗床、铅笔条件格。

### CH-081 / 温室门口软刷

- 推荐 POV：周砚屏 / 应声反馈位。
- 前台动作：门口软刷和停步线进入温室入口。
- 场景边界：洁净要求不变成责备。
- 主要物件：温室门口软刷、停步线。

### CH-082 / 散热余量条

- 推荐 POV：罗衡 / 榫七。
- 前台动作：温室散热余量条挂到公共排程旁。
- 场景边界：资源压力真实存在，但不写成抢资源。
- 主要物件：散热余量条、公共排程页。

### CH-083 / 未命名种子袋暂存

- 推荐 POV：陈照野 / 留帧。
- 前台动作：未命名种子袋被记录并暂存。
- 场景边界：不包装成希望象征。
- 主要物件：未命名种子袋、暂存签。

### CH-084 / 冷凝盘第一次空转

- 推荐 POV：周砚屏 / 应声。
- 前台动作：冷凝盘空转，提示写成“空转复核中”。
- 场景边界：没有水珠不等于失败或掉线。
- 主要物件：冷凝盘、空转提示。

### CH-085 / 只看条件的人

- 推荐 POV：宋清岚 / 小穹。
- 前台动作：一位老人只看条件核对表，不报名照看。
- 场景边界：只看也算参与。
- 主要物件：条件核对表、门口小凳。

### CH-086 / 第一章空苗床收束

- 推荐 POV：林问秋 / 罗衡 / 宋清岚。
- 前台动作：第一格苗床仍为空，条件页合上一半。
- 场景边界：不播种、不发芽、不宣布生活循环成功。
- 主要物件：第一格空苗床、水雾收集膜、门口软刷。

## 行业反差

本章主方向：preflight / checklist / dry run / environmental readiness / participation without signup。

转译要求：

- preflight -> 温室条件核对，不是开工典礼。
- checklist -> 生活条件页，不是验收表。
- dry run -> 冷凝盘空转复核，不是失败。
- environmental readiness -> 水、热、洁净、散热和维护窗口同时被看见。
- participation without signup -> 只看条件也算参与，不生成报名压力。
