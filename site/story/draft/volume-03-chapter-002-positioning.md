## 本章任务句

本章要让温室进入第一次可观测试运行，但不让“第一滴水”变成胜利。共同体展开水雾收集膜，看见冷凝盘水痕，也同时保留光照暂停、霉斑样本、空隔离托盘和维修坞余量边界；卷尾只承认冷凝和霉斑并存，不写成功、可饮用、稳定供水或生活循环成熟。

## 本章最低推进

- 水雾收集膜展开，水路只进入低功率试运行。
- 冷凝盘出现第一滴水，但公共状态只写“可观测 / 不可饮用 / 待复验”。
- 光照排程因散热余量暂停一次，提示写成“暂停中”。
- 第一片疑似霉斑被记录成样本片，不藏到后台，也不剪成失败。
- 隔离托盘设立但保持空置，用来承接下一轮复核。
- 温室水路复验不借维修坞应急余量，只拿下一轮低功率窗口。
- 污染提示改为“需隔离复核”，不写脏、不写责任人、不生成照看排名。
- 章末冷凝水痕与霉斑样本并存；两者都进入下一轮复核。

## 场景切分

### CH-087 / 水雾收集膜展开

- 推荐 POV：林问秋 / 尺素。
- 前台动作：展开第一片水雾收集膜，确认低功率收集和回流路径。
- 场景边界：水路只是试运行，不承诺稳定供水。
- 主要物件：水雾收集膜、低功率回流路径、条件核对页。

### CH-088 / 冷凝盘出现第一滴水

- 推荐 POV：周砚屏 / 应声反馈位。
- 前台动作：冷凝盘出现第一滴水，提示改成“可观测 / 不可饮用 / 待复验”。
- 场景边界：第一滴水不能写成成功、庆祝或可饮用。
- 主要物件：冷凝盘、第一滴水、可观测提示。

### CH-089 / 光照排程暂停一次

- 推荐 POV：周砚屏 / 罗衡。
- 前台动作：散热余量不足，光照排程暂停一轮。
- 场景边界：暂停不是故障，也不是温室坏了。
- 主要物件：光照排程、散热余量条、暂停提示。

### CH-090 / 霉斑样本片

- 推荐 POV：陈照野 / 留帧。
- 前台动作：疑似霉斑被拍成样本片并留存。
- 场景边界：霉斑不是羞耻，不是失败素材，也不能藏到后台。
- 主要物件：霉斑样本片、样本夹、低亮度记录图。

### CH-091 / 隔离托盘空置

- 推荐 POV：林问秋 / 尺素。
- 前台动作：隔离托盘设立后保持空置。
- 场景边界：空置托盘是可暂停边界，不是惩罚区。
- 主要物件：隔离托盘、空置标签、铅笔条件格。

### CH-092 / 水路不抢维修坞

- 推荐 POV：罗衡 / 榫七。
- 前台动作：罗衡拒绝借用维修坞应急余量，只安排下一轮低功率窗口。
- 场景边界：拒绝是保护已有承诺，不是资源争吵。
- 主要物件：维修坞应急余量、温室复验排程、低功率窗口条。

### CH-093 / 污染不是羞耻

- 推荐 POV：蒲晓岑 / 周砚屏。
- 前台动作：污染提示改成“需隔离复核”。
- 场景边界：不写脏、不写责任人、不写照看排名。
- 主要物件：污染提示、隔离复核标签、样本片记录。

### CH-094 / 冷凝和霉斑并存

- 推荐 POV：林问秋 / 陈照野 / 周砚屏 / 罗衡。
- 前台动作：冷凝盘水痕和霉斑样本一起进入下一轮复核。
- 场景边界：水痕不是成功，霉斑不是失败；种子袋不打开。
- 主要物件：冷凝盘水痕、霉斑样本片、散热余量条、空隔离托盘。

## 行业反差

本章主方向：observable / not for production / pause is a valid state / incident wording / no resource override。

转译要求：

- observable -> 可观测，不等于可用。
- not for production -> 不可饮用 / 待复验，不是成功。
- pause is a valid state -> 暂停中，不是故障。
- incident wording -> 需隔离复核，不写责任人。
- no resource override -> 温室复验不能抢维修坞应急余量。
