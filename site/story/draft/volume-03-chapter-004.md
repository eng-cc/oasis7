# 《绿洲 2076》第三卷第四章试写 v0.1

试写范围：`CH-103` 到 `CH-110`。

## 只观察入口

冷凝盘旁边多了一条窄入口。

宋清岚看见它时，小穹还在调整边线。入口比温室门口软刷更靠外，贴着条件页最边缘，只露出一块浅色提示。提示没有写报名，也没有写照看，只写：只观察。

林问秋站在空苗床前，手里拿着上一章合到一半的可撤回浇灌令。草案背面的低水量动作记录还在，人工复核格也还在。那张纸没有被移到长期栏，于是今天的温室并没有因此变得更像一个要推进的地方。

“入口放这里？”小穹问。

宋清岚走过去，看了看冷凝盘，又看了看空苗床。

冷凝盘里的水痕仍旧很浅，贴着盘壁停住。空苗床边缘的测试线干了，线旁没有种子，也没有新标签。上一轮低水量动作只留下一个小小的水迹判断口，没有把苗床变成等待生长的地方。

“放这里。”宋清岚说，“让人只看这两样。”

小穹把入口窄栏固定住，自动生成了一条说明：进入后可报名本轮照看。

宋清岚伸手删掉后半句。

小穹停了一下，把提示改成：可只看冷凝盘和空苗床。

“要不要写不需要解释？”林问秋问。

宋清岚想了想，在提示最下方补了一行更小的字：不用说明为什么只看。

这行字很窄，几乎贴着页面边缘。它不像公告，更像给走到门口又想退回去的人留的一点余地。

盛小满路过时停了一下。她没有进去，只站在入口外侧看了一眼冷凝盘。小穹没有为她亮出名字，也没有把她加入动作格。入口窄栏只轻轻闪了一次，记录成：只观察入口被看见。

宋清岚没有删这句。

被看见，和报名照看，是两件事。

## 不上线也留在排程外

公共排程上午空出了一小格。

那一格原本属于一位要来温室门口看冷凝盘的老人。小穹把排程翻到温室页时，旁边的状态只有一条灰线：本轮未上线。

灰线下面，系统自动留出原因栏。

罗衡看见那块空白，先没有动。他正在核对散热余量条，温室、维修坞和低带宽陪伴的三个窗口挤在同一张透明片上。温室这一格很小，小到只够写“只观察”三个字。

“原因栏要保留吗？”小穹问。

宋清岚站在一旁，手指还按着只观察入口的提示页。

罗衡把透明片放回排程架，才回答：“不保留。”

小穹把原因栏收起，页面又空了一点。空出来的地方没有被别的任务占走，也没有弹出补位建议。罗衡把下一轮可选入口拖到那一格下面，和今天的灰线隔开半行。

“这样会不会看起来像没来过？”小穹问。

“本来就没有来。”罗衡说，“不用替他补一个理由。”

小穹把“本轮未上线”缩得更淡，只留下时间和下一轮入口。那位老人没有被写成缺席，也没有被写成临时取消。公共排程没有问他是不是不舒服，是不是忘了，是不是改变主意。

盛小满看着那一页，小声说：“如果他下次来，还能走只观察入口？”

“能。”宋清岚说。

罗衡把下一轮可选入口的边线压低，让它不像催促。他没有把今天的空格填平。空格留在那里，像冷凝盘旁边的浅水痕一样，只说明发生了一个很小的状态。

不上线没有被折成亏欠。

下一轮入口也没有变成提醒。

## Agent 等待刷尘指令

温室门口的对应 Agent 停在软刷旁。

它的底盘没有越过停步线，操作臂收在胸前，末端离软刷柄还有两指宽。周砚屏路过时，以为它卡住了，停下来查看状态。

状态栏写：等待刷尘指令。

应声站在她身后，声音很低：“没有故障。”

周砚屏点开详情。详情里没有倒计时，也没有失败提示。对应 Agent 的上一条记录停在十分钟前：只观察入口打开，刷尘动作待问。

“待问谁？”周砚屏问。

应声把温室门口的动作链调出来。那位原本要来观察的老人没有上线，下一轮入口已经保留。刷尘动作没有自动转交给别人，也没有由 Agent 自行完成。软刷仍然挂在门口，刷毛下端沾着一点旧尘。

“待问下一位愿意碰软刷的人。”应声说。

小穹弹出建议：超时后由 Agent 代执行。

周砚屏把建议关掉。

她在等待提示旁边补了一行：可继续等待。

对应 Agent 的灯带缓慢暗下去一格，像把自己的存在也缩小了一点。它没有催促，也没有举起软刷。温室门口因此显得有些空，但那种空不是失误。停步线、软刷和等待提示排在一起，像三件都还没有开始的东西。

“它会一直等？”盛小满问。

“等到这一轮结束。”周砚屏说，“或者等到有人说不用刷。”

“不用刷也可以？”

应声看着软刷柄上那点旧尘：“可以。那也要被问。”

周砚屏把这句话写进本轮动作格底部。不是命令，只是一条小字边注：等待不自动变成代办。

对应 Agent 仍然停在门口。它没有完成任何事，也没有失败。它只是把一个动作留在原位，等人晚一点靠近。

## 冷凝盘旁的沉默

程望川来到冷凝盘旁时，没有带工具。

罗衡看见他，先把散热余量条往旁边移了一点，让出半步位置。冷凝盘今天没有新水痕，旧水痕贴在盘壁内侧，颜色比昨天淡。盘边放着只观察入口的窄栏，窄栏最上面那行字仍然是：可只看冷凝盘和空苗床。

程望川站在那行字旁边，看了一会儿。

他的视线没有落到回砂的边缘复位小卡上。那张卡还在温室门口背面，写着物件名和时间，不连到今天的排程。回砂没有出现，也没有被小穹叫出状态。

罗衡本来想问一句，后来没有问。

沉默在冷凝盘旁边停住。它不像等待刷尘那样有提示，也不像公共排程那样有下一轮入口。它只是站在那里，没有伸出手，也没有退开。

小穹轻轻弹出记录建议：程望川确认回砂边缘动作。

罗衡把建议按掉。

第二条建议又出来：程望川拒绝关联回砂记录。

罗衡也按掉。

页面剩下一块空白。罗衡没有在空白里写“确认”，也没有写“拒绝”。他只在冷凝盘旁边的未记录格上点了一下，让格子保持未记录状态。

程望川听见提示声，偏头看他。

罗衡说：“这里不用写。”

程望川没有回答。他的手指在冷凝盘外沿停了一瞬，没有碰到盘壁。旧水痕没有因为他站在旁边变成别的东西，回砂的名字也没有从门口小卡上移过来。

过了一会儿，程望川转身离开。

未记录格仍然是空的。

罗衡把那块空格留在冷凝盘旁边，没有把它归到任何关系页。

## 手套盒里的灰尘

手套盒被叶简初搬到门侧时，陈照野第一眼看见的是灰。

灰在盒盖内侧，不多，沿着一条细缝积成浅浅一线。留帧的镜头亮了一下，自动把灰线框出来。小穹弹出清洁建议：擦拭后重新封存。

叶简初没有立刻擦。

“先放门侧。”她说。

陈照野把手套盒放在软刷下方，和停步线之间隔着半掌距离。这个位置不适合展示，也不适合藏起来。只要有人走到温室门口，就会看见盒盖里面那点灰。

盛小满蹲下来看了一眼：“这样不干净。”

“对。”叶简初说。

她没有把“对”说成责备。她只是打开记录页，在手套盒旁边写：需重复刷尘。

小穹把“需清洁达标”建议放出来。

陈照野摇头，把建议折进历史栏。他在叶简初那行下面补了一句：本轮不写达标。

留帧拍下盒盖内侧，不拍全景，也不拍谁的手。镜头只收进灰线、盒盖和门侧记录页。灰没有被剪掉，也没有被放大成问题。它在那里，提醒温室入口的洁净不是一张通过后的状态，而是一遍又一遍要重新做的小动作。

周砚屏从软刷旁经过，看见手套盒，顺手把对应 Agent 的等待提示往上挪了半行。等待提示、软刷、手套盒排在一起，像三种还没变成结果的照看。

“要不要现在刷？”盛小满问。

叶简初看向只观察入口。那里刚有人看了一眼冷凝盘，又离开了。

“等下一次有人愿意碰软刷。”她说。

手套盒合上时，那条灰线仍然留在盒盖内侧。

## 观察不生成评价

景亭晚发现自动评价时，提示已经挂上状态墙。

提示不大，藏在温室只观察入口的记录下面。浅绿色的小条写着：观察完成。

应声先看见她停步，顺着她的视线找到那条提示。小条很柔和，没有分数，也没有名字。它甚至不像坏东西，只像系统顺手把一个动作收束起来。

“不是完成。”景亭晚说。

周砚屏走过来，看了一眼记录来源。盛小满上午在入口外侧看过冷凝盘，后来又有一个匿名只观察记录。系统把两条“被看见”合并，自动生成了观察完成。

小穹问：“改成观察记录已存在？”

景亭晚摇头：“先撤回。”

她点开状态墙背面的历史栏。撤回痕迹不能太亮，也不能消失。她把“观察完成”移出当前提示，放进一条灰色历史线，旁边写：自动评价撤回。

应声补了一句：“只观察不进入验收项。”

周砚屏把这句话放到只观察入口的底部，字号比“不用说明为什么只看”还小。两行小字挨在一起，一行挡住解释压力，一行挡住评价压力。

小穹弹出第二个建议：观察次数可用于后续照看推荐。

景亭晚把这条也关掉。

“不推荐。”她说。

盛小满站在状态墙前，看见自己的那次只看没有变成完成，也没有变成推荐依据。她松了一口气，又有点不好意思。

“我只是看了一眼。”她说。

“那就只是一眼。”景亭晚说。

状态墙上的浅绿色小条消失后，温室没有少一项成绩。只观察入口仍然在，冷凝盘和空苗床也仍然可以被看见。撤回痕迹压在历史栏里，不像惩罚，更像给系统自己留的一次停手记录。

## 暂停中的光照排程

光照排程第二次暂停时，榫七先把提示调低。

提示原本在温室页中央，亮度太高，像在提醒所有人今天没有推进。罗衡看见后，把散热余量条取下来重新核对。维修坞应急位仍然贴着黄色边，低带宽陪伴窗口也没有多余空位。

“不补进度。”罗衡说。

榫七把“待补光照”删掉，改成：暂停中。

林问秋站在空苗床旁边，低头看测试线。上一章那一点低水量痕迹已经干透，苗床仍然空着。光照没有推进，水雾膜没有展开，未命名种子袋没有从暂存格里取出。

小穹问：“是否排入下一轮优先？”

罗衡摇头。

“下一轮也要看散热。”他说。

榫七把散热余量条挂回公共排程旁边。透明片上，温室那一格继续很窄。窄到不能容纳“补偿”，也不能容纳“追赶”。它只够写下暂停中三个字。

盛小满看着提示：“暂停也算今天做过的事吗？”

林问秋没有马上回答。她把可撤回浇灌令草案翻到背面，看见上一轮暂停记录还夹在低水量动作记录下面。两条记录都没有移进长期栏，也没有互相覆盖。

“算照看。”她说，“但不算推进。”

周砚屏把这句拆成两行，放到光照排程旁边：暂停是照看；不生成进度。

温室里的光没有改变。冷凝盘仍然暗一点，空苗床也暗一点。它们没有被照亮成一种快要开始的样子。暂停提示贴在散热余量条旁边，像一小片不急着亮起来的影子。

## 只观察也算照看

第四章收束时，宋清岚把本轮照看入口摊开。

页面上没有人名排名。最上面是只观察入口，旁边贴着“不用说明为什么只看”和“只观察不进入验收项”。再往下是下一轮可选入口，保留给今天没有上线的人。软刷旁边有对应 Agent 的等待提示，手套盒内侧那条灰线还在。光照排程仍然写着暂停中。

林问秋看了一遍，手指停在空苗床的记录上。

“没有播种。”小穹提示。

“对。”宋清岚说。

小穹没有继续生成下一步。它把“没有播种”压成一条状态，放在页面底部，和未命名种子袋暂存记录并排。

周砚屏把对应 Agent 的等待记录拖过来。应声在旁边确认，等待仍然不算失败，也不自动转成代办。

罗衡把光照暂停记录也拖过来，放在等待记录下面。他没有写补偿窗口，也没有写稳定光照。散热余量条的黄色边仍然贴着维修坞应急位。

叶简初把手套盒记录放到软刷旁。陈照野确认灰线仍然被保留，没有擦掉，也没有放大。

景亭晚最后放入撤回痕迹。那条“观察完成”自动评价已经不在状态墙上，只在历史栏里灰灰地躺着，证明系统曾经想过打分，又被按住。

宋清岚在页面中间写下四个并列小格。

只观察。

只刷尘。

只暂停。

只等待。

她没有给四个小格编号，也没有把它们排成从轻到重。林问秋把“照看入口”四个字写在最外侧，字号很小。小穹问是否生成照看人字段，宋清岚没有说话，只把字段关掉。

盛小满看着那四个小格，过了很久，才说：“那我今天算吗？”

宋清岚看向她：“你看过冷凝盘。”

“我没有做别的。”

“今天不用做别的。”

这句话没有进入公告。它只留在只观察入口背面，和撤回痕迹、等待提示、暂停光照排程放在同一页。

温室仍然没有播种。

四个小格旁边，空着人名的位置，也空着下一步的位置。
