## 本章任务句

本章要让“旧承诺材料的处理流程”发生，同时让共同体学会：材料可追溯不等于承诺被接住；接收人、执行资格和风险责任必须重新分开确认。

## 本章最低推进

- 从 `CH-054` 的“入口证据”退回待确认夹，不把它升级成旧承诺接收依据。
- 把旧承诺拆成三栏：材料 / 接收人 / 风险责任。
- 允许安全部分被替代班次处理，但不让替代班次替代关系。
- 让程望川的“先不接”成为有效状态，而不是拒绝共同体。
- 章末只得到：旧承诺材料保留追溯入口，接收人仍空白，执行资格仍未确认。
- 不处理完资产、私人习惯、空白握手记录和第一条草案。

## 场景切分

### CH-055 / 旧承诺拆成三栏

- 推荐 POV：罗衡。
- 前台动作：把待确认夹里的旧承诺页抽出来，另贴三栏纸，拆成材料、接收人、风险责任。
- 场景边界：材料可追溯，接收人留空，风险责任另行确认。
- 避免：不要用账本短句下判断，不要把 `CH-054` 的入口证据升级成旧承诺依据。
- 主要物件：三栏承诺表、待确认夹。

### CH-056 / 接收人空格

- 推荐 POV：宋清岚 / 小穹记录位。
- 前台动作：记录组试图补接收人，宋清岚提醒空格不能被好意填上。
- 场景边界：空格是有效状态；公共好意不能替当事人确认。
- 避免：不写投票、不写表决、不让旁听者代填。
- 主要物件：空接收人栏、铅笔边注。

### CH-057 / 替代班次不替代关系

- 推荐 POV：榫七维修安全位。
- 前台动作：安排替代班次处理旧承诺里的安全部分。
- 场景边界：替代班次只处理风险，不替回砂接住旧承诺。
- 避免：不要把替代完成写成承诺完成。
- 主要物件：替代班次卡、风险拆分表。

### CH-058 / 资产保管链复核

- 推荐 POV：林问秋 / 尺素。
- 前台动作：把旧资产、工具和材料分开复核。
- 场景边界：资产不随编号或身份链自动返还，只能按安全状态、保管链和当事人授权逐项打开。
- 避免：不写“返还名下”，不写工具权限回流。
- 主要物件：资产保管链、暂锁工具柜、旧模块接口盖。

### CH-059 / 公共账本只证明边界

- 推荐 POV：陈照野 / 留帧。
- 前台动作：把旧承诺材料旁的公共记忆改成边界证据。
- 场景边界：记录证明曾经等过、做过、记录过，不能证明现在该由谁接住。
- 避免：不要把公共记忆写成情感胜利墙。
- 主要物件：公共记忆、“不能证明”标记。

### CH-060 / 回砂不能自证

- 推荐 POV：榫七 / 回砂动作位。
- 前台动作：回砂尝试复述旧承诺，被保护性拦下。
- 场景边界：自述只能成为当前材料，不能自证身份、关系或旧义务资格。
- 避免：不写 Agent 权利宣言，不写自证身份。
- 主要物件：自述记录、未同步外层记录。

### CH-061 / 暂不接收被记录

- 推荐 POV：程望川 / 罗衡。
- 前台动作：程望川只说“先不接”，罗衡把它记录为有效选择。
- 场景边界：暂不接收不是拒绝共同体；承诺材料继续保留。
- 避免：不把沉默写成同意，不把老人推上台解释，不引导补签。
- 主要物件：空接收人栏、铅笔边注。

### CH-062 / 旧承诺没有接收人

- 推荐 POV：罗衡收束。
- 前台动作：收束三栏状态，未完成承诺继续保留追溯入口。
- 场景边界：材料保留，接收人和执行资格仍未确认；资产和私人习惯不处理。
- 避免：不让空格被温柔填满，不写公共承诺已经继承。
- 主要物件：三栏承诺表、待确认夹、空接收人栏。

## 行业反差

本章主方向：工单继承 / owner 归属 / 风险拆分 / 值班替补 / 审计证据。

转译要求：

- 工单 owner 空缺 -> 空接收人栏不补。
- 值班替补 -> 替代班次只处理安全风险。
- 审计证据 -> 公共记忆只证明边界。
- 权限继承 -> 暂锁工具柜和资产保管链逐项复核。
- 自述日志 -> 当前材料，不是身份或关系证明。

不要直接堆黑话；每场最多一个行业反差，术语后立刻落到物件动作。

## Agent 与规则边界

Agent 可以：

- 提供当前材料。
- 执行当前安全部分。
- 建议风险拆分。
- 等待、记录、停止自述。

Agent 不能：

- 自证身份连续、关系连续或旧承诺资格。
- 替程望川确认、接收、签名、握手、接纳、原谅或默认同意。
- 把入口证据、局部动作、当前能力局部可用、重新授权试验入口当作旧承诺接收依据。
- 把替代班次完成写成旧承诺完成。

## P0 / P1 风险

### P0

- 把身份链、公共账本、记录组或回砂自述写成旧承诺已被接收。
- 把程望川写成必须解释、必须接住、必须原谅或必须公开私人关系。
- 把第二章入口证据回收成测试通过、工具归还、权限恢复或关系恢复。

### P1

- 替代班次完成安全部分后，被叙事语气写成旧承诺完成。
- 空接收人栏被共同体善意、投票、旁听者或记录组补满。
- 公共记忆被写成情感胜利，而不是边界证据。
- 回砂自述过长，滑成 Agent 自证身份或权利宣言。

## CH-055 起写边界

- `CH-055` 只能开在“旧承诺材料可追溯，但接收人仍空白”。
- 第一动作建议：罗衡把待确认夹里的旧承诺页抽出来，另贴三栏纸。
- 第一栏写“材料”；第二栏先不写人名；第三栏写“风险责任另核”。
- 榫七可以确认安全风险需要处理，但不能确认谁接承诺。
- 贺南溪可递表或压住夹页，不做价值总结。
- 结尾停在空接收人栏被保留，不进入 `CH-056` 的补栏冲突。
