## 本章任务句

本章要让一次低风险普通工具复查在程望川局部允许、维修坞限流、记录组旁注的条件下发生，同时让共同体学会把“当前能力可重新校准”与“旧关系恢复”分开。

## 本章最低推进

- 从第一章“第一条旁出现小修订建议，议题成立但未解决”进入。
- 把议题从纸边移入一次低风险、单次、可撤回的普通工具重新授权试验。
- 章末只获得“重新授权试验入口”：回砂完成一次低风险普通工具复查，但旧资产、旧承诺和私人习惯仍在待确认夹。
- 不写成第一条通过、修宪完成、共同体共识、关系恢复、工具归还完成或旧承诺接收。

## 场景切分

### CH-047 / 待确认夹

- 推荐 POV：罗衡近距离视角。
- 前台动作：只做分栏登记：身份链、旧承诺材料、当前能力、资产保管、私人习惯。
- 场景边界：待确认夹是防丢和风险分栏，不是认领表；私人习惯栏允许空白。
- 避免：不要开会解释，不要把记录动作写成替关系归档。

### CH-048 / 工具柜暂锁

- 推荐 POV：程望川观察位。
- 前台动作：维修坞把旧工具权限暂锁，程望川看见没有人替他打开旧工具。
- 场景边界：暂锁是保护当事人控制权，不是惩罚回砂。
- 避免：不逼程望川表态，不写工具归还。

### CH-049 / 第一只手先空握

- 推荐 POV：榫七 / 回砂动作位。
- 前台动作：空握、停手、低风险标线。
- 场景边界：只验证基础态动作边界，不证明旧手感回来。
- 避免：不写成功感；许映舟 / 砾光如果出现，只能提醒“手感另测”，不能当权威裁判。

### CH-050 / 程望川选择旁听

- 推荐 POV：程望川门侧 / 旁听位。
- 前台动作：程望川只旁听，不公开私人习惯，不作证。
- 场景边界：不表态也被记录为有效选择；旁听不等于确认，沉默不等于同意。
- 避免：不要把旁听写成第一卷式“位置保留”安慰。

### CH-051 / 误差样本留下

- 推荐 POV：周砚屏 / 应声反馈位。
- 前台动作：回砂第一次动作偏轻，误差样本被保留。
- 场景边界：误差样本说明当前能力仍需校准，不证明关系失败，也不能写成恢复。
- 避免：不包装成纪念，不写“恢复中”。

### CH-052 / 普通工具局部授权

- 推荐 POV：程望川 + 罗衡。
- 前台动作：程望川只授权一次普通工具复查。
- 场景边界：授权单次、低风险、可撤回；不授权资产包和旧承诺。
- 避免：不要顺手解锁其他工具、资产或承诺材料。

### CH-053 / 空白握手记录仍空白

- 推荐 POV：回砂后退半步，程望川不伸手。
- 前台动作：空白握手记录继续空白。
- 场景边界：空白是有效状态，关系确认留给当事人。
- 避免：不要把后退半步写成戏剧化懂事，不让程望川被感动式接住。

### CH-054 / 第一只手没有接住全部

- 推荐 POV：罗衡收束。
- 前台动作：低风险动作完成，但工具授权到期，待确认夹仍保留旧资产、旧承诺和私人习惯。
- 场景边界：章末只得到重新授权试验入口。
- 避免：不写“小成功”“关系开始恢复”“第一只手被接住”。

## 行业反差

本章只选一个主方向：权限重开 / 灰度试用 / 单次授权。

写法要求：

- 把系统流程转译成老人可暂停、可撤回、不被催促的关系动作。
- 正文里落成柜门、授权条、停手线和一枚偏轻的误差样本。
- 不连续抛术语；如果出现“权限”“灰度”“单次授权”等词，下一句必须落到动作或物件。

## Agent 与规则边界

Agent 可以：

- 建议、限流、记录、等待。
- 执行低风险动作。
- 给出可理解的边界理由。

Agent 不能：

- 自证身份或旧关系。
- 替程望川确认私人习惯。
- 把通过测试写成旧手感回来。
- 自动拿回旧工具、旧资产、旧承诺。
- 把授权流程说成恢复流程。
- 用高风险任务证明自己。

## P0 / P1 风险

### P0

- 把身份链写成关系证明。
- 写成工具、资产、承诺自动归还。
- 让程望川被规则或共同体推着接住。
- 把低风险测试升级成高风险证明任务。
- 把本章写成 AI 权利宣言、投票、法庭、现实监管戏或制度胜利。

### P1

- 章末写成“小成功”“关系开始恢复”“第一只手被接住”。
- 误差样本被美化成胜利纪念物。
- `待确认夹` 语气太像流程验收，吞掉关系裂缝。
- 程望川旁听被误写成默认同意。
- 回砂表现太懂事，像完美陪护或完美信任修复对象。
- 行业反差黑话过密。
- 复用第一卷 `留灯`、`位置保留`、`下一次回应时间`、`三行提示`、`调字号` 作为情感收束。
