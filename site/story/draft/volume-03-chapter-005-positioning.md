## 本章任务句

本章要让低规格生活循环入口成立，但不把成立写成胜利完成。种子袋可以打开，第一枚种子仍不命名；第一格苗床只做低规格启动，水量、光照、散热、隔离托盘和撤回口令全部可暂停；霉斑样本片和未命名种子并列保留，温室不做开放日，低水量动作完成也只写本轮完成 / 下一轮仍可暂停。卷尾最多保留一格可继续照看的苗床、一份暂停中的光照排程和一只带灰尘的手套盒，生活循环入口成立，但生态自给没有完成。

## 本章最低推进

- 种子袋可以打开，但第一枚种子仍不命名，不成为希望符号。
- 第一格苗床进入低规格启动；水量、光照、散热、隔离托盘和撤回口令都可暂停。
- 霉斑样本片不收走，和未命名种子一起留在记录旁。
- 宋清岚取消温室开放日措辞，只保留相关人小范围复核。
- 一次低水量动作完成，但公共状态只写 `本轮完成 / 下一轮仍可暂停`。
- 第一格苗床旁仍保留空格，给暂停、失败或下一次选择留位置。
- 带灰尘的手套盒不擦成全新，重复照看的痕迹被保留。
- 卷尾只拥有一格可继续照看的苗床、一份暂停中的光照排程和一只带灰尘的手套盒。

## 场景切分

### CH-111 / 第一枚种子仍未命名

- 推荐 POV：陈照野 / 留帧。
- 前台动作：打开未命名种子袋，但第一枚种子仍不命名。
- 场景边界：打开袋口不等于命名，也不等于胜利符号成立。
- 主要物件：未命名种子袋、第一枚未命名种子、半合暂存格、空命名栏。

### CH-112 / 一格低规格苗床启动

- 推荐 POV：林问秋 / 尺素。
- 前台动作：第一格苗床只进入低规格启动。
- 场景边界：水量、光照、散热、隔离托盘和撤回口令全部可暂停。
- 主要物件：低规格苗床、低水量标记、光照排程、散热余量条、撤回口令。

### CH-113 / 霉斑样本旁的种子

- 推荐 POV：陈照野 / 蒲晓岑。
- 前台动作：霉斑样本片和未命名种子一起留在记录旁。
- 场景边界：风险不被收走，不写污染已解决。
- 主要物件：霉斑样本片、未命名种子、隔离托盘、并列记录栏。

### CH-114 / 温室不做开放日

- 推荐 POV：宋清岚 / 景亭晚。
- 前台动作：取消温室开放日措辞，只留小范围复核。
- 场景边界：温室不是展示窗口，生活设施不做公共宣传入口。
- 主要物件：开放日草稿、小范围复核条、撤回痕迹。

### CH-115 / 低水量动作完成

- 推荐 POV：林问秋 / 周砚屏。
- 前台动作：一次低水量浇灌完成。
- 场景边界：公共状态只写 `本轮完成 / 下一轮仍可暂停`，不写开始种植成功。
- 主要物件：低水量动作记录、公共状态条、下一轮暂停口令。

### CH-116 / 空苗床旁的一格继续

- 推荐 POV：尺素 / 盛小满。
- 前台动作：第一格苗床旁保留空格。
- 场景边界：可继续不等于填满；必须给暂停、失败或下一次选择留位置。
- 主要物件：空格、低规格苗床、下一次选择栏、暂停记录位。

### CH-117 / 手套盒没有擦净

- 推荐 POV：叶简初 / 陈照野。
- 前台动作：带灰尘手套盒不擦成全新。
- 场景边界：洁净不是一次性胜利，灰尘仍是下一次刷尘入口。
- 主要物件：带灰尘的手套盒、门侧记录、灰线照片。

### CH-118 / 一格可继续照看的苗床

- 推荐 POV：宋清岚 / 林问秋 / 罗衡。
- 前台动作：第三卷以一格可继续照看的苗床、一份暂停中的光照排程和一只带灰尘手套盒收束。
- 场景边界：生活循环入口成立，但生态自给没有完成。
- 主要物件：可继续照看的苗床、暂停中的光照排程、带灰尘的手套盒、空命名栏。

## 行业反差

本章主方向：minimum viable life-cycle / unnamed start / risk co-presence / non-public review / continuable maintenance。

转译要求：

- minimum viable life-cycle -> 低规格苗床启动，不是成熟温室。
- unnamed start -> 第一枚种子仍未命名，不做希望符号。
- risk co-presence -> 霉斑样本片和种子并列，风险不收走。
- non-public review -> 小范围复核，不做开放日。
- continuable maintenance -> 可继续照看，保留空格、暂停光照排程和带灰尘手套盒。
