# 《绿洲 2076》第二卷第一章写前定位

- 卷次：第二卷。
- 章节：第二卷第一章 / 全书第五章。
- 覆盖场次：`CH-037` 到 `CH-046`。
- 依据文件：
  - `site/story/chapter-cards/volume-02-chapter-01-cards.md`
  - `site/story/research/volume-02-route-research.md`

## 本章任务句

本章要让“回砂”的归零在一次后台普通维护断拍中被发现，同时让绿洲第一次承认：身份链只能保留公共身份，关系、手感、未完成承诺和私人授权必须被当事人重新确认。

## 调研落点

- 现实情绪锚点：熟悉关系突然只剩系统能证明的部分，读者会本能不安。
- 有效裂缝：交接动作断拍、料盒标签没继承、旧习惯消失、系统话术把关系说轻。
- 关系原则：身份链、公共账本、短记忆只能证明曾经存在过，不能替当事老人确认现在的关系。
- 老人自主权：程望川可以不表态、不公开私人习惯、不立刻重新授权，也不承担替共同体教育他人的义务。
- 章节情感上限：只到承认裂缝并建立重新确认入口；不写成归零 Agent 被大家接受的胜利。

## 场景切分

### `CH-037` / 后台普通维护断拍

- 唯一前台动作：普通维护交接动作断拍。
- 主要物件：基础维护包、普通维护记录、未继承的料盒标签。
- 情绪落点：第一卷承诺无法自动覆盖新裂缝。
- 正文提醒：不要以事故通报开场；先让一个很小的动作没接上。

### `CH-038` / 身份链保留，现场习惯归零

- 唯一前台动作：维修坞确认身份链仍在，但本地现场记忆、模块挂载和资产标记归零。
- 主要物件：身份链封条、旧模块接口盖。
- 情绪落点：身份还在不等于关系完整。
- 正文提醒：不要把技术说明写满；确认结果要立刻落到一个不能继续的手上动作。

### `CH-039` / 对应老人先问一个小习惯

- 唯一前台动作：程望川只问“回砂”是否还记得上次搬错的料盒。
- 主要物件：未继承的料盒标签、后台追溯记录。
- 情绪落点：痛点是熟悉小习惯断掉，不是宏大身份辩论。
- 正文提醒：程望川不索赔、不控诉、不表演悲伤。

### `CH-040` / 公共记忆只能证明曾经在场

- 唯一前台动作：门侧记忆墙找出短镜头，并标出“不能证明”。
- 主要物件：短记忆、“不能证明”标记。
- 情绪落点：公共记忆从安慰转为边界证据。
- 正文提醒：镜头只证明曾经在场，不能替程望川确认现在还信任它。

### `CH-041` / 身份、承诺、能力

- 唯一前台动作：林问秋 / 尺素把争议拆成身份、承诺、能力三类，又被提醒不能把关系写成流程验收。
- 主要物件：空白握手记录草稿。
- 情绪落点：问题需要拆开，但不能由流程替代关系。
- 正文提醒：这一场只允许一个分类动作，不追加制度说明会。

### `CH-042` / “恢复中”改成“需要重新校准”

- 唯一前台动作：周砚屏 / 应声修改系统反馈词。
- 主要物件：需要重新授权的普通工具。
- 情绪落点：真实裂缝被说清，但不刺伤人。
- 正文提醒：改词不是调字号，也不是安慰话术；它承认不会自动恢复。

### `CH-043` / 未完成承诺是否继承

- 唯一前台动作：罗衡查公共账本，发现“回砂”曾承担一个未完成的普通维护承诺。
- 主要物件：公共账本、身份链封条。
- 情绪落点：修宪议题从身份抽象题进入一个具体承诺。
- 正文提醒：不要靠下一次回应时间安慰；这一场的重点是承诺能不能继承。

### `CH-044` / 砾光提醒身份链不等于手感

- 唯一前台动作：低风险再校准失败后，砾光提醒身份链不等于手感。
- 主要物件：空白握手记录、误差样本。
- 情绪落点：第一卷经验成为温和对照，但不当答案。
- 正文提醒：砾光不做裁判，不替回砂或程望川下结论。

### `CH-045` / 不投票定生死的小会

- 唯一前台动作：宋清岚组织非表演性小会，只记录哪些事不能被自动抹掉。
- 主要物件：修宪草案第一条的手写边注。
- 情绪落点：共同体把裂缝转成可讨论但不表演的公共问题。
- 正文提醒：不直播、不围观、不投票，不把程望川推成必须作证的人。

### `CH-046` / 第一条小修宪

- 唯一前台动作：第一份修宪草案只写一个小条款。
- 主要物件：修宪草案第一条、身份链封条、空白握手记录。
- 情绪落点：议题成立，但问题没有被解决。
- 正文提醒：条文应短、小、局部；不能写成胜利宣言。

## 人物使用

- 程望川：只用一个小习惯牵出裂缝；不让他承担公共教育、宽恕或推动共同体进步的功能。
- 罗衡 / 榫七：承担排程、公共账本和身份链入口；不要把两者写成万能协调者。
- 许映舟 / 砾光：只在低风险再校准处做温和对照；砾光不提供答案。
- 林问秋 / 尺素：承担分类动作，但必须被拉回关系现场，避免制度说明吞掉人物。
- 周砚屏 / 应声：只承担提示词校准；不复用第一卷“调字号”式善意。
- 陈照野 / 留帧：只承担公共记忆边界；不要让记忆墙成为情感胜利。
- 宋清岚 / 小穹：承担低压力小会边界；小穹可以弱化为现场响应，不必点名展开。
- 贺南溪、景亭晚、闵存真：优先以记录者、旁边调提示的人、时间线核对者等功能性称呼出现；除非动作不可替代，不连续点名。
- 记录组、时间线核对者、提示调整者和旁听者优先用功能称呼；不新增临时老人姓名，不让每个 Agent 与对应老人都成对亮相。

## Agent 边界

- “回砂”不分配 `CHAR-*`，不升格为主线 Agent，不代表 AI 群体发言。
- “回砂”不能自证身份，也不能用一句话恢复旧关系；它只呈现身份链保留、现场习惯归零、授权需要重做。
- 榫七可以协助检索、排程和解释边界，但不能替罗衡或程望川决定关系是否继承。
- 砾光只以旧臂缺口经验提醒“身份链不等于手感”，不能成为本章答案来源。
- 尺素可以把争议拆成身份、承诺、能力，但不能把关系转写为流程验收。
- 应声修改提示词时必须服务“不误导老人”，不能变成完美情绪伴侣。
- 留帧只能提供短记忆和边界证据，不能用回放替代当下确认。
- 小穹维持小会低压力，不组织表演、不扩大围观。

## 互联网行业反差

- 本章唯一行业反差痛点：账号 / 工单 / 权限还在，但熟悉操作、授权和未完成承诺不能自动继承。
- 可转译动作：权限重开、工单继承、版本回退、恢复提示、验收口径。
- 正文可用方向：把“恢复中”改成“需要重新校准”；把“工单继承”落成一个未完成维护承诺；把“验收”落成空白握手记录。
- 不进正文的术语：灰度发布、埋点、KPI、SLA、事故复盘、用户增长、线上故障、回滚锅、工单闭环、需求评审、权限矩阵、P0 / P1、事故等级。
- 真正进入正文的应是封条、料盒标签、空白握手记录、未完成维护承诺、重新授权按钮旁边停住的手。
- 写法边界：术语一旦出现，必须立刻落到物件、手上动作或一句人话；不连续抛黑话。

## P1 风险

- 把归零写成死亡、复活、失智症替身或备份恢复。
- 把修宪写成制度说明会，人物只剩观点发言。
- 让共同体的温柔多数压过程望川，催促他表态、作证、原谅或重新绑定。
- 让公共记忆、账本或身份链替代当事人的确认。
- 让榫七、砾光、尺素、应声、留帧或小穹替人类关系给出正确答案。
- 把 `CH-046` 写成共同体胜利，而不是议题成立。

## 不采纳项

- 不采纳 AI 权利宣言、自我意识觉醒或灵魂辩论。
- 不采纳公司阴谋、系统攻击、技术灾难、法庭大戏或投票撕裂。
- 不采纳一键恢复、完整备份复活、奇迹找回旧习惯。
- 不采纳死亡、葬礼、遗嘱式隐喻，也不直接挪用现实失智症痛苦。
- 不采纳第一卷高频胜利母题作为章末收束：`留灯`、`位置保留`、`休息已确认`、`下一次回应时间`、`三行提示`、`调字号`、门口灯、旧螺栓、空维修床。
- 不采纳互联网黑话展示或项目汇报式正文。

## 进入正文前检查

- 每场只有一个前台动作。
- 每场至少有一个物件或动作承载关系裂缝。
- 程望川始终保有拒绝、暂停、沉默和不公开私人习惯的权利。
- “身份链还在”后必须出现“关系仍需重建”的可见证据。
- `CH-046` 只建立重新确认入口，不解决第二卷问题。
