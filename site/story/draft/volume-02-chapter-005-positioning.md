## 本章任务句

本章要让共同体学会用未完成的规则生活。第一条仍不正式通过，只进入一次窄范围、低规格、可暂停、可撤回的铅笔条款试运行；卷尾最多给一个有限重新协作入口，不给制度胜利。

## 本章最低推进

- 第一条从手写边注移动到草案正文，但仍用铅笔标注试运行，不编号、不盖章、不公告。
- 将条款拆成材料追溯、工具授权、资产保管、能力校准、私人习惯五层；每层都能暂停和撤回。
- 只开放一个低风险试运行窗口，不同步所有 Agent 或外层记录。
- 系统提示只能说明试运行中、可暂停、可撤回，不能写恢复、通过、完成。
- 给出一次有限托付：新的排气阀复查夹 / 单次授权条；不恢复旧资产包，不接收旧承诺。
- 保留一次误认并撤回：材料可追溯不等于关系已确认。
- 复盘不投票、不庆祝、不公告，只确认下一次仍可暂停。
- 章末只得到一个有限重新协作入口；修宪仍未完成，第一条仍未通过。

## 行业反差

本章主方向：sandbox / pilot / feasibility trial / consent withdrawal / privacy by design。

转译要求：

- sandbox / pilot -> 低规格试运行窗口，不是正式通过。
- feasibility -> 看能不能继续、哪里会误认，不是宣布成功。
- consent withdrawal -> 每层都能暂停和撤回。
- privacy by default -> 默认不公开、不外层同步、不把私人习惯纳入条款。
- risk management -> 暂锁、单次授权、错误留痕和人工复核。

每场最多一个行业反差，术语后必须落到纸、页角、窗口、锁柜、夹子、提示和撤回记录。

## Agent 与规则边界

Agent 可以：

- 在一个低风险窗口内执行单次授权动作。
- 识别试运行提示。
- 等待暂停和撤回。
- 保留错误痕迹为警示。
- 在未盖章草案边界内协作。

Agent 不能：

- 把试运行当成正式通过。
- 把材料追溯、工具授权、资产保管、能力校准或私人习惯互相替代。
- 用自述、公共记忆、备份或旧动作页证明关系确认。
- 把一次有限托付扩展成长期权限、旧资产恢复、旧承诺接收或关系复原。
- 把 `CH-070` 的局部小习惯变成规则样本。

## P0 / P1 风险

### P0

- 第一条通过、盖章、编号、生效或正式公告。
- 试运行窗口扩展到所有 Agent / 外层记录 / 工具资产。
- 材料追溯、一次托付、局部授权或私人习惯被写成关系确认、同意、作证、旧承诺接收或原谅。

### P1

- 把试运行写成制度胜利、共同体成熟表彰或剧场式收束。
- 把撤回记录写成责备人，而不是保留误认。
- 让回砂用解释性独白完成“学会可撤回”。
- 用抽象政策语言替代物件动作。
