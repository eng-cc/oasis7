## 本章任务句

本章要让温室从一次可撤回低水量动作退回到更低压力的“只观察”边界。共同体设置只观察入口，保留不上线者的下一轮可选入口，让 Agent 在门口等待刷尘指令，让程望川在冷凝盘旁的沉默不被写成确认或拒绝；带灰尘的手套盒留在门侧，景亭晚撤回“观察完成”的自动评价，光照排程第二次暂停。章末确认只观察、只刷尘、只暂停和只等待都可以是照看，但温室仍未播种，也不生成照看资格。

## 本章最低推进

- 温室门侧出现只观察入口，老人可以只看冷凝盘和空苗床。
- 原本要观察温室的老人当日不上线；公共排程不补缺席原因，只保留下一轮可选入口。
- 对应 Agent 在门口等待刷尘指令，等待不被标成任务失败。
- 程望川站在冷凝盘旁但不说回砂，罗衡不替他记录确认或拒绝。
- 带灰尘的手套盒保留在门侧，洁净被写成重复动作而不是一次性达标。
- 景亭晚撤回“观察完成”的自动评价，只观察不进入验收或绩效链。
- 光照排程第二次暂停，暂停被写作照看的一部分，不写温室推进。
- 章末温室仍未播种；只观察、只刷尘、只暂停和只等待都算照看入口。

## 场景切分

### CH-103 / 只观察入口

- 推荐 POV：宋清岚 / 小穹。
- 前台动作：在温室门侧设置只观察入口。
- 场景边界：只观察不报名、不解释、不证明自己会养。
- 主要物件：只观察入口、冷凝盘、空苗床、入口窄栏。

### CH-104 / 不上线也留在排程外

- 推荐 POV：罗衡 / 小穹。
- 前台动作：一位原本要观察温室的老人当日不上线，排程只保留下一轮可选入口。
- 场景边界：不上线不被填成缺席原因，也不被写成失约。
- 主要物件：公共排程、下一轮可选入口、空缺席原因栏。

### CH-105 / Agent 等待刷尘指令

- 推荐 POV：周砚屏 / 应声。
- 前台动作：对应 Agent 停在温室门口等待刷尘指令。
- 场景边界：等待不是任务失败，也不是老人拖累温室。
- 主要物件：温室门口软刷、等待提示、停步线。

### CH-106 / 冷凝盘旁的沉默

- 推荐 POV：罗衡 / 程望川旁证位。
- 前台动作：程望川站在冷凝盘旁但不说回砂，罗衡不把沉默写成确认或拒绝。
- 场景边界：沉默不产生证词，不替代同意，不恢复旧关系。
- 主要物件：冷凝盘、未记录格、沉默旁注。

### CH-107 / 手套盒里的灰尘

- 推荐 POV：叶简初 / 陈照野。
- 前台动作：带灰尘的手套盒被保留在门侧。
- 场景边界：灰尘是重复动作的提醒，不是脏、失败或责任归属。
- 主要物件：带灰尘的手套盒、尘样格、门侧记录。

### CH-108 / 观察不生成评价

- 推荐 POV：景亭晚 / 应声。
- 前台动作：撤回“观察完成”的自动评价。
- 场景边界：只观察不是验收项，也不是绩效。
- 主要物件：自动评价条、观察记录、撤回痕迹。

### CH-109 / 暂停中的光照排程

- 推荐 POV：罗衡 / 榫七。
- 前台动作：光照排程第二次暂停。
- 场景边界：暂停不等于失败，也不触发加速补偿。
- 主要物件：光照排程、暂停提示、散热余量条。

### CH-110 / 只观察也算照看

- 推荐 POV：宋清岚 / 林问秋 / 周砚屏。
- 前台动作：把只观察、只刷尘、只暂停和只等待并列写入本轮照看入口。
- 场景边界：温室仍未播种，不写资格、不写稳定、不写章级胜利。
- 主要物件：只观察入口、温室门口软刷、暂停中的光照排程、带灰尘的手套盒。

## 行业反差

本章主方向：observer-only access / optional participation / idle-state tolerance / no automatic scoring / paused schedule as care。

转译要求：

- observer-only access -> 只观察入口，不是报名或验收。
- optional participation -> 下一轮可选入口，不补缺席原因。
- idle-state tolerance -> Agent 等待刷尘指令，不报任务失败。
- no automatic scoring -> 撤回“观察完成”，不生成绩效或资格。
- paused schedule as care -> 暂停中的光照排程也是照看，不是温室推进。

## 正文开头提醒

不要从“第三章已经允许浇灌，所以第四章该推进温室”开头。建议从冷凝盘旁多出来的一条窄入口写起：入口不是给想报名的人，而是给只想看一眼冷凝盘和空苗床的人；第一段就让“只观察”成为动作，而不是旁观或犹豫。
