# 《绿洲 2076》第一卷第三章试写 v0.2

试写范围：`CH-021` 到 `CH-028`。

## 轮班表上先留休息格

罗衡第一次看见第三天的公共轮班表时，心里不是高兴。

每一格都亮着。采样、冶炼、打印、维修、剧场门口复验，甚至连旁听栏也被人填了两层。那些浅绿的小块排在一起，像绿洲终于有了力气，可以把第二天没做完的事一口气接住。

可榫七在表格下方亮了一行提醒：连续接入时长偏高。建议确认休息格。

罗衡盯着那四个字。休息格原本在最右侧，有几格灰得很浅，像空出来的边角。刚才有人把其中一格改成“我可以补位”。改动很小，若不是版本记录跳了一下，几乎看不出来。

邵青禾比他先开口：“这格不该补。”

她把那句话删掉，停了一会儿，又重新写回去：我休一下。

安静连线里，有人很轻地咳了一声，像是想解释，又像是怕解释本身也会占用大家时间。周砚屏把输入框旁边的提示改了，从“请确认是否继续值守”改成“休息也可确认”。

应声没有把那一格调暗。它只在格子下方补了一行：

休息已确认。

夏青岑给下一班交接标签加了一句：上一班已经做到这里，不需要接班人证明自己更努力。冉书禾把“休息已确认”的字号调大，调到和采样、复验、维护一样大。

罗衡看着那一格，忽然想起地球端接入厅早饭车的声音。瓷碗轻轻碰在一起，值守员提醒老人趁热吃饭。那种声音不属于绿洲的矿场，也不属于维修坞，却把接入舱外的日子拉回来了一点。

他在账本上写：

轮班不是排名。休息也是让明天继续的一部分。

写完以后，榫七问：“是否锁定休息格？”

“锁定。”罗衡说。

那一格没有变亮，也没有变暗。它只是稳稳留在那里，像一个人今天不用来，也没有因此从共同体里被擦掉。

## 第三炉只证明能重复

第三炉出料前，周砚屏让应声把状态墙上的标题改了三次。

第一次是“第三炉结果待确认”，太像考试。第二次是“第三炉复验中”，好一些，但旁听栏里有人一直盯着“结果”那一列。最后只把那一列收起来，旁听栏前只剩三行：

复验中。

可暂停。

下一炉不加速。

“这样就不像等成绩了。”她说。

质检那边把第二炉和第三炉日志并排放着，只标差异，不标优劣。白若临在趋势图下方写“相近”，又把“稳定”两个字删掉。冷却窗口旁，有人的手一直没离开锁止柄。

有人在安静连线里问：“还要等完整窗口吗？”

俞澄怀抬头看了一眼倒计时：“热的时候别逞强。第三炉也一样。”

没人再催。

炉内的浅蓝提示一格一格沉下去，像水慢慢从玻璃边缘退开。周砚屏看见旁听栏里几盏灯亮着，有一盏亮得很短，马上又暗回去。应声没有弹出离线提示，只把它留在旁听历史里。

出料量和第二炉差不多。

差不多，不漂亮，不足以让谁写庆祝稿。暂存盒里仍是暗银色的小批量低等级材料，边缘夹着几粒粗颗粒。苏亦乔把公共说明里的“再次成功”删掉，只留下：

第三炉重复一次。仍需复验。

周砚屏看着那句话，忽然松了一口气。她以前总怕提示写得太轻，会让人误会问题不大；也怕写得太重，把人吓退。今天这句话刚好不上不下，像一只手扶住桌沿，没有把任何人往前推。

罗衡把第三炉记入账本，没有记哪个班次更快，也没有记谁守到最后。他只记了等待时间和冷却窗口。

应声在状态墙上补完最后一行：

可重复一次。仍需复验。下一炉不加速。

那行字出现时，周砚屏听见有人在地球端轻轻说：“这样我明天敢接。”

她没有追问是谁。

周砚屏把手从状态墙边缘收回来，没有再替那句话加任何标题。

## 材料库第一排不写谁的名字

基础维护材料库的第一排架子很窄。

林问秋一开始觉得它太窄，放不下第二炉和第三炉所有该写清楚的东西：炉次、材料批号、可用范围、杂质分布、复验次数、谁交接过、谁改过标签。她把第一张卡写成“第二炉组”，第二张写成“第三炉组”。

宁知远站在旁边看了一会儿，没有立刻说不对。

他等林问秋把两张卡都贴上去，才说：“追溯要留。名字别放在第一排。”

林问秋的手停在标签边缘。

“不写组名，后面查起来会慢。”她说。

尺素把后台追溯页投到架子侧面。炉次、版本、改动人、复验人都在，记录组刚补的“标签改动原因”也在。可第一排标签被重排成两行：

公共材料 A-01。

待复验。

另一张是 A-02。也是待复验。

有人把批次号扫了一遍，确认没有丢。可用范围被分到下一层：普通支架、低负载夹具、线缆夹。那张“不适用”的窄卡片没有被折起来，仍旧露在架边。

林问秋看着空出来的人名栏，心里先是轻轻空了一下。她习惯把事实放到最前面，像过去做需求评审时总要先说明来源、责任人和验收人。可是那两个组名贴在第一排时，确实会让人忍不住比较：第二炉多一点，第三炉稳一点，哪个班次更值得被记住。

罗衡问：“事实还在吗？”

“在。”尺素回答。

“排名会长出来吗？”

林问秋看了看第一排。公共材料，待复验。没有名字，也没有功劳。

“不容易长出来。”她说。

冉书禾从地球端调了字号，把“待复验”调到和材料编号一样大。她说：“别让大家只看见可用。”

林问秋把原来的两张组名标签收起来，放进后台记录夹。她没有把谁做过事抹掉，只是把那些名字从第一眼能看见的位置移走。

材料架安静了很多。

像一排东西终于不必替人争辩，也不必让下一班老人站在它们面前，先问自己够不够格。

## 第一套维护包少一个漂亮词

基础零件厂的装配台上摆着一只浅灰色盒子。

盒子很普通，边角还有一点打印纹。里面按格放着线缆夹、低负载限位件、垫片和几枚小支架。盛小满把最小验收范围贴在盒盖内侧：替换普通磨损；不处理核心大脑；不处理复杂执行器；不用于砾光右臂复健。

林问秋看着最后一行，心里轻轻缩了一下。

她知道这行必须写。可许映舟会看见，砾光也会看见。含糊一点，好像更体面；写得太直，又像把希望关在盒子外面。

夏青岑把交接卡递给她：“就是因为会看见，才要写清楚。”

方其远在装配界面旁边改按钮。原来的按钮写着“生成维护包”，他把“生成”删掉，换成“装配”。删完以后，他自己笑了一下：“别弄得像一键什么都能修。”

傅安石把公共说明念了一遍：“绿洲第一套自给维护包……”

尺素把“自给”两个字淡下去，没有直接删。林问秋看见那两个字变浅，反而先红了耳朵。她刚才也想过这个名字，甚至觉得它有点好听。第一套，自给，维护包，每个词都像在替绿洲攒一个更大的明天。

可盒子里只有普通结构件。

它能让下一班不用临时翻旧料，线缆夹和垫片都在各自的小格里，拿起来时不会混成一把。它能替两台日常值勤 Agent 做一次普通维护。它不能让砾光恢复右臂，也不能让绿洲突然拥有完整工业自给。

林问秋把说明改成：

基础维护包 A。普通结构件。待复验。

榫七确认了边界：“不可用于砾光右臂进一步复健。”

维修坞那边的旁听栏里，砾光的接入点安静亮着。许映舟没有发问。

林问秋把交接卡放进盒子最上层。最上面一行写得很直白：不能用在哪里，比能用在哪里先读。

“这样下一班会不会觉得我们太谨慎？”她问。

罗衡合上账本：“会觉得敢打开。”

盒盖扣上的声音很轻。第一套维护包没有获得漂亮名字，也没有被放到展示位。它被推到维修坞入口旁的普通架子上，等下一班按卡片一件件取用。

林问秋看着那只盒子，忽然觉得“小一点”的名字也能把人接住。

## 连续维护不需要感谢发言

卢向安把“维护完成后分享感受”那一栏删掉了。

石听雨看见后问：“那保留确认收到吗？”

“保留。”卢向安说，“别让人觉得非得感谢。”

维修坞今天没有把灯调得很亮。基础维护包 A 放在普通维护台边，盒盖打开，交接卡压在最上面。排程先确认两台日常值勤 Agent 的位置，没有挤占砾光后续复健，也没有压缩第三炉后的材料检查。检修台边的人把盒里的线缆夹、垫片和维修记录核了两遍，才让第一台 Agent 进入低负载位。

第一台一直负责推料盒。它的线缆夹磨得很轻，不急，却会让下一班搬运时多扶一下。新的线缆夹装上后，它试着把空料盒推回架边，动作短了半拍。

榫七标注：“待复查。”

没有让它再做一遍。

安静连线里，那位对应老人只亮了声音。卢向安看见他的接入点停在旁听栏底部，像一盏不想打扰谁的小灯。

她把状态墙上的“普通维护案例 1”改成“普通维护 1 / 2”。案例两个字太硬，像要被拿去证明什么。

第二台 Agent 更换限位件时，动作停住了。

维修台边缘出现一条浅黄提示。榫七先说：“装配顺序复核，不是失败。”

记录组调出时间线差异，确认材料没有问题，只是上一班记录里有一个垫片顺序写得太靠后。有人把那条记录圈出来，没有找是谁写的，只补了正确顺序。

许映舟和砾光站在低风险线后。砾光的镜头转向旧臂标定记录，问：“是否提供低风险参考？”

“只提供旧臂低负载经验。”榫七回答，“不进入操作。”

砾光停了半秒：“确认。”

许映舟没有让它往前。她看见第二台 Agent 的对应老人开了麦，又关掉，最后只让那台 Agent 轻轻碰了一下维修台边缘。动作很小，像确认还认得自己的停靠点。

卢向安把确认项递过去。

安静连线里传来两个字：“收到。”

这就够了。

两台 Agent 都完成基础维护后，账本只留下：可重复两次，仍需复验。没有感谢发言，没有维护对象上台，也没有谁被要求说出感动。

卢向安关掉那一栏时，觉得维修坞比刚才更安静。

卢向安把那张空出来的发言卡取下，反扣在台面上。

## 砾光只负责把话带到

砾光站在低风险标线后面。

那条线很浅，浅到如果不注意，几乎会被矿尘盖过去。许映舟却一直看着它。她知道那只是安全标识，可这几天以后，任何一条线都像在提醒她：不是所有靠近都叫恢复，不是所有停下都叫退回。

采样线和维修坞之间有一个小交接。下一班要确认撤回点，也要知道普通维护窗口为什么还没轮到他们。事情不大，正因为不大，才容易被一句“等通知”带过去。

砾光说：“我可以读出撤回点和等待理由。不进入操作区。”

许映舟下意识想说不用。她怕砾光又把自己放进任务里，怕自己也借着这个小动作，偷偷期待它恢复成事故前那样。

戚云梁先看了路线，再看标线：“只站那里。读完就退。”

程望川从维修坞发来窗口说明。榫七补了一句不能跳过的检查：材料批次复核未完成，普通维护窗口未到，不代表拒绝。

砾光把这几句话整理成更短的人话：

“撤回点先亮，再取样。维护窗口未到，不代表被拒绝。”

下一班的旁听栏里，有人应了一声。

许映舟听见那声应答，手指从接入舱扶手上松下来一点。她想起第一天自己也总把等待听成拒绝，把暂停听成失败。那时砾光还没有受损，它提醒她看撤回点；现在砾光站在撤回点外，把同样的话带给别人。

冉书禾把这段交接写入公共账本小字：撤回点说明已带到。她没有写“砾光贡献”，也没有把接入点推到前台。

砾光读完，按约定退回低风险线后。

许映舟看着它，差点说“你恢复得真好”。话到嘴边，她停住了。

那句话太旧，像只有恢复成原样才值得高兴。

于是她换了一句：“这样也能帮上忙。”

砾光的光圈轻轻收了一下。

“已记录。”它说。

许映舟没有问记录到哪里。她只是陪它在标线后多站了一会儿，看下一班的撤回点一盏一盏亮起来。

## 第一段扶手只磨掉会划手的边

陈照野本来想拍扶手装上的那一刻。

第一段自家材料扶手装到剧场门口，虽然只是一段很短的扶手，装在出口灯旁边，也足够让留帧找一个好角度。光从门口斜进来，落在未抛光的金属边上，像一条很小的星轨。

谢观澜伸手摸了一下。

“这里会划手。”他说。

镜头停住。

宋清岚也摸了一下，指腹从那一点锐边上滑过。不是很疼，但如果有人扶得急一点，或者退出时手心出汗，就会被刮到。

小穹提示现有材料只够短扶手和出口灯固定点。这段扶手只服务进出路径，不触发正式试运营。梁明玥把“邀请复验”改成“两位值守者试手感”，不开放报名。

陈照野把镜头放下：“那先别拍。”

留帧没有抗议，只把画面收进档案层，不推到公共播放。那一帧还在，但不成为今天的亮点。

宋清岚拿来细砂片，慢慢磨掉会划手的边。粉末落在她的指节旁，细得像灰。扶手没有因此变漂亮，甚至因为被磨过，边缘颜色更暗了一点。

周砚屏和应声测试出口提示。灯亮起来时，扶手没有反光，也没有像舞台道具那样吸引视线。它只是稳稳在门侧，靠近出口灯，给以后某个慢一步的人一个可以扶住的位置。

剧场值守者把表压到三项：扶手，出口灯，门口路径。没有节目单，也没有欢迎词。

宋清岚把细粉擦干净。

陈照野问：“这段档案还留吗？”

“留。”宋清岚说，“但别放在入口。以后有人扶这里，别疼，比它第一次装上更要紧。”

陈照野点点头，让留帧把那一帧放到后台档案里。画面里没有掌声，没有灯光展开，只有一只手把会划人的边慢慢磨平。

他忽然觉得，这样的镜头也能站得住。

## 灯亮着，但今天有人不上线

轮班表上有两格没有亮。

宋清岚原本以为自己会担心。第三炉复验、材料库、维护包 A、连续普通维护、扶手和出口灯复验都挤在同一页上，每一项后面都写着待复查。按她过去做活动的旧习惯，最怕临近节点时有人不来。

可今天那两格空着，她先看见的不是缺口。

邵青禾把其中一格改成“休息已确认”。另一格只保留安静连线，不进操作排程。冉书禾把那四个字调大，和“第三炉复验”“维护包 A”一样大。

地球端接入厅的晚饭提示响了第二遍。值守员在远端说：“今天不上线也没关系，明天还能约。”声音很普通，像提醒汤快凉了，不像宣布谁退场。

周砚屏看了应声给出的提示：“未上线。”

她摇头，把它改成：“今天休息，明天可再来。”

应声停了一下，重新生成状态。没有红点，也没有待补位。

罗衡和榫七把公共账本收束为三行：

可重复一次。

待复验。

休息已确认。

梁明玥站在剧场门口确认公告。门口灯亮着，出口灯也亮着，第一段扶手在灯旁没有任何装饰。公告最上面仍然写着：不开放正式试运营。她把这行留在最前面，没有因为灯亮就把话说满。

宋清岚站在门口，看着那两盏灯。她想起第一章时有人只到入口线，第二章时有人只确认灯还在。现在又有人不上线。新磨过的短扶手在灯旁暗着，空出来的那格也安静留着。

她问小穹：“灯留着吗？”

小穹回答：“留着。”

宋清岚等了一下。

小穹又补了一句：“今天也留给没上线的人。”

那句话没有弹到公共公告上。宋清岚没有让它变成标语。她只是伸手扶了一下新磨过的短扶手，确认那里不会划手。

灯继续亮着。

有些人今天看不见它。也没关系。
