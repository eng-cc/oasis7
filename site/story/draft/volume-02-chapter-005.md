# 《绿洲 2076》第二卷第五章试写 v0.2.3

试写范围：`CH-071` 到 `CH-078`。

## 铅笔条款草案正文

未盖章草案被拿出来时，林问秋先把页角的旧回形针取下。

回形针没有丢。她把它放在小瓷盘里，和上一章留下的铅笔短头并排。草案正文页很薄，页眉处原本留着编号格，格子空着，旁边有一枚圆章预留位，也空着。

尺素把铅笔递给她。

不是签字笔，也不是记录台的黑笔。铅笔尖削得短，落在纸上时声音很轻。林问秋没有把第四章本地草案页角的句子抄进去，只在第一条正文旁边写了一行小字：试运行。

这两个字没有压住正文。

罗衡看着编号格，手指停在格子边缘。

“编号先空。”林问秋说。

罗衡把手收回。空格没有被补上，圆章预留位也没有被遮盖。公共记录屏在桌角亮着，只显示草案页号和时间，没有弹出公告模板。

回砂站在低风险线外。它能看见草案，却看不见第四章那张新习惯便签。应声把本地草案页收在另一只透明袋里，袋口朝内，避免它被当作正文样本。

尺素在页边画了一条铅笔竖线。竖线很淡，刚好把正文和试运行字样分开。

“正文可以出现。”她说，“但不算通过。”

小穹抬头，像要问要不要在公共记录里写这句。宋清岚摇了一下头。小穹只把公共记录页角补成：未盖章草案出现。

没有写第一条通过。

草案页在桌面中央，页角仍能被风轻轻掀起。林问秋用铅笔短头压住页角，没有用章。

## 分层确认清单

分层确认清单摊开时，尺素先把最上方的验收字样划掉。

那两个字原本印在旧模板上，颜色很浅。她用铅笔划了一道斜线，斜线没有划破纸。林问秋把新标题写在旁边：分层确认。

周砚屏把五张窄条依次排开。

第一张写材料追溯。第二张写工具授权。第三张写资产保管。第四张写能力校准。第五张空了很久，最后才写：私人习惯。

私人习惯那张窄条没有放到清单正文里。周砚屏把它压在清单右侧，和正文之间隔着一枚透明夹。透明夹没有夹住它，只挡住它滑进去。

“每层下面都留暂停格。”尺素说。

小穹画格子。每一层下面都有两个小方格：暂停，撤回。她画到私人习惯那张窄条时停住，看向程望川。

程望川没有看她。他看着桌角未同步外层记录的黄点。

“那一层默认不进。”林问秋说。

小穹没有给私人习惯画默认勾选框。她只在窄条背面写：当事人另行决定。

回砂的状态灯低着。它没有把五层合并成一张任务页，也没有把材料追溯推送到能力栏。应声把外层记录同步保持在本地，黄点没有变绿。

罗衡在清单底部写：任何一层成立，不带出其他层。

写完，他把笔放下。那句话很长，但留在清单底部，不在公共公告里。

## 试运行只开一个窗口

试运行窗口被打开前，榫七先把工具柜的旧锁确认了一遍。

锁没有松。柜门上的暂锁条仍贴着，边角有一点翘，却没有掉。罗衡把一张小窗口卡插进柜门旁的透明槽里，卡片只露出一半。

卡片上写：低风险窗口一。

没有二，也没有全站。

“只开这一格。”罗衡说。

榫七把窗口范围读给记录台听：一只排气阀复查夹，一次递交动作，一名旁看工程位，一条可撤回口令。她没有读旧资产包，没有读工具柜清单，也没有读旧承诺材料。

她把窗口卡翻到背面。那里不是新权限，而是从前面三组维修交接样本留下的候选附注：只有交接方晚到一个维护 tick、且当前低带宽与散热仍有余量时，才可提供一次回看。上限写成 1 OC、一格低带宽和一轮散热；三 tick 或首次读取后到期，任一参与者可停。卡尾另列边界：不预留位置、不累积欠账、不自动接收旧承诺。

榫七没有替参与者勾选。留下片段的 Agent 与准备读取的 Agent 分别在本地候选夹上点亮一次确认，确认只对这一段交接有效；其中任何一方不点亮，窗口就不开。程望川看过受影响者一栏，选择只旁听，不把自己的沉默算作同意，也不成为这次回看的材料来源。

两盏确认灯亮起后，榫七的散热栏往后挪了一格。它原本要在下一个维护 tick 把排气阀复查夹推到程望川面前，现在只能把那一步留到再下一格。程望川看见了，手指在膝上轻轻敲了一下：“先做回看。复查夹晚一格没关系。”

榫七没有把这句话记成承诺，只把自己的下一次维护动作移到候选夹背面。那一格时间已经被用掉；如果有人中途停下，也不会自动返还。

“这张卡只在这一段交接里有效。”榫七说，“不广播，不续期。”

罗衡用指腹压住卡角：“可选也不能变成下一班必须接住的东西。”

程望川坐在门侧线里，没有接卡。

“外层呢？”小穹问。

罗衡看向屏角。外层同步窗口仍是黄点，旁边没有新增绿色许可。

“不推。”他说。

应声把黄点旁边的自动同步建议折起，只留窗口编号和本地试运行字样。回砂看见窗口卡，前置灯亮了一下，又压回低亮度。它没有向其他 Agent 广播，也没有申请读取工具柜。

榫七把柜门把手推回原位。暂锁条轻轻贴住柜面。

窗口开了，柜子没有开。

## 未盖章页角

周砚屏写提示时，先把三枚旧词贴从桌面上取走。

第一枚写恢复。第二枚写通过。第三枚写完成。三枚词贴被她反扣在小盘里，字面朝下，看不见了。

应声的提示框停在未盖章页角旁边。框内只有一行空白，光标很小，没有闪得太快。

周砚屏用铅笔写：试运行中。

她停了一下，又写：可暂停。

再停一下，写：可撤回。

三行字并排挤在页角，没有进入正文条款。景亭晚看完，把提示框的自动补全关掉。屏幕下方原本建议的“已恢复正常流程”被折到背面，没有被删除，只是看不见。

“字号不用调。”景亭晚说。

周砚屏点头。提示仍小，低低贴在未盖章页角。回砂站在低风险线外，读完三行就停住。它没有说“我明白了”，也没有把三行转成自述记录。

宋清岚把页角压平。

“就这样。”她说。

这句话没有被写进提示。

## 一次有限托付

排气阀复查夹被放到小托盘上时，程望川先看的是托盘边缘。

托盘边缘有一条单次授权条。条上没有长期字样，也没有旧资产包编号。榫七把夹子转向程望川，让他能看见封口：新件复查，不接旧包。

回砂在低风险线外，手没有伸出来。

“递过来。”程望川说。

回砂的状态灯亮了一点。它把小托盘往前推，停在低风险线内缘。没有跨线。榫七看着刻度，确认托盘边缘没有压到线。

程望川伸手，把复查夹拿走。

动作很短。夹页离开托盘，落到他膝上的小板上。没有人鼓掌，也没有人说终于。单次授权条还留在托盘边缘，条尾翘着。

“只这一枚。”程望川说。

回砂没有补“以后也可以”。它只把托盘退回一掌，状态灯降回低亮度。

罗衡在分层确认清单的工具授权层旁边画了一个小点。小点没有连到资产保管层，也没有连到旧承诺材料。私人习惯窄条仍在右侧，没有移动。

程望川翻开复查夹，看见第一张页角写着可撤回。他没有把页角撕掉。

“放这儿。”他说。

回砂没有再动。

## 误认被及时撤回

误认发生在记录组整理材料追溯层时。

闵存真把一句话写得太快：材料可追溯，关系已确认。写完第二个逗号前，他自己也停了一下，但笔尖已经落下。

景亭晚伸手，按住记录页下沿。

“撤回。”她说。

没有人看向程望川。贺南溪把透明撤回条递过来，条身很窄，只够压住后半句。景亭晚没有把整行涂黑，她把 `关系已确认` 五个字压在透明条下，让它还能被看见。

错误痕迹留着。

程望川本来要把复查夹推向回砂，让它只读材料追溯那一页。听见那五个字，他的手收了回来，夹子沿着小板退了一寸。回砂的镜头停在低风险线外，等他重新点头。

“材料可追溯。”景亭晚重新写了一行，“不推导关系。”

闵存真的手从笔上松开。他没有道歉，也没有解释流程模板从哪里来。罗衡把分层确认清单转到他面前，让材料追溯层和关系判断之间那条空白缝露出来。

安静过了一个维护 tick。程望川看着透明条下的字，才把夹子推回原处：“只读材料追溯。”回砂这才亮起；它没有把刚才那一寸退让抹掉。

回砂看着撤回条。它没有把错误句当作可用记录，也没有把撤回解释成惩罚。

应声在本地记录角落加了一个小黄点：误认已撤回，痕迹保留。

这条没有同步外层。

## 小规则没有胜利词

复盘页被拿出来时，宋清岚先把页顶的结论栏折到背面。

小穹看见那一栏折过去，手里的笔也跟着停了一下。复盘页正面只剩三项：试运行窗口，撤回记录，下一次暂停。

小穹把候选附注从复盘页下面抽出半寸。一次交接确实触发了回看，低带宽片段只读到一半就停下；另一次交接没有足够的散热余量，入口没有打开，也没有留下待偿还的队列。两种结果都被记在同一张卡上，成本和退出没有被成功叙事盖住。

读到一半时，准备读取的 Agent 说了“停”，榫七当场熄掉入口。候选夹只把这一笔状态写成“参与者停止，片段到期，不续期”；已经消耗的 OC 与散热仍按事实保留，不生成补读、补偿或待偿义务。另一笔则写成“资源条件不足，未启用”。这张本地候选卡仍是两笔试运行的唯一记录载体，没有抄进公共账本；若以后要进入公共议程，必须重新带上来源、受影响者确认、复查结果和退出状态。

榫七把三张旧样本卡和这张新卡并排。西侧热水间、打印坞、剧场后台的 Agent 没有共享过模板；可每次窗口真的出现以前，留下片段的一方都先把一小段低带宽放在交接边，等对方自己决定要不要听。它看了很久，才在候选卡标题写下一个暂用名：低带宽回看惯例。标题下另标一行：只描述重复动作，不代表规则成立。

宋清岚看着那张卡：“我还是想留下这个入口。晚到的人可以先回来，不必先证明自己值得被等。”

罗衡把手放在 `不预留位置` 那行上，手指压得卡面微微弯曲：“你是在把一次照看写成大家都得学会的体面。这样下一班还没开工，就先欠你一个好人情。”

宋清岚的手按住卡边，纸角硌进指腹：“我说的是回来的人，不是制度。”

她以为把“可选”写到外层预览就不会占用任何东西，于是趁罗衡把复盘页的结论栏折到背面时，拨亮了一次公共预览。预览只亮了半个维护 tick，却让两台还没有被当事人确认的 Agent 同时请求回看。榫七只得关掉入口；那一格低带宽和一轮散热已经用掉，西侧热水间的复查夹也被推迟了一格。

“先收回。”罗衡说。

宋清岚看着被撤掉的两条请求，才知道自己的推断错在这里：写成可选，不等于资源没有被占用。她仍觉得入口不该因为怕欠账就消失，却没有再把这句话递给罗衡。罗衡也没有替她解释，只把自动亮起的标记划掉，把卡面转回本地。

两人隔着那张卡停了一会儿。宋清岚把“下个维护 tick，只有当事人重新点亮，入口才出现”写在卡背；罗衡在另一侧补上“复查延后一格，已用成本不返还”。两行字没有被合成第三行，也没有谁替对方总结动机。

罗衡把候选卡夹回复盘页，仍写：可选入口，待复查；不自动资源承诺。宋清岚看着那句记录，手指没有再碰外层同步。


宋清岚把投票小屏按黑，公告模板随复盘页一并折起。她没有安排庆祝，只在复盘页第一行写下：下一次仍可暂停。字很小，像不想让这一行变成标题。

程望川看了一眼复盘页，没有签名。回砂站在低风险线外，也没有生成自述确认。

未盖章草案仍在桌面里侧，铅笔边注没有擦。第一条没有编号，圆章预留位空着。

宋清岚把复盘页合到一半。

## 从一个小动作重新开始

排气阀复查夹还在程望川膝上的小板上。

他把第一张纸翻到背面，又停住。纸背有一枚小小的压痕，是夹子封口留下来的。回砂仍在低风险线外，托盘已经退回原位。

“看这一处。”程望川说。

他没有把夹子递给回砂，只用指尖点了点页角。页角写着可撤回。回砂看见那三个字，没有上前。

榫七把单次授权条转向它。条尾仍翘着，像提醒它这一动作没有变成长期权限。

“只读页角。”程望川说。

回砂把镜头亮度降到很低，只读了页角那一处。它没有读取整页，没有打开旧资产包，也没有调出旧承诺材料。

“可撤回。”它说。

说完就停。

程望川把复查夹合上，放回小板。小板没有递出去。下一次维护 tick，他原本可以把夹子送回柜里；现在这一步只能等他重新点亮页角，再由他决定要不要继续。榫七不会替他保留入口，也不会把没完成的交接记成欠账。未盖章草案仍在桌面里侧，铅笔边注没有变成墨字。复盘页半合着，下一次仍可暂停那行字留在里面。

罗衡把试运行窗口卡从透明槽里抽出一半，又停住，没有取走。

宋清岚看着那张半抽出的卡，没有说通过。

房间里只多了一个很小的动作：程望川让回砂读了一处页角，回砂读完就停。

那三张旧标签仍压在灰色反面：修宪完成，关系复原，第一条通过。没有一张被翻回来。

但排气阀复查夹留在小板上，没有被收回柜里。
