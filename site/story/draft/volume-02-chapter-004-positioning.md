## 本章任务句

本章要让“私人习惯是否应被共同体保存”成为前台冲突，并证明：重新协作可以从不公开、不解释、不作证、不立刻重新托付开始。私人关系可以重新长出新入口，但不必进入公共档案。

## 本章最低推进

- 从第三章的旧承诺无接收人状态进入私人习惯栏，而不是解决旧承诺。
- 程望川拒绝把私人小习惯放入公共待确认夹；拒绝被记录为有效边界，不是失败。
- 只允许一个动作被复现，不允许公共记录追问背后私密记忆。
- 旁听者只旁听，不作证；沉默和离场仍是有效选择。
- 一个新习惯可以被重新教给回砂，但明确不是从备份恢复，也不是旧关系恢复原样。
- 章末只得到：当事人局部确认一个新小习惯；公共档案只记录边界，不记录内容。
- 不处理完铅笔条款试运行、旧资产返还、旧承诺接收或第一条正式通过。

## 场景切分

### CH-063 / 小习惯不进入公共夹

- 推荐 POV：林问秋 / 程望川门侧。
- 前台动作：校准需要一个私人小习惯，待确认夹被推近，程望川拒绝把它放入公共夹。
- 场景边界：私人习惯不默认存在，也不默认公共化；拒绝不是不配合。
- 避免：不写成老人冷淡、拖延或共同体受挫。
- 主要物件：待确认夹、私人习惯空栏、遮挡纸。

### CH-064 / 只给动作不给解释

- 推荐 POV：程望川 / 榫七动作位。
- 前台动作：程望川只允许复现一个动作，用小型力矩扳手给出角度、停手点和撤回口令，不解释记忆。
- 场景边界：记录动作边界，不追问含义；能力训练不等于关系确认。
- 避免：不让记录组追问，不把动作写成私密内容泄露。
- 主要物件：小型力矩扳手、动作边界卡。

### CH-065 / 旁听不作证

- 推荐 POV：宋清岚 / 旁听席。
- 前台动作：贺南溪、景亭晚和闵存真旁听一致性复核，宋清岚把旁听记录限制在到场和离开。
- 场景边界：旁听只证明有人在场，不证明认可；沉默不是同意。
- 避免：不使用“位置保留”作为情感收束，不让旁听者替程望川作证。
- 主要物件：旁听记录、未同步外层记录。

### CH-066 / 私人习惯可重新教

- 推荐 POV：程望川 / 回砂动作位。
- 前台动作：程望川重新教一个新习惯，周砚屏把它标为新习惯，不从备份恢复。
- 场景边界：习惯可以重新放回日常，但不能写成恢复旧习惯。
- 避免：不写情感奇迹，不补空白握手记录。
- 主要物件：新习惯便签、空白握手记录。

### CH-067 / 不公开也能继续

- 推荐 POV：宋清岚 / 小穹。
- 前台动作：宋清岚把小会改成更小的闭门复核，只保留必要人员。
- 场景边界：减少围观保护老人主体性；不公开不影响继续校准。
- 避免：不用剧场式活动收束，不把闭门写成秘密审判。
- 主要物件：闭门复核清单、本地草案页。

### CH-068 / 未同步外层记录

- 推荐 POV：林问秋 / 尺素。
- 前台动作：林问秋提出暂不把私人习惯边界同步外层公共记录，只在本地草案页角留铅笔边注。
- 场景边界：私密关系不制度化展示；规则只保留必要边界。
- 避免：不把文档完整性凌驾于人，不让外层记录吞掉私人内容。
- 主要物件：未同步外层记录、铅笔页角。

### CH-069 / 回砂学会等拒绝

- 推荐 POV：回砂低亮度动作位 / 周砚屏。
- 前台动作：回砂收到“不公开”的选择后停止追问，后退半步等待。
- 场景边界：当前能力包括等待拒绝；这不是旧关系恢复。
- 避免：不写成 Agent 自我觉醒演说，不把等待写成错误恢复。
- 主要物件：动作边界卡、未同步外层记录、低亮度状态灯。

### CH-070 / 不能公开的小习惯

- 推荐 POV：罗衡 / 宋清岚收束。
- 前台动作：一个新小习惯进入程望川和回砂的局部日常，但不进入公共档案。
- 场景边界：私人习惯被当事人局部确认；公共档案只记录边界不记录内容。
- 避免：不要写成关系恢复原样，不进入 `CH-071` 铅笔条款试运行。
- 主要物件：新习惯便签、本地草案页角。

## 行业反差

本章主方向：个性化数据 / 最小必要收集 / 本地草案 / 不同步外层 / consent scope。

转译要求：

- 个性化数据 -> 私人习惯空栏不入公共夹。
- 最小必要收集 -> 只记录动作边界，不记录私密含义。
- 会议权限收缩 -> 小会改闭门复核，旁听不作证。
- 本地 draft -> 本地草案页角，不同步外层记录。
- 用户撤回 / 拒绝 -> 回砂后退半步等待。

不要直接堆隐私术语；每场最多一个行业反差，术语后立刻落到物件动作。

## Agent 与规则边界

Agent 可以：

- 学习一个新动作。
- 等待拒绝。
- 记录“不公开”为有效边界。
- 在低亮度状态下停问。
- 执行已授权普通工具范围内的动作。

Agent 不能：

- 从备份、身份链、公共记忆、自述记录或旧动作页恢复私人习惯。
- 把私人习惯公开化、归档化或同步到外层记录。
- 把程望川的旁听、沉默、动作许可、不公开、离场或局部教学当作作证、同意、原谅、接收或关系恢复。
- 用自我解释证明它已经理解拒绝。

## P0 / P1 风险

### P0

- 把私人习惯写进公共档案或公共待确认夹。
- 把新习惯写成备份恢复、旧关系恢复原样或空白握手记录补签。
- 把程望川的局部动作许可写成公开同意、作证、原谅或重新托付。

### P1

- 把“不公开”写成老人不配合、情绪惩罚或共同体失败。
- 把未同步外层记录写成流程缺口，而不是隐私保护。
- 让回砂用解释性独白完成“学会拒绝”。
- 让 `CH-070` 提前进入第五章的铅笔条款试运行。

- 第一动作建议：林问秋把待确认夹转到私人习惯空栏，程望川把夹页推回去或压住遮挡纸。
