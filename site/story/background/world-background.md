## 1. 地球身体与绿洲现场

故事发生在 2076 年前后。绿洲是小行星带里实际存在的设施与活动现场，包括矿场、工业设施、维修坞、公共区、低重力星光剧场及培养设施。机器、材料、损坏和等待都发生在那里。

老人本人仍在地球，通过接入舱等设备取得对应 Agent 的画面、声音、触觉与获准动作。地球身体没有被运往小行星带，也没有消失：饥饿、疲劳、手指压住的扶手、眼镜、吃饭和到时退出都会影响接入。只接声音、只看画面、完整感官接入与开放动作输入是不同状态，不能混为无条件在场。

首批共同体为五十位老人，每人对应一台绿洲端 Agent。Agent 不计入五十人的人数。五十个接入位置存在，不表示所有人同时拥有全部模块或每个人都在每一章出场。未进入正文的完整名册、年龄或职业不能据旧规划补成正文人物事实。

地球生活也在正文中实际出现：养老社区的饭桌、纸青蛙、画图的桌面和花坛，并非只作说明性背景。绿洲关系与地球生活会彼此牵动。

## 2. 架空通信设定

本书中的低延迟量子通信，是2076年的架空叙事前提，并非对现实通信能力的预测。现实深空通信受光时限制；小说不为这一虚构通道提供物理证明。它也不意味着无条件在场：疲劳、感官带宽、安全交接与掉线保护仍会限制接入。

既有背景规定通信通道本身不消耗绿洲币。感官处理、复杂判断、动作控制、多人协作和交接依然需要算力、能源、散热与维护窗口。通信可用也无法使失效存储中的完整个体状态自动恢复。

## 3. 保障、资金与参与

以下保留为既有架空前提；V50 并未逐项展开其制度实施过程：

- 基础生活和照护由养老金与公共系统保障，不以某个人在绿洲的产出、出勤或任务表现换取。
- 老人共同体自愿投入部分长期资金建设绿洲，并拥有对价值方向的实质支配权。长期参与可以包括建设、维修、种植、娱乐、旁听、休息与退出。
- 长青养老金信托是远端受托与审计接口；资金池包括自愿投入、公共照护配套及自治工业的补充收益。收益进入共同池，不能成为个人贡献榜或照护资格排名。
- 绿洲币 / Oasis Coin（OC）用于智能运行、模块部署、维护和公共建设的预算结算；能源、材料、散热、数据及设备寿命仍须真实存在。账面余额不能替代物理条件。

这些制度目的不保证人与人没有分歧，也不保证每次帮助、安排或邀请都会被接受。V50 的人物会误认、着急、替人决定、拒绝和失望；共同体需要在具体事件里处理这些后果。

## 4. Agent、模块与身份

Agent 具有唯一身份，不能复制、分裂或合并。初始本体是带模块化接口的通用机器人；采样、维修、搬运和影像等能力来自挂载或接入的生产力模块、设施与经验，不是天生固定职业。默认生存模块、基础感知、移动、储能和本地存储属于既有背景。接口数量有限，扩展和维护需要资源。

每人一台对应 Agent 是接入、长期协作和维护责任关系，不构成对它的全部时间、记忆或关系的占有。Agent 会给出建议、提出问题、说明风险，也会在已获准范围内行动。对应关系不会自动替老人回答一项新的请求，老人也不能把自己的意愿当作 Agent 已经同意。

V50 第二卷中，回砂的本地状态单元失效，诊断未能读回完整的个体状态。通信一直可用；更换件来自初始备件库，外部模块另留隔离架等待复核。原机身和原身份链仍在，同一链上只有眼前这一个基础实例。身份资料、公共记录与私人经历的记忆因此不能视为同一种东西。

普通工具检查、动作开放、移动复核和重新相处分步进行。回砂能读到记录中有自己，不能据此声称记起从前；别人的说明也不能替它证明连续的私人记忆。第二卷建立的是新的有限协作，没有证明旧状态完全恢复。

第三卷里，尺素与小穹有自己的玩耍与等待。林问秋希望尺素先看她的画，尺素想先等眼前的动作。这段关系没有在当场被一句道理解决。Agent 的活动不只服务于老人当前提出的需要。

## 5. 时间、资源与工程条件

时间单向流动，世界状态不能任意回退；资源不能凭空生成，计算与移动有成本。既有背景以单调推进的 tick 表示内部逻辑节拍，并以链上共识和事件记录确认公共状态。tick 不自动换算成现实分钟，也不能据此为正文补造日历日期。

设施、模块和结构会磨损。电力、算力、存储、金属材料、备件、散热、占用空间、运输路线与可信记录都影响可以进行的工作。规则可以修订，底层物理条件不能靠表决取消。安全拒绝、交接、撤回及失去连接后的保护，应有现场原因和可理解的后续选择。

绿洲启动时已有基础能源、通信、装配条件、有限仓储、初始备件和可轮用模块。第一卷要赶在地球补给窗口关闭前，把矿石处理、基础零件和常规维修接起来。基础零件制造可提供普通结构与机械件，不能随意打印芯片、精密传感器、电池或身份核心。

第一炉故障、砾光的右臂受损、取样与维修过程都留下后续影响。普通件过检和局部维修不意味着所有设备风险已经消失。低重力星光剧场开放的是有限座席、可进退的通道与小型放映，须与维护安排和安全条件共存。

## 6. V50 已发生的进展与开放状态

### 三枚种子

第三卷已完成播种。G-01 的这一格通过清洁、载体、供水、根区、运行接续和故障处置等检查后，三枚种子分别进入固定穴；盛小满完成播种操作，林问秋参与，叶简初接续培养班次。不能继续用旧稿“仍未播种”概括 V50。

播种后的第五天，中间一处的两片子叶已经能分开看；第一处先显出浅色，随后顶开表面细缝；最靠边的第三处尚未出现同样变化，仍检查根区与供水。三处并非同时取得同样结果，第三处也没有被判定死亡。

实际补水包含处理、复验、管路与载体滞留、取样及清洁等耗用。评估批准的是这一格再接续五天，后续班次和故障储备仍要保留；第二格支架仍扣着，第二只舱未领。已有萌发不能写成丰收、成熟农业或生态自给。

### 短片与放映

第四卷已有居民短片的取材、粗剪、修改和公开放映。宋清岚起初把第一枚播种画面与中间种子的子叶近景接在一起，盛小满指出两者不是同一枚；取材与剪接随后围绕具体画面、许可和结尾展开。

最终放映已发生，不能再把第四卷列为只有 scaffold。影片的完成不替所有人统一观看感受，也没有解决温室、Agent 身份连续性或私人关系的全部问题。尾声明确发生在居民短片首映后的第二天：许映舟在地球花坛边，只以声音和照片与砾光继续辨认石头。

《白盒》位于第三卷第三章与第四章之间；正文没有给它补出确定的日历日期。完整顺序和明确相对时间见 [时间线](../timeline/timeline.md)。
