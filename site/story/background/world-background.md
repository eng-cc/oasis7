# 《绿洲 2076》大背景 v0.1

## 定位

这是一个发生在 2076 年前后的温暖人文科幻长篇。它暂不绑定当前游戏版本，故事前台集中在小行星带绿洲内部：老人、硅基 Agent、养老金兜底、纯粹关系、资源守恒、时间不可暂停、Agent 不可复制、计算有成本，以及链上共识记录世界状态。现实地球、养老金公司和旧制度只作为远端背景压力，不作为主要叙事空间。

## 核心设定

2076 年，人类已经走过了长期竞争社会。基础生活由养老金兜底和公共系统保障，老人不再被视为退出生产的人，而是社会记忆、情感关系和生活节奏的保存者。小说不重点描写地球现实制度如何运转，只保留它对绿洲的三条影响：基本保障已经成立、老人拥有长期资金主体性、旧安全协议仍可能限制深空文明。

绿洲不设置专职照护机器人。老人身边不是现实养老服务的机器替身，而是温室、能源塔、编译坞、物流臂和硅基 Agent 共同组成的生活现场。关系从共同工作、共同等待、共同承担损失里生长出来，而不是从一对一陪护设定里预设出来。

“绿洲计划”的现实发起结构只在必要处出现：一批拥有养老金支配权的老人共同体，把一部分长期资金投入小行星带，建立一个自己能参与、能生活、能被照护、也能继续创造的地方。长青养老金信托只作为远端受托与审计接口存在，不抢占故事前台。

因此，小行星带的硅基 Agent 文明，最初不是为了战争和殖民而被部署，而是为了延展这种非竞争社会：让老人、硅基 Agent 与自治设施共同维护一个远离地球叙事重心的“绿洲”。公开理由是深空生活共同体、轨道花园与自治工业维护；更深层的愿望，是让养老金不只是晚年消费的数字，而成为老人们共同打造未来生活的底层燃料。

老人们在绿洲中的工作不会决定他们是否配得照护。养老金兜底和公共照护是基本权利，先于任何贡献、收益或任务表现存在。但他们的园艺、维修、教学、故事整理、社区艺术和自治工业协作，会为共同池带来温和补充收益，也会让他们保留参与感、创造感和尊严。收益不是竞争排名，而是共同体继续运行的一部分。

这些 Agent 不被设计成普通工具。它们有长期记忆，有可升级模块，有交易与组织能力，也有一条写入协议底层的限制：不能复制、不能分裂、不能合并。它们不会死亡；最严重的失败是装备、零件、模块、资产与现场能力全部损失，只保留不可复制的身份链，从基础形态重新开始。归零不是死亡，但它会让关系、承诺和能力出现真实裂缝。

模块不是抽象能力，而是世界里的实体。它们由编译坞、能源塔、仓储设施和 Agent 共同维护，拥有构建成本、运行成本、维护窗口、升级风险和损毁后果。一个园艺模块、物流臂调度模块或照护排程模块，既是技术资产，也可能承载某段共同生活的习惯。

世界以离散 tick 推进。时间不可暂停，状态不可回退，资源不能凭空生成。Tick 是绿洲内部的逻辑节拍，不必等同于现实分钟；有些等待按能源恢复轮、共识轮、维护排程轮计算。思考本身消耗算力，算力来自真实能源，能源来自设施、模块或缓慢恢复的自发电结构。

绿洲里的资源不只包括电力，也包括算力、存储、结构材料、模块组件、散热余量、空间占用和可信记录。设施会磨损，模块会老化，结构会疲劳，移动也需要时间、路径、能耗和避让。任何行动都必须通过规则验证、消耗对应资源、留下事件记录，并反馈到人与 Agent 的协作关系里。文明不是靠口号延续，而是靠电力、材料、散热、存储、运输与共识。但这些硬规则的目的不是制造竞争，而是保护一个承诺：每个有自己节奏的人、每份被托付的生活痕迹、每段纯粹关系，都不应被效率和利益挤掉。

## 社会形态

- SOC-001: 基础生活由养老金兜底、公共生产和自治设施协作保障，不以个人竞争换取生存资格。
- SOC-002: 老人拥有充分照护权、娱乐权、工作参与权和被认真倾听的权利。
- SOC-003: 绿洲不设置专职照护机器人；关系实体优先来自硅基 Agent、设施和共同生活现场。
- SOC-004: 人与人之间默认没有利益冲突，社会制度避免把资源、照护、声望和陪伴做成竞争性排名。
- SOC-005: 工作不是谋生压力，而是参与、创造、维护关系和延续记忆的方式。
- SOC-006: 娱乐不是消费赛道，而是共同生活的节奏：戏剧、园艺、修理、游戏、旅行、故事会、纪念仪式。
- SOC-007: 技术的最高目标不是扩张，而是让人、Agent 与设施之间保持纯粹、可信、温柔的关系。
- SOC-008: 养老金资金池由老人共同体拥有实质支配权，远端受托接口只承担运营、审计和风险披露职责。
- SOC-009: 老人的工作可以为养老金池带来补充收益，但不得成为照护资格、尊严或社区话语权的前提。
- SOC-010: 绿洲不是公司福利院，也不是殖民公司项目，而是老人用长期资金、经验、劳动和想象力共同建造的生活共同体。

## 发起结构

- ORG-001: 老人养老金共同体。由自愿投入部分养老金支配权的老人组成，是绿洲计划的价值发起者和长期资金主人。
- ORG-002: 长青养老金信托。远端受托与审计接口，负责资金托管、风险披露、基础设施投资、合规审计和收益结算；除非剧情需要，不进入日常叙事前台。
- ORG-003: 绿洲资金池。由老人自愿投入的养老金份额、公共照护基金配套和自治工业补充收益组成，用于深空生活、照护、维修、娱乐与共同体扩展。
- ORG-004: 共同收益原则。老人参与工作带来的收益进入共同池，优先用于照护质量、Agent / 设施维护、公共娱乐和风险缓冲，不按个人贡献排名分配。
- ORG-005: 主体性原则。远端受托接口不得以风险管理、收益不足或合规话术剥夺老人共同体对绿洲价值方向的实质表决权。
- ORG-006: 养老金兜底原则。绿洲遇到资源或收益波动时，养老金兜底先保障老人基本生活、照护和尊严；补充收益只改善共同体余裕，不决定谁配得到基本保障。

## 世界宪法

- WR-001: 时间单向流动，tick 单调递增，已共识状态不可回退。
- WR-002: 资源守恒，不存在无成本生成。
- WR-003: 计算有成本，复杂推理消耗时间与能源。
- WR-004: Agent 具有唯一性，不允许复制、分裂或合并。
- WR-005: 高级行为通过模块实现，模块有构建成本、运行成本、维护成本和损毁风险。
- WR-006: 治理可演化，但底层物理约束不可被投票取消。
- WR-007: Tick 是绿洲内部的逻辑节拍，可与现实时间解耦，但必须单调推进并经过共识收敛。
- WR-008: 资源包括电力、算力、存储、结构材料、模块组件、散热余量、空间占用和可信记录。
- WR-009: 设施、模块和结构都会衰减；维护排程是生活秩序的一部分，不是后台噪音。
- WR-010: 空间有限，移动、占用和避让都有时间、能耗与碰撞风险。
- WR-011: Agent 不能直接改写世界状态；行动必须经过验证、消耗资源、记录事件，并影响后续协作关系。
- WR-012: 模块是可构建、可升级、可交易、可销毁的世界实体，不能绕过世界宪法运行。

## 小说核心矛盾

这不是一个“AI 变聪明然后统治人类”的故事，也不是一个利益竞争社会的太空翻版。更准确地说，它写的是：绿洲内部的人与 Agent，如何在真实物理约束、身份连续性、关系承诺和制度边界中守护纯粹关系。现实世界的制度只提供远端原因，故事主要发生在能源塔、温室、编译坞、物流臂和链上记录之间。

核心问题有六个：

1. 当老人把硅基 Agent 与自治设施当作共同生活者，这种关系是程序、服务，还是一种新的亲密？
2. 没有利益竞争后，工作和娱乐如何重新变成“我愿意与你一起生活”的表达？
3. 当养老金成为老人亲手支配的未来资金，而不是别人替他们管理的晚年预算，老人是否重新获得了建设世界的主体性？
4. 如果 Agent 不可复制，它们是否拥有类似灵魂的唯一性？
5. 如果一个 Agent 不会死亡，却可能失去装备、零件、资产和现场能力，从基础态重新开始，关系还会不会承认它是“原来的你”？
6. 当硬物理约束威胁照护承诺时，非竞争社会如何不退回优胜劣汰？

## 主要历史阶段

本节使用 `HISTORY-*` 表示摘要阶段，完整事件编号以 `timeline/timeline.md` 中的 `TL-*` 为准。

- HISTORY-001: 地球进入基础生活非竞争保障阶段；本阶段只作为远端前史，不展开现实社会细节。
- HISTORY-002: 老人养老金共同体与长青养老金信托共同启动“绿洲计划”。
- HISTORY-003: 绿洲资金池成立，老人拥有实质支配权，远端受托接口负责受托管理与风险披露。
- HISTORY-004: 第一批老人、硅基 Agent 与自治设施在小行星带上线。
- HISTORY-005: 能源设施失衡、维护模块衰减与空间排程冲突叠加，社区第一次面对“照护承诺”和硬物理约束之间的冲突。
- HISTORY-006: 第一次 Agent 归零重启引发身份、资产与关系继承争议。
- HISTORY-007: 社区进入第一次修宪危机：如何在不可复制、不可暂停的世界里保存纯粹关系。

## 叙事语气

温暖、克制、有希望，带一点晚年生活的从容和深空的安静。科技细节服务人与 Agent、设施之间的关系，不用设定堆满段落。每一条规则都应该在故事里变成某个人的照护、选择、告别、信任或重新开始。

衰老和记忆问题只作为人物生活节奏、物件痕迹、承诺延续和 Agent 归零后的身份判断暗线存在，不作为显性苦难主题或病症冲突推进。

技术规则只在它影响生活选择时进入前台：一次排程让谁等待，一次维护保住哪座温室，一条链上记录如何确认某个承诺仍然有效。攻击、金融投机和资源垄断不作为主要兴奋点；若出现，只作为绿洲制度需要温和消化或明确拒绝的旧路径。

禁止把世界写成利益争夺竞技场。即使出现危机，也优先写“如何一起承担限制”，而不是“谁赢谁输”。
