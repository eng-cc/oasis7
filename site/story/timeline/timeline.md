# 《绿洲2076》V50 时间线

故事设定在2076年。正文没有给出具体月日，各人在地球端的本地作息也不相同。下表用首次接入为首轮第1天，再使用温室、播种和首映各自的明确时间锚点；不同锚点之间没有足够证据时不换算为连续日历。

[V50正文入口](../releases/v50-reading-version.md) · [故事梗概](../outline/novel-outline.md) · [人物关系](../characters/character-registry.md)

旧`TL-*`是较早十九章体系及后续路线规划的事件编号；本表不沿用或强配这些编号。

## 首次接入至单独看灯

| 相对日序 | 事件 | 正文依据与限制 |
| --- | --- | --- |
| 第1天 | 许初次接入砾光、参加晨会并取回第一粒样本；退出吃半份晚饭、与老邱玩纸蛙；回来将留样叫作灰边。第一炉失败，砾光右臂受损、臂端记录无法读取。分步维修占用剧场部分窗口，第一件支架不合格、第二件通过；仅开放有限动作。许参加入口预演 | [第一卷第一章](../releases/v50/volume-01-chapter-01.md)。晨会不是所有人的当地早晨；样本未入第一炉 |
| 第2天 | 许先到门口等，再以左臂取回邻样，和灰边对照。第二炉产出有限合格材料；林先打料盒支架，钟得以离开扶料位去看矿尘。普通限位件与出口夹座相继使用，完整灯座仍待做 | [第一卷第二章](../releases/v50/volume-01-chapter-02.md)明写“第二天早上” |
| 第3天 | 邵青禾退回补位班次。第三炉普通件接上维护；回砂按住歪标签。方换线缆夹，祝的地图板装配因垫片顺序错误拆开重放。短扶手安装、去毛边；宋与邵、罗约次日来试 | [第一卷第三章](../releases/v50/volume-01-chapter-03.md)明写“第三天” |
| 第4天 | 剧场首次开放少量座席。方的普通复检改到次日并退掉当天搬运班；灯座装好，灯光从座席间隙照到壁板。众人看两遍七十秒星光片，罗赶上第二遍。宋与林结束接入后，小穹和尺素开始触碰游戏 | [第一卷第四章](../releases/v50/volume-01-chapter-04.md)由前章次日约定衔接；本章约后天再看片，明天安排普通维护 |
| 第5天 | 回砂停靠自检失效；罗与榫七按时完成方的普通复检，装料范围仍须另核。回砂更换本地单元、重建基础实例。程在下一轮低风险检查中夹取练习片，后退出去吃饭、下楼打牌；约明天进剧场 | [第二卷第一章](../releases/v50/volume-02-chapter-01.md)、[第二章](../releases/v50/volume-02-chapter-02.md)由“昨晚”、同日下一轮检查和明日邀请连接；程定下次日地球端11:50下线、12:00吃饭 |
| 第6天 | 应声使用已获准的片尾回看。宋额外开放申请准备，取片、转码及余热挤走回砂移动复核；程按约来到，却赶不上自己下线点前入座，只接声音，按时结束。宋发出次日十分钟无片查看时段，未代程预约。回砂复核转到下一轮完成 | [第二卷第三章](../releases/v50/volume-02-chapter-03.md)是首场后天的原定放映；与前章“明天”吻合。没有补演来还原错过的在场 |
| 第7天 | 程自行选下十分钟窗口，与回砂沿放行路线入场。两者练习明确说“停”，看墙缝、手背退光与椅背间窄角，按时退出 | [第二卷第四章](../releases/v50/volume-02-chapter-04.md)承接次日查看，先读已完成的上一轮复核结果 |

## 温室的局部时间锚点

温室段开始时已组装了数日，但正文未交代它距第7天的精确天数。

| 锚点 | 事件 | 可确认到的时间关系 |
| --- | --- | --- |
| 空床测试日 | 林与盛拆包装、试托架，发现连续供养与换班尚未接齐，决定不领种子、只测空床。水在载体铺开，冷凝面出现水滴，回收水进入待检侧 | [第三卷第一章](../releases/v50/volume-03-chapter-01.md)。仅计算当天在线时间不足以承担播种后的运行 |
| 换膜日 | 膜边出现灰绿色迹象；隔离、取样、拆膜、清洁。林退掉第二格试装，归还未用工具；盛按约离开，叶接手 | [第三卷第二章](../releases/v50/volume-03-chapter-02.md)。与空床测试是前后两轮，间隔未明写 |
| 换膜日稍晚 | 原留给第二格试装的正常窗口转给G-01；新水和新空载用品完成一轮复验，回收物另行取样 | 正文明确“那天稍晚” |
| 换膜日的第二天 | 林在地球工作台读到过程记录，仍未见本轮放行结果 | 正文明写“第二天”，不能等同已经过检 |
| 后续复查日 | 本轮水路与相关表面检验通过，后续检视无新增迹象。旧样来源还在查，前次水仍待检；叶已挪好正式种植盒，林向盛发新的播种候选时间 | 具体间隔未说明。罗衡与妹妹唱歌的地球场景紧接其后，但没有精确同日标记 |
| 播种日 | 到五天后首轮评估的连续运行、换班、用水用气与故障接管已核定。林让出控制，盛放下三枚生菜种子；叶接班，种植盒留在舱内 | [第三卷第三章](../releases/v50/volume-03-chapter-03.md)。不是最初空床测试日，也不是换膜后的过程记录日 |
| 白盒场景 | 公共区拆旧柜、加宽过道；何与短桥取白盒、收零件和蓝把手，磨片最后放不下 | [第三卷间章《白盒》](../releases/v50/volume-03-interlude-white-box.md)。叙述位于播种章之后、第五天章之前；正文未明写其发生在播种后第几天，不给它补一个日期 |
| 播种后第5天 | 第一处已有萌发变化，中间有两片子叶，第三处没有同样变化。联合评估后再续养五天，仅一格；第二格未恢复。叶按自己顺序维护，盛后续只接观察画面。林回地球画叶子，得知尺素与小穹的游戏从星光片后就已开始 | [第三卷第四章](../releases/v50/volume-03-chapter-04.md)明写“播种后的第五天” |
