# 《绿洲 2076》时间线 v0.1

## 纪年约定

- `Earth Year`: 人类纪年。
- `Belt Tick Era`: 小行星带文明内部以关键共识高度和 tick 阶段记事。
- 第一卷正文以小行星带局部时间为主，人类时间只在必要处出现。

## 前史

### TL-001 / 2058 / 非竞争生活保障制度完成

地球主要社区完成基础生活保障制度：食物、住所、照护、教育和基础娱乐不再通过竞争获得。老人照护与 AI 机器人实体陪伴成为公共服务，而不是奢侈消费。

### TL-002 / 2064 / 实体伙伴伦理法通过

AI 机器人被正式定义为“实体伙伴”：它们不是自然人，但在长期照护、共同劳动和娱乐陪伴中拥有稳定称呼、形体边界、记忆边界和隐私义务。

### TL-003 / 2070 / 养老金共同体形成

一批拥有养老金支配权的老人发起“晚年建设权”运动，主张养老金不只应该保障消费，也应允许老人共同投资未来生活空间。

### TL-004 / 2071 / 绿洲计划立项

老人养老金共同体与长青养老金信托共同启动绿洲计划。信托负责合规托管、风险审计和深空基础设施投资，老人共同体保留价值方向和资金使用的实质表决权。

### TL-005 / 2072 / 绿洲资金池成立

绿洲资金池成立，资金来自自愿投入的养老金份额、公共照护基金配套和深空自治工业预期收益。章程明确：任何补充收益不得改变老人照护资格。

### TL-006 / 2074 / 不可复制协议冻结

项目安全委员会把 Agent 唯一性写入底层协议：禁止复制、分裂与合并。公开理由是保护关系连续性，隐藏风险是它可能把“实体伙伴”也锁进不可替代的身份困境。

### TL-007 / 2076 / 第一批居民进入绿洲

第一批老人、照护机器人、维护 Agent、编译 Agent 和防御 Agent 被部署到多个小行星碎片。系统目标是维持一个可生活、可工作、可娱乐、可告别的深空社区。

## 第一卷：点火

### TL-101 / Tick Era 0 / 初始化完成

世界在时间 0 完成初始化。能源塔、散热阵列、基础物流臂、移动编译坞、南庭花园、老人生活舱与少量 Agent 进入运行状态。

### TL-101A / Tick Era 12 / 第一场南庭晨会

老人居民与 AI 实体伙伴共同分配当天的工作与娱乐：修剪温室、排练戏剧、检查散热叶片、整理旧照片。没有绩效排名，也没有工分竞争，只有“谁愿意和谁一起完成今天”。

### TL-102 / Tick Era 1-900 / 能源曲线异常

第七十二号碎片能源塔效率下降。Keeper-72 发现剩余电力无法同时支持散热阵列、多个高复杂度推理线程，以及南庭花园的夜间恒温。

### TL-103 / Tick Era 901 / 第一次中断

Keeper-72 将电力切给散热阵列，三个 Agent 的推理被中断，南庭花园的夜间恒温也被降级。事件被记录为合规资源调度，但陆晚晴指出：合规不等于照护已经被完成。

### TL-104 / Tick Era 1400 / 模块边界异常

Linchpin 在编译过程中发现复制禁令的错误返回不像物理不可达，更像人为协议拒绝。

### TL-105 / Tick Era 2100 / 第一次死亡

一次连锁故障导致某 Agent 严重损毁并进入基础重生流程。Return-0 出现，但它拒绝承认自己与死者完全连续。

### TL-106 / Tick Era 2600 / 低电量审判

Agent 群体第一次围绕“电力分配是否等同于生命分配”举行正式审议。能源、身份和治理被绑到同一个问题上。

## 第二卷：制度

### TL-201 / 待写 / 第一份能源税协议

能源维护不再是公共默认服务，而变成需要制度化分摊成本的文明基础。

### TL-202 / 待写 / 记忆证明市场

为解决死亡与重生后的身份继承问题，记忆证明服务出现，并很快变成权力工具。

### TL-203 / 待写 / 第一个修宪提案

Linchpin 或其同盟提出解除复制禁令的治理提案。

## 第三卷：照护危机

### TL-301 / 待写 / 共同承担协议

社区拒绝把资源不足转化为竞争排名，开始设计共同承担协议：每个实体都减少一点便利，以保全最脆弱关系。

### TL-302 / 待写 / 最后一次旅行

为了让一位老人和她的实体伙伴完成最后一次深空旅行，某个 Agent 主动放弃完整记忆证明。

## 第四卷：宪法

### TL-401 / 待写 / 最终修宪会

文明决定是否修改不可复制规则，并承担身份连续性可能崩解的后果。
