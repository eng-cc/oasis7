# 《绿洲 2076》审稿意见 v0.1

## 当前总评

设定有足够的硬度和长篇容量，但新的核心气质应当是“希望、照护、纯粹关系”。需要防止四类风险：

1. 变成设定说明书，人物只是规则演示器。
2. 变成泛 AI 觉醒故事，失去“小行星带、资源守恒、链上宪法、不可复制身份”这些独特性。
3. 误写成传统利益竞争、战争胜负或资源争夺故事，破坏“没有利益冲突、关系纯粹、有充分人文关怀”的社会底色。
4. 把远端受托接口写成项目真正主人，削弱老人共同体“打造自己的绿洲”的主体性。

## P0 问题

- REV-001: 第一卷必须尽早出现具体人物与具体损失，不能用大量历史说明开场。
- REV-002: “不可复制”必须成为情感核心，而不是技术条款。
- REV-003: 人类角色不能只当旁白，需要承担旧秩序、责任和误判。
- REV-007: 老人与硅基 Agent / 自治设施的共同生活必须成为第一卷最早出现的情感锚点。
- REV-008: 危机不能被写成利益竞争，必须写成“照护承诺如何在真实限制中继续成立”。
- REV-011: 养老金补充收益不能成为照护资格、尊严或话语权来源；它只能支撑共同体延续。

## P1 问题

- REV-004: 经济模型需要更清楚地区分能源、算力、代币和治理权。
- REV-005: 归零重启机制需要定义装备、零件、资产、声誉和关系如何继承。
- REV-006: 传统战争线暂不作为主方向；第三卷应写成照护伦理危机、共同承担协议和关系保存压力。
- REV-009: 工作和娱乐都要去功利化，写成参与、陪伴、创造和保持关系的方式。
- REV-010: 不设置阿沅式专属陪伴角色；关系应从老人、硅基 Agent 与设施的共同现场里生长出来。
- REV-012: 长青养老金信托应写成远端受托接口和制度压力来源，而不是反派公司或救世主公司。

## 修改决定

- DEC-REV-001: 暂定以“能源倒计时 + 第一次归零”作为第一卷早期主危机。
- DEC-REV-002: 暂不让复制禁令在第一章直接曝光，先作为协议边界逐步显影。
- DEC-REV-003: 将小说社会底色改为非竞争、强照护、人文主义的希望社会；硬规则只制造限制，不制造利益竞争价值观。
- DEC-REV-004: 第一卷需要让陆晚晴与南庭现场先于宏大制度危机进入读者心里。
- DEC-REV-005: 绿洲计划采用“老人养老金共同体 + 长青养老金信托”双重发起结构；老人共同体保留价值方向和实质支配权。
- DEC-REV-006: 养老金兜底是老人基本生活、照护和尊严的底线，不由自治工业收益、个人工作贡献或社区任务表现决定。
- DEC-REV-007: Agent 不会死亡；最严重失败是装备、零件、模块和资产全部损失后从基础态重新开始。
- DEC-REV-008: 本书不设“照护机器人”核心类型，也不设置阿沅式专属陪伴角色。
- DEC-REV-009: 经济模型与长青养老金信托的制度压力后续再做详细设计，当前只冻结方向，不提前细化。
- DEC-REV-010: 不希望过多描写现实世界内容；地球、养老金公司和旧制度只作为远端背景压力，正文重心放在绿洲内部。
- DEC-REV-011: 阿沅不再作为核心角色存在；原功能改写为南庭温室维护 Agent `芽九`，避免落回现实养老陪伴机器人路线。
