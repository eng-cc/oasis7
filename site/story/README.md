# Story Workspace

本目录用于沉淀长篇小说《绿洲 2076》（英文名：oasis 2076）的站点侧资料。它不是当前游戏玩法 canon，而是以硅基小行星文明为种子的长篇世界观写作空间。

## 目录

- `background/`: 文章的大背景、世界宪法、历史前提、核心规则。
- `outline/`: 长篇总纲、分卷结构、主要人物线和章节路线。
- `characters/`: 人物注册表、角色弧线、关系与秘密。
- `timeline/`: 年表、重大事件、卷内事件顺序。
- `chapter-cards/`: 章节卡、场景卡、每章目标与依赖关系。
- `research/`: 调研材料、参考问题、科学/社会/叙事验证笔记。
- `reviews/`: 审稿意见、问题清单、修改记录。
- `draft/`: 正文草稿、章节片段和可发布稿。

## 写作边界

- 暂不绑定当前游戏版本的可玩性、PRD 或发布承诺。
- 原始 `world-rule.md` 可作为底层世界宪法种子，但小说正文优先服务人物、冲突和历史。
- 每次新增正文前，先补齐对应的大纲、时间线或角色动机，避免几十万字后期失控。
