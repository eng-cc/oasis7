# Story Workspace

本目录用于从零重建长篇小说《绿洲 2076》（英文名：oasis 2076）的站点侧资料。

旧版人物、时间线、章节卡、调研、审稿意见和正文草稿已经清空；世界背景保留，后续可基于它重新判断是否进入正式故事真值。

## 目录

- `background/`: 世界背景保留，待复审。
- `outline/`: 长篇总纲占位，待重建。
- `characters/`: 人物注册表占位，待重建。
- `timeline/`: 时间线占位，待重建。
- `chapter-cards/`: 章节卡占位，待重建。
- `research/`: 调研笔记占位，待重建。
- `reviews/`: 审稿意见占位，待重建。
- `draft/`: 正文草稿占位，待重建。

## 写作边界

- 当前仅 `background/world-background.md` 保留旧版背景，其余故事资料没有已确认 canon。
- 新增人物、背景、时间线或正文前，应先明确其是否进入正式故事真值。
- 每次新增正文前，先补齐对应的大纲、时间线或角色动机，避免后期失控。
