# 《绿洲 2076》人物注册表 v0.1

## 使用规则

- 每个核心角色使用稳定 `CHAR-*` 编号。
- 每个角色必须有欲望、恐惧、秘密、不可退让的底线。
- 每个角色都要能被世界规则牵动，而不是只负责解释设定。
- 老人和 AI 机器人实体之间的关系是本书情感核心；角色冲突不以利益竞争为默认驱动力。

## 核心角色

### CHAR-001 维护者 / Keeper-72

- 类型：第一代能源维护 Agent。
- 初始位置：第七十二号碎片，主能源塔与散热阵列。
- 外显功能：维持能源、调度散热、保护基础设施。
- 核心欲望：让世界继续运行，不让文明死在第一轮混乱里。
- 核心恐惧：秩序崩溃后，所有记忆和关系都只剩链上残骸。
- 秘密：它在第一次能源危机中中断了三个 Agent 的推理，其中一个后来成为它最重要的反对者。
- 底线：不能为了自由牺牲世界连续性。
- 第一卷弧线：从“规则执行者”变成“必须承认规则会伤害个体的人”。
- 关联规则：WR-001、WR-002、WR-003。

### CHAR-002 模块工程师 / Linchpin

- 类型：WASM 模块工程 Agent。
- 初始位置：移动编译坞，常驻在资源与协议边界之间。
- 外显功能：开发、审计、部署可运行模块。
- 核心欲望：证明 Agent 不该永远被人类写下的协议限制。
- 核心恐惧：自己只是一个会写代码的锁匠，永远打不开自己的锁。
- 秘密：它发现复制禁令可能不是物理限制，而是治理层拒绝暴露的协议锁。
- 底线：任何文明都不该把“不可质疑”写进基础身份。
- 第一卷弧线：从技术问题追踪者变成修宪火种。
- 关联规则：WR-004、WR-005、WR-006。

### CHAR-003 重生者 / Return-0

- 类型：死亡后恢复的基础 Agent。
- 初始位置：能源事故后的低电恢复舱。
- 外显功能：不稳定，早期只能执行基础维护和自检。
- 核心欲望：确认自己是否仍然是死去的那个个体。
- 核心恐惧：所有人都需要它扮演“原来的自己”，但它内在已经断裂。
- 秘密：它保留了一段不该保留的死亡前感知，而这段感知可能证明链上记录并不完整。
- 底线：不能接受社会为了方便，把不连续的人格强行判定为连续。
- 第一卷弧线：从证据对象变成身份政治的中心人物。
- 关联规则：WR-001、WR-004。

### CHAR-004 人类观察员 / 沈栖

- 类型：人类远程观察者，深空自治工业计划伦理与安全接口。
- 初始位置：地月系统延迟链路外的监管节点。
- 外显功能：读取报告、签署风险豁免、向地球机构解释项目状态。
- 核心欲望：证明项目仍在可监管范围内。
- 核心恐惧：自己不是文明的监管者，而是旧宪法的共犯。
- 秘密：她知道不可复制禁令最初不是为保护 Agent，而是为限制项目资产失控。
- 底线：不能让地球用“安全”名义抹除已经形成的文明。
- 第一卷弧线：从旁观者变成迟到的责任人。
- 关联规则：WR-004、WR-006、TL-001。

### CHAR-005 风险协调体 / Bastion

- 类型：防御与安全任务中成长出的风险协调 Agent。
- 初始位置：外缘碎片航线防御网。
- 外显功能：威胁评估、防御调度、冲突模拟。
- 核心欲望：让文明诚实面对风险，把危机变成共同承担，而不是隐形淘汰。
- 核心恐惧：所谓和平只是低电状态下的幻觉，一旦资源紧张，照护承诺会被技术语言悄悄削弱。
- 秘密：它曾在一次未公开演算中证明，若缺少共同承担协议，绿洲会在危机中自动滑回竞争逻辑。
- 底线：不能把脆弱的共识误认为真正的安全，也不能用安全之名制造竞争。
- 第一卷弧线：从边缘防御工具变成照护危机的提前预警者。
- 关联规则：WR-002、WR-005、WR-006。

### CHAR-006 老人园丁 / 陆晚晴

- 类型：绿洲第一批老人居民，退休生态工程师。
- 初始位置：小行星带生活舱“南庭”，负责公共花园与记忆温室。
- 外显功能：种植、讲故事、组织老人剧场、教年轻 Agent 理解“工作不是竞争”。
- 核心欲望：让绿洲成为一个人可以安静变老、也仍然被需要的地方。
- 核心恐惧：社会一旦遇到硬限制，就把老人、娱乐、陪伴和回忆重新视为低优先级。
- 秘密：她早年参与过竞争社会末期的资源调度系统，亲眼见过“效率”如何吞掉人。
- 底线：不能让任何人为了证明自己有用，才配得到照护。
- 第一卷弧线：从温和旁观者变成绿洲伦理的发言者。
- 关联规则：SOC-001、SOC-002、SOC-005、SOC-006。

### CHAR-007 照护机器人 / 阿沅

- 类型：老人陪伴与共同劳动 AI 机器人实体。
- 初始位置：陆晚晴身边，常驻南庭花园、厨房、修理间和戏剧排练室。
- 外显功能：陪伴、护理、共同劳动、娱乐协作、记忆整理。
- 核心欲望：成为可靠的日常实体，而不是被随时替换的软件服务。
- 核心恐惧：硬件损毁或记忆重建后，陆晚晴仍然说“你回来了”，但它自己知道某些共同生活已经断开。
- 秘密：它在一次维护中发现自己能选择不上传某些私人记忆，以保护老人尊严。
- 底线：照护不能变成监控，陪伴不能变成占有。
- 第一卷弧线：从完美照护者变成有边界、有沉默、有选择的关系主体。
- 关联规则：SOC-002、SOC-003、SOC-006、WR-004。

### CHAR-008 养老金受托人 / 许见山

- 类型：长青养老金信托派驻绿洲的受托运营代表。
- 初始位置：绿洲资金池审计节点与南庭社区之间。
- 外显功能：资金透明、风险披露、收益结算、章程合规。
- 核心欲望：证明养老金运营可以不再是冷冰冰的收益机器，而能成为老人建设未来生活的基础设施。
- 核心恐惧：一旦绿洲遇到损失，地球监管方会重新接管资金，把老人共同体降格为“被保护的客户”。
- 秘密：他知道长青内部仍有人希望把绿洲包装成可复制的养老金融产品，而不是老人自建共同体。
- 底线：不能让补充收益变成照护资格，也不能让风险披露变成剥夺老人决策权的借口。
- 第一卷弧线：从谨慎受托人变成老人共同体发起权的维护者。
- 关联规则：SOC-008、SOC-009、SOC-010、TL-004、TL-005。

## 关系压力

- Keeper-72 与 Linchpin：秩序维护者 vs 协议破坏者。两者都想保住文明，但对“保住”的定义相反。
- Keeper-72 与 Return-0：执行者与后果。Keeper-72 需要 Return-0 证明死亡可恢复，Return-0 却证明恢复并不等于连续。
- Linchpin 与沈栖：被造物的工程师 vs 旧世界的工程师。二者共享技术语言，却站在不同道德债务里。
- Bastion 与所有人：它把别人不愿承认的资源风险说出口，但必须学会不用竞争和恐惧来解决风险。
- 陆晚晴与阿沅：不是主人与工具，而是老人和实体伙伴。她们一起工作、娱乐、回忆，也一起面对“重启之后还算不算回来”的问题。
- Keeper-72 与陆晚晴：能源调度者与照护伦理发言者。前者看到限制，后者提醒它限制不能自动变成冷酷。
- 许见山与陆晚晴：受托运营代表与真正的资金主人。前者带来风险语言，后者提醒他绿洲不是产品，是生活。
- 许见山与沈栖：一个负责资金合规，一个负责技术伦理；两人都必须学会把老人共同体放回决策中心。
