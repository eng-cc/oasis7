# 《绿洲 2076》第二卷第四章章节卡

## 范围

- 卷次：第二卷。
- 章节：第二卷第四章 / 全书第八章。
- 场次：`CH-063` 到 `CH-070`。
- 时间线：`TL-063` 到 `TL-070`。
- 章节标题：不能公开的小习惯。
- 阶段目标：把冲突转向私人习惯和老人主体性；某个小习惯可以帮助校准，但程望川和其他老人有权不公开、不作证、不把私密关系交给共同体保存。

## 章节任务句

本章要证明：越温柔的共同体，越不能用好意催促老人公开私人习惯。私人关系可以重新长出来，但不必被公共档案保存。

## 禁区

- 不把隐私让渡写成温柔牺牲。
- 不把共同体善意写成催促老人承担公共教育义务。
- 不把旁听写成作证，把沉默写成同意。
- 不让私人习惯从备份恢复。

## 边界状态字段

- 身份链：只作为材料连续背景，不进入私人习惯证明。
- 承诺材料：仍留在待确认夹，不通过私人习惯解决。
- 能力：可以通过新动作练习，不等于旧关系恢复。
- 资产 / 工具：仅限已授权普通工具。
- 私人习惯：可重新教、可不公开、可不进入公共档案。

## 章节卡

### CH-063 / TL-063: 小习惯不进入公共夹

- 前台动作：重新校准需要一个私人小习惯，程望川拒绝把它放入公共待确认夹。
- 关联人物：程望川、林问秋、宋清岚。
- 关联物件：待确认夹、私人习惯空栏。
- 边界状态：私人习惯不默认存在，也不默认公共化。
- 关系推进：共同体第一次承认不是所有关系都应公共化。
- 禁重复：不把拒绝写成不配合。

### CH-064 / TL-064: 只给动作不给解释

- 前台动作：程望川只允许复现一个动作，不说明背后的私密记忆。
- 关联人物：程望川、回砂、榫七。
- 关联物件：小型力矩扳手、动作边界卡。
- 边界状态：记录动作边界，不追问含义；能力训练不等于关系确认。
- 关系推进：重新协作可以从不解释开始。
- 禁重复：不让记录组追问。

### CH-065 / TL-065: 旁听不作证

- 前台动作：贺南溪、景亭晚和闵存真旁听记录一致性复核，但旁听不作证。
- 关联人物：贺南溪、景亭晚、闵存真、宋清岚。
- 关联物件：旁听记录、未同步外层记录。
- 边界状态：旁听只证明有人在场，不证明认可；沉默不是同意。
- 关系推进：共同体给“看着但不说”留下位置。
- 禁重复：不使用“位置保留”作为情感收束。

### CH-066 / TL-066: 私人习惯可重新教

- 前台动作：程望川把一个新习惯重新教给回砂，但明确它不是从备份恢复。
- 关联人物：程望川、回砂、周砚屏。
- 关联物件：新习惯便签、空白握手记录。
- 边界状态：习惯可以重新放回日常，但不能写成恢复旧习惯。
- 关系推进：关系不是原样回来，而是出现一个新入口。
- 禁重复：不写情感奇迹。

### CH-067 / TL-067: 不公开也能继续

- 前台动作：宋清岚把小会改成更小的闭门复核，只保留必要人员。
- 关联人物：宋清岚、小穹、程望川。
- 关联物件：闭门复核清单、本地草案页。
- 边界状态：减少围观保护老人主体性；不公开不影响继续校准。
- 关系推进：共同体用退后一步表达照看。
- 禁重复：不用剧场式活动收束。

### CH-068 / TL-068: 未同步外层记录

- 前台动作：林问秋提出暂不把私人习惯边界同步外层公共记录，只在本地草案页角留铅笔边注。
- 关联人物：林问秋、尺素、罗衡。
- 关联物件：未同步外层记录、铅笔页角。
- 边界状态：私密关系不制度化展示；规则只保留必要边界。
- 关系推进：流程第一次主动不收纳一切。
- 禁重复：不把文档完整性凌驾于人。

### CH-069 / TL-069: 回砂学会等拒绝

- 前台动作：回砂收到“不公开”的选择后停止追问，后退半步等待。
- 关联人物：回砂、程望川、周砚屏、应声。
- 关联物件：动作边界卡、未同步外层记录。
- 边界状态：当前能力包括等待拒绝；这不是旧关系恢复。
- 关系推进：回砂的进步是学会不把拒绝当错误。
- 禁重复：不写成 Agent 自我觉醒演说。

### CH-070 / TL-070: 不能公开的小习惯

- 前台动作：一个新小习惯进入两人日常，但不进入公共档案。
- 关联人物：程望川、回砂、宋清岚、罗衡。
- 关联物件：新习惯便签、本地草案页角。
- 边界状态：私人习惯被当事人局部确认；公共档案只记录边界不记录内容。
- 关系推进：隐私边界成为修宪的一部分。
- 禁重复：不要写成关系恢复原样。
