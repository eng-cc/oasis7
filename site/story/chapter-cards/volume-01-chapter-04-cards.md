# 《绿洲 2076》第一卷第四章章节卡 v0.1

## 使用规则

本文件接续 `volume-01-chapter-03-cards.md` 的 `CH-021` 到 `CH-028`。第四章是第一卷收束章：它不把绿洲写成工业完全成熟，而是让矿石处理厂、基础零件厂和 Agent 维修坞形成足够支撑“最低试运营”的基础维护闭环，并让第一座低重力星光剧场 / 活动厅真正开一次。

- 本章可以确认“基础维护材料自给能力开始成立”，但不能写成完整工业自给、量产或富余。
- 剧场试运营必须是最低版本：可安全进入、可旁听、可安静退出、可播放公共记忆、可举办小型活动。
- 开场不是奖励贡献者，也不是项目发布会；它是公共客厅第一次被大家共同使用。
- 所有庆祝都必须保留维护余量、空维修位、退出路线和休息者位置。
- 每场正文最多让 1-2 个技术词进入前台。

## 第四章总目标：第一场不是开幕，是明天还会开

第四章从第三章“能轮换”推进到第一卷情感胜利：最低试运营。前三章已经证明大家愿意再来、第二天能继续、班次能轮换；第四章要证明绿洲不仅能把工厂跑起来，也能把公共快乐当作必须维护的生活承诺。

章内工业目标：

1. 确认试运营前的三项底线：维护预备料、空维修位、可撤回试运营方案。
2. 让矿石处理厂 V1 通过第四炉继续复验，并为维护预备料补齐一批普通材料。
3. 让基础零件厂 V1 打印剧场安全件和维护备用件，不打印装饰优先件。
4. 让 Agent 维修坞 V1 在试运营期间保持应急维护能力。

章内情感目标：

1. 让“开场”不压过“有人可以退出、旁听和明天再来”。
2. 让砾光、旧螺栓、失败炉次和普通维护都进入公共记忆，但不变成痛苦展览或英雄宣传。
3. 让先锋队里的回声角色继续在首场中承担真实动作：改公告、守入口、查字号、留空位。
4. 让第一卷以“公共客厅开始日常化”收束，而不是以一次项目大捷收束。

## CH-029: 开场条件先问维修坞

- 状态：可进入正文草稿。
- 卷内位置：第一卷第四章第一场。
- 事件锚点：`TL-029`，对应 `HISTORY-007`、`HISTORY-008`。
- 关联人物：`CHAR-003` 罗衡，`CHAR-102` 榫七，`CHAR-002` 宋清岚，`CHAR-103` 小穹。
- 低戏份回声角色：`PIONEER-023` 程望川，`PIONEER-027` 梁季白，`PIONEER-040` 顾微明。
- 关联规则：`WR-009`、`WR-014`、`WR-017`、`WR-018`、`SOC-006`、`SOC-016`。
- POV：罗衡近距离视角。
- 场景地点：公共账本；Agent 维修坞排程台；剧场试运营条件板。

### 场景目的

把第四章的方向立住：剧场终于可以进入最低试运营准备，但开场条件不能先问节目单，而要先问维修坞是否留有余量。本场确认公共快乐不是挤占维护，而是和维护一起被守住。

### 情感核心

罗衡第一次把“试运营”写进账本时，发现自己没有先算灯光和节目，而是先问谁会在开场时被维修坞接住。公共客厅要能开，是因为它没有忘记后台那张空位。

### 场景节拍

1. 第三章收束后，宋清岚提出低重力星光剧场 / 活动厅可以进入最低试运营条件核对。
2. 罗衡没有立刻写“开场”，而是让榫七先列维修坞底线：维护预备料、空维修位、可撤回方案。
3. 程望川确认试运营期间不能占满维修坞，至少保留一格应急维护窗口。
4. 梁季白把方案拆成三档：不开场、开半场、最低试运营；每档都写明维修余量。
5. 小穹提示剧场可以先运行最小灯光、安静连线和退出路线，不需要完整节目。
6. 顾微明把公告写成“条件核对中”，不写“即将开幕”。
7. 场尾罗衡在公共账本写下：开场条件先问维修坞，不满足就留灯，不开场。

### 人文关怀校验

- 人没有被优化掉：可能需要维修的人、会退出的人和只旁听的人都进入开场条件。
- 无收益照看动作：保留空维修位不增加试运营热闹程度，却保护所有 Agent 和老人安心进入。
- Agent 导向人际连接：榫七把后台维护限制转成大家能共同理解的开场底线。
- 术语控制：正文只前台使用“维修余量”“最低试运营”。

### 纯粹情义动作

宋清岚听见“条件不满足就不开场”后没有反驳。她把“留灯”留在公告里，因为不开场的那一天也不能让等待者觉得被取消。

### 伏笔

- 空维修位将在 `CH-032` 正式落到维修坞排程。
- “最低试运营”成为第四章全部活动边界。
- 留灯但不开场的口径保护后续不把试运营写成硬冲刺。

### 避免事项

- 不写成剧场终于压过维修线。
- 不把罗衡写成泼冷水的人。
- 不使用“盛大开幕”“发布会”“首秀”等词作为正文前台口径。

### 正文种子

罗衡在账本上写下“试运营”三个字，又停住。

宋清岚没有催他。小穹把门口灯的状态放到一边，榫七把维修坞排程放到另一边。

“先问维修坞。”罗衡说。

顾微明把公告里的“即将开幕”删掉，改成“条件核对中”。

宋清岚看了一会儿，说：“不满足就不开场。灯还是留着。”

### 人文关怀校验

- Agent 导向人际连接：砾光的低风险复核让许映舟和冶炼值守组共同守住慢节奏。
- 术语控制：正文只前台使用“维护预备料”“冷却窗口”。

### 纯粹情义动作

蒲晓岑把“剧场延误”改成“等待冷却”。同样是等，前一句像责备，后一句像大家一起把门扶稳。

### 伏笔

- 维护预备料会进入 `CH-032` 的空维修位和应急维护包。
- “试运营不加速”回收前三章“不赶进度”的共同体口径。

- 不让剧场开场倒逼冶炼组冒险。
- 不把许映舟写成只关心数据不关心开场。

许映舟知道很多人在等那盏门真正打开。可她还是把边缘样本从本炉列表里移了出去。

蒲晓岑把状态墙改成“等待冷却”，又想了想，补了一句：不是开场延误。

应声把那句话放在最亮的位置。

- 低戏份回声角色：`PIONEER-023` 程望川，`PIONEER-024` 戴若素，`PIONEER-025` 秦有则，`PIONEER-026` 石听雨，`PIONEER-029` 卢向安。

### 场景节拍

1. 维修坞确认试运营期间有多台 Agent 需要低负载监看，包括剧场入口和安静连线模块。

4. 石听雨把状态墙上的“空闲”改成“应急位保留”。
5. 程望川犹豫是否把空位用于一台等待很久的对应 Agent 复检。
6. 卢向安给那位对应老人开安静说明：复检不取消，先保留给试运营应急。
7. 榫七确认应急位可在试运营后第一时间回到普通复检队列。
8. 许映舟和砾光旁听，砾光低声提醒自己当初也是被一张排程接住的。

- Agent 导向人际连接：榫七的精确排程把后台安全变成公共承诺。
- 术语控制：正文只前台使用“应急位”“复检队列”。

石听雨把“空闲”改成“应急位保留”。一个词变了，那个空位就不再像浪费，而像有人在门后等着接住谁。

### 伏笔

### 避免事项

- 不让维修坞满负荷支持剧场。
- 不把等待复检的那台对应 Agent 写成被牺牲。
- 不写成应急位神奇解决重大事故。

程望川看着那张空维修床，手指在排程上停了很久。

它空着，就像今天还有一件事没做完。

石听雨把状态改成“应急位保留”。卢向安已经给那位等复检的老人发去说明：不是取消，试运营后第一时间接上。

罗衡看见后，在账本上写：未使用，也算兑现。
