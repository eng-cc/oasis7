# 《绿洲 2076》第三卷第二章章节卡

## 范围

- 卷次：第三卷。
- 章节：第三卷第二章 / 全书第十一章。
- 场次：`CH-087` 到 `CH-094`。
- 时间线：`TL-087` 到 `TL-094`。
- 章节标题：冷凝盘和霉斑样本。
- 阶段目标：水雾、冷凝和散热窗口进入低规格试运行；第一滴水和第一处污染风险同时被看见。

## 章节任务句

本章要让温室从“条件核对”推进到“可观测试运行”：水雾收集膜展开，冷凝盘出现第一滴水，但光照会暂停、霉斑样本会被保留、隔离托盘先空着，维修坞应急余量不会被温室借走；真空、低重力、带电尘埃和日照 / 阴影热差要在膜的固定、清洁和散热动作中产生实际限制；卷尾只能承认冷凝和霉斑并存，不写成功、可饮用、稳定供水或生活循环成熟。

## 禁区

- 不写水路成功、稳定供水、可饮用、温室开放、播种、发芽、丰收、生态闭环或食物自给。
- 不把第一滴水写成胜利事件、宣传素材、对外标题或设施成熟证明。
- 不把霉斑 / 污染写成羞耻、责备、责任归属、灾难惩罚或照看排名。
- 不让温室抢维修坞应急余量，也不把罗衡的拒绝写成冷酷或资源竞争。
- 不把隔离托盘写成惩罚区；它是可暂停和可复核的边界。
- 不补完第二卷铅笔条款，不恢复程望川 / 回砂旧关系、旧资产、旧承诺或私人习惯。

## 章节卡

### CH-087 / TL-087: 水雾收集膜展开

- 前台动作：温室组展开第一片水雾收集膜；舱外真空、低重力漂移与日照 / 阴影热差使固定点必须分段确认，测试低功率收集和回流路径。
- 关联人物：林问秋、尺素、罗衡、小穹。
- 关联物件：水雾收集膜、低功率回流路径、条件核对页。
- 边界状态：水路只进入试运行，不承诺稳定供水。
- 关系推进：共同体把“可以试一下”写成小窗口，而不是写成开始养起来。
- 禁重复：不写播种预备或第一滴水预告。

### CH-088 / TL-088: 冷凝盘出现第一滴水

- 前台动作：冷凝盘出现第一滴水，周砚屏和应声把公共状态改成“可观测 / 不可饮用 / 待复验”。
- 关联人物：周砚屏、应声、关棠。
- 关联物件：冷凝盘、第一滴水、可观测提示。
- 边界状态：第一滴水可被看见，但不可饮用、不可庆祝、不可当作成功。
- 关系推进：系统学会把好消息也压在复验边界里，不替人急着高兴。
- 禁重复：不写成功提示或欢呼。

### CH-089 / TL-089: 光照排程暂停一次

- 前台动作：光照排程因散热余量不足暂停一轮；周砚屏不再重复改写同类提示，只把暂停和下一轮复看标在散热余量旁。
- 关联人物：周砚屏、罗衡、榫七。
- 关联物件：光照排程、散热余量条、暂停提示。
- 边界状态：暂停不是故障，也不是温室坏了。
- 关系推进：共同体把不推进也写成照看的一部分。
- 禁重复：不写成事故警报或资源抢夺。

### CH-090 / TL-090: 霉斑样本片

- 前台动作：温室边缘出现第一片疑似霉斑，陈照野和留帧把样本片留存。
- 关联人物：陈照野、留帧、庄可闻。
- 关联物件：霉斑样本片、样本夹、低亮度记录图。
- 边界状态：霉斑不被剪成失败，也不被藏到后台。
- 关系推进：共同体允许生活系统把麻烦也留在记录里。
- 禁重复：不写脏、不写责任人、不写污染羞耻。

### CH-091 / TL-091: 隔离托盘空置

- 前台动作：林问秋和尺素设立隔离托盘，但托盘先保持空置。
- 关联人物：林问秋、尺素、盛小满。
- 关联物件：隔离托盘、空置标签、铅笔条件格。
- 边界状态：隔离托盘是可暂停边界，不是惩罚区或失败区。
- 关系推进：共同体先准备接住问题，而不是急着把问题放进去。
- 禁重复：不让隔离动作替代责任归属。

### CH-092 / TL-092: 水路不抢维修坞

- 前台动作：罗衡拒绝把维修坞应急余量借给温室加速复验，只给出下一轮低功率窗口。
- 关联人物：罗衡、榫七、许映舟。
- 关联物件：维修坞应急余量、温室复验排程、低功率窗口条。
- 边界状态：温室不能因为“生活愿望”就挤掉已有维修承诺。
- 关系推进：拒绝被写成保护边界，而不是否定温室。
- 禁重复：不写成资源争吵或谁更重要。

### CH-093 / TL-093: 污染不是羞耻

- 前台动作：蒲晓岑把污染提示改成“需隔离复核”，不写脏、不写责任人、不生成照看排名。
- 关联人物：蒲晓岑、周砚屏、应声。
- 关联物件：污染提示、隔离复核标签、样本片记录。
- 边界状态：污染是生活系统的复核对象，不是人的错。
- 关系推进：共同体把“出问题”从责备语言里拿出来。
- 禁重复：不写照看人资格、扣分或责任榜。

### CH-094 / TL-094: 冷凝和霉斑并存

- 前台动作：第二章收束时，冷凝盘有可观测水痕，霉斑样本也被保留。
- 关联人物：林问秋、陈照野、周砚屏、罗衡。
- 关联物件：冷凝盘水痕、霉斑样本片、散热余量条、空隔离托盘。
- 边界状态：有水痕不等于成功，有霉斑不等于失败；两者都进入下一轮复核。
- 关系推进：共同体承认生活系统会同时长出希望和麻烦。
- 禁重复：不写章级胜利，不打开种子袋。
