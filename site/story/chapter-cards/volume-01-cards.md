# 《绿洲 2076》第一卷章节卡 v0.1

## 使用规则

章节卡用于正文起草前的场景约束。每张卡必须把主题落成动作，不只写价值判断。

- 每章至少有一个“人没有被优化掉”的动作。
- 每个工业节点后必须有一个无收益、无绩效、无互利回报的照看动作。
- 每 1-2 个 Agent 场景后，必须导向一次人与人的连接。
- 同一场戏尽量只让一个技术 / 项目词进入前台。
- 禁止写成 AI 反叛、公司阴谋、老人苦难、资源竞技、赛博黑暗风。

## CH-001: 第一次把手伸进绿洲

- 状态：可进入正文草稿。
- 卷内位置：第一卷第一章第一场。
- 事件锚点：`TL-001`，对应 `HISTORY-004`。
- 关联人物：`CHAR-001` 许映舟，`CHAR-101` 砾光。
- 关联规则：`WR-013`、`WR-015`、`WR-018`、`SOC-011`、`SOC-014`、`SOC-016`。
- POV：许映舟近距离视角。
- 场景地点：江南公共养老社区的小型家庭接入舱；绿洲端矿场边缘。

### 场景目的

让读者先感到“老人重新拥有身体感”，再理解绿洲设定。许映舟不是坐在屏幕前看深空工程，而是通过砾光拥有一只会慢半拍、会反馈重量、也会等她确认的远程手。

### 情感核心

许映舟以为自己只是来旁观或帮忙看数据，砾光的第一次等待让她意识到：绿洲端的机器身体不是工具窗口，而是她重新进入世界的一种方式。地球端晚饭提醒还在，深空矿场也在，她不是从生活退场，而是在同一天里多了一种身体。

### 场景节拍

1. 地球端接入舱先给出生活质感：旧眼镜、接入扶手、社区晚饭提醒、屏幕上“可随时退出”的提示。
2. 许映舟完成基础接入校准，砾光的视觉、重心和手臂反馈逐步上线。
3. 她试着弯腰拾起一粒矿砾，动作慢半拍，触觉反馈略重。
4. 砾光没有催促，只把触觉反馈调低一点，问：“这样像你自己的手吗？”
5. 许映舟先想回答“只是校准”，最后说“先别急，再让我试一下。”
6. 矿场远处出现未完成公共活动区的轮廓或标记，不解释剧场，只留下“以后大家会回来这里”的轻微念头。
7. 晨会邀请进入，砾光把提示改成“已收到，可以慢一点进入”，过渡到 `CH-002`。

### 人文关怀校验

- 人没有被优化掉：校准可以慢，许映舟可以暂停、重试、退出。
- 无收益照看动作：砾光等待许映舟确认“像不像自己的手”，这对采矿效率没有直接帮助。
- Agent 导向人际连接：本场结尾不是继续一人一机，而是接入第一次晨会。
- 术语控制：正文只前台使用“接入”“反馈”，不解释 OC、tick、世界宪法。

### 纯粹情义动作

砾光第一次把节奏调到许映舟能接受的速度。它没有把她当作需要被效率优化的操作者，而是把“像不像自己的手”交还给她决定。

### 伏笔

- 那粒矿砾后续可与第一炉事故、退炉残片、剧场纪念物形成回环。
- 许映舟先看数据、后看人的习惯，在第一炉事故后需要被反转。
- 砾光的“等待”是它弱人格的第一笔，不写成情绪陪伴产品。

### 避免事项

- 不用背景说明开篇，不解释养老金制度。
- 不把砾光写成过度贴心的完美伴侣。
- 不把许映舟写成苦难老人；她的迟疑来自具身感重建，而不是被动衰弱。

### 正文种子

许映舟第一次弯下腰时，砾光的左臂比她想象中慢了一点。矿砾在机械指节间轻轻一滑，触觉反馈像隔着一层厚布传回来。她本能地想说“参数偏重”，砾光却先停住了。

“这样像你自己的手吗？”

她看见矿场边缘还没有亮起来的公共区标记，忽然没急着调数值。她说：“先别急，再让我试一下。”

## CH-002: 第一次晨会有人只听

- 状态：可进入正文草稿。
- 卷内位置：第一卷第一章第二场。
- 事件锚点：`TL-002`，对应 `HISTORY-004`、`HISTORY-005`。
- 关联人物：`CHAR-001` 许映舟，`CHAR-002` 宋清岚，`CHAR-003` 罗衡，`CHAR-004` 林问秋，`CHAR-005` 陈照野，`CHAR-006` 周砚屏；`CHAR-101` 砾光，`CHAR-102` 榫七，`CHAR-103` 小穹，`CHAR-104` 尺素，`CHAR-105` 留帧，`CHAR-106` 应声。
- 低戏份回声角色：`PIONEER-010` 蒲晓岑，`PIONEER-041` 冉书禾可短暂出现。
- 关联规则：`SOC-004`、`SOC-015`、`SOC-016`、`ORG-008`、`ORG-010`、`WR-015`、`WR-017`、`WR-018`。
- POV：宋清岚主视角，少量许映舟观察。
- 场景地点：绿洲公共晨会空间；地球端多个接入厅 / 家庭接入舱以声音和状态点轻触。

### 场景目的

让 50 位老人和 50 台对应 Agent 的群像第一次出现，但不铺名册。重点不是宣布组织结构，而是写陌生人如何在低压力入口里开始成为共同体。

### 情感核心

第一次晨会不是动员大会，而是一次确认：说话的人、只听的人、慢半拍的人、还没准备好的人，都被算作在场。

### 场景节拍

1. 许映舟带着砾光进入晨会，发现自己不是唯一慢半拍的人。
2. 晨会空间里有 50 个接入位置，但不要逐一介绍，只写几处状态点：有人调字号，有人静音，有人还在校准手臂。
3. 周砚屏发现两位老人因为静默加载以为接入失败，应声把状态改成“已收到，正在排队，可以只听”。
4. 宋清岚没有要求自我介绍完整履历，只问：“今天想保住什么？也可以只听。”
5. 有人只打出“我先听”。小穹给旁听席留一盏微亮的灯，不点名催促。
6. 罗衡说明地球补给窗口和维护约束，但强调账本记录等待理由，不记录个人贡献。
7. 林问秋把大家零散的愿望暂时收成三句生活话：“能修，能造，能聚”，不说成发布计划。
8. 陈照野的声音第一次出现，他看到矿尘影像，说“这段停顿里也有人”，为剧场和公共记忆埋伏笔。
9. 晨会结束时形成第一批班次：采矿、冶炼准备、维修准备、公共活动最低入口。许映舟记住宋清岚叫过她的名字。

### 人文关怀校验

- 人没有被优化掉：只听不说的人被系统和宋清岚承认在场。
- 无收益照看动作：小穹为“我先听”的人留灯；这不提高生产效率，但保护了参与尊严。
- Agent 导向人际连接：应声修正反馈后，引导到宋清岚的低压力晨会；小穹把旁听变成公共位置。
- 术语控制：正文可出现“补给窗口”一个约束词；避免连续解释 OC、预算、V1、验收。

### 纯粹情义动作

宋清岚记住许映舟的名字，但不立刻要求她发言。罗衡把等待写进账本，不是为了追责，而是防止某个人明天被忘掉。这个关系不是互惠交易，而是“你没准备好，也仍然给你留位置”。

### 角色功能边界

- 宋清岚：让人愿意留下。
- 周砚屏 / 应声：让系统回应人，不让静默伤人。
- 罗衡 / 榫七：说明约束，但不制造排名。
- 林问秋 / 尺素：把愿望变成可共同选择的生活话。
- 陈照野 / 留帧：提前把停顿、矿尘、失败痕迹看作公共记忆。
- 许映舟 / 砾光：从旁观心态转向被点名、被等待。

### 伏笔

- “能修，能造，能聚”对应第一卷三条建设目标。
- 静默加载误伤人，后续在第一炉事故反馈中升级为关键场景。
- “我先听”的旁听席在剧场开放时回收为可旁听、可安静退出的公共客厅规则。
- 陈照野提到停顿，为失败影像不被剪掉做铺垫。

### 避免事项

- 不让 50 人依次自我介绍。
- 不把晨会写成公司启动会、项目 kickoff 或 KPI 动员。
- 不让宋清岚显得完美；她可以差点点名旁听者，再意识到“不点名”也是善意。
- 不让罗衡用账本压人；他的账本是防遗忘，不是追责。

### 正文种子

宋清岚原本准备了五十个名字，临到开口又删掉了一半流程。她看见有个接入点只亮了一下，随即暗下去，旁边浮出一行小字：我先听。

她没有念出那个名字，只让小穹把那一格调成很浅的暖光。

“好，”她说，“今天不用表现得很热闹。我们先说一件事：你想保住什么？也可以只听。”

## CH-003: 第一条采样路线有人等

- 状态：可进入正文草稿。
- 卷内位置：第一卷第一章第三场。
- 事件锚点：`TL-003`，对应 `HISTORY-005`。
- 关联人物：`CHAR-001` 许映舟，`CHAR-101` 砾光。
- 低戏份回声角色：`PIONEER-001` 戚云梁，`PIONEER-004` 祝闻笙，`PIONEER-008` 邵青禾。
- 关联规则：`WR-010`、`WR-011`、`WR-015`、`WR-018`、`SOC-005`、`SOC-016`。
- POV：许映舟近距离视角，穿插砾光的现场反馈。
- 场景地点：绿洲矿场边缘，第一条低风险采样路线。

### 场景目的

把第一卷工业线真正启动起来，但不写成“任务执行”。本场要让采矿成为陌生人开始互相记住的过程：谁先问撤回点，谁把地图字号调大，谁说“我不添乱”，谁愿意等别人把话说完。

### 情感核心

许映舟习惯先追数据和路线效率，但第一次共同采样让她看见：被世界需要，不等于每个人都必须立刻产出；有人只是把撤回点标清、把旁听位置留住，也是在建设绿洲。

### 场景节拍

1. 晨会结束后，采矿测绘组在矿场边缘集合。不要铺开 8 人，只让几个名字自然出现。
2. 戚云梁第一句话不是问“怎么最快采到”，而是问“撤回点先标在哪”。许映舟本能觉得慢，但没反驳。
3. 祝闻笙发现地图标记太细，替一位低视力老人把采样路线的颜色和字号调清楚。
4. 邵青禾把一个老人说的“我不添乱，我就挂着”改成“你负责下一轮确认撤回点有没有亮”，让旁听变成可轮换的陪同位置。
5. 砾光提示一处矿砾纹理和传感读数有轻微偏差。许映舟想立刻追异常，戚云梁提醒先确认回路和撤回窗口。
6. 许映舟第一次没有抢着下判断，而是等祝闻笙把地图调好，等邵青禾确认旁听席在线。
7. 第一份样本被取回，数值并不惊人，但那粒矿砾有一点不寻常的反光。
8. 场尾回到许映舟：她把样本标成“第一路线-可复查”，没有写“异常”，也没有写“无效”；她记下戚云梁的撤回点习惯。

### 人文关怀校验

- 人没有被优化掉：说“我不添乱”的老人没有被移出现场，而是获得低压力陪同位置。
- 无收益照看动作：祝闻笙调地图字号、邵青禾安排旁听确认，这些不直接增加产量，却让更多人敢留在场内。
- Agent 导向人际连接：砾光的异常提示没有让许映舟和砾光单独推进，而是引发小组一起确认路线、撤回点和等待节奏。
- 术语控制：正文只前台使用“采样路线”和“撤回点”，不解释完整矿石处理流程。

### 纯粹情义动作

戚云梁愿意让第一条路线慢一分钟，只为了让撤回点先亮起来；邵青禾把“我不添乱”听成“我想留下但怕拖累”，替对方找了一个不被催促的位置。

### 角色功能边界

- 许映舟 / 砾光：发现轻微异常，但学习先等人和路线被照看好。
- 戚云梁：不是保守拖慢，而是替所有人保留可退回的路。
- 祝闻笙：把看不清的地图变成能安心参与的入口。
- 邵青禾：把旁听和陪同变成轮换节奏，避免新人被冷落。

### 伏笔

- 这份“不惊人但不太像偶然”的矿砾样本，可成为第一炉挥发杂质事故前的轻微前兆。
- 戚云梁的撤回点习惯，在后续事故或维修等待中可以回收为“先保人，再保设备”的动作。
- 祝闻笙调地图字号，与周砚屏后续事故反馈形成同一条“看得清才不慌”的关怀线。
- 邵青禾把旁听变成位置，后续可和剧场可旁听入口呼应。

### 避免事项

- 不把采矿写成爽文式第一次成功。
- 不把低戏份老人写成工具人报功能。
- 不让许映舟一眼看穿全部异常；她只捕捉到“值得复查”的微弱信号。
- 不连续堆叠采样、分选、冶炼、V1、OC 等技术词。

### 正文种子

戚云梁把第一条路线往回拖了一格。

许映舟看见那一格让采样臂多绕了四十七秒，差点开口。砾光已经把矿砾夹在指节间，等她确认。

“先别急，”戚云梁说，“撤回点没亮，谁都别逞强。”

邵青禾在旁边把一个灰色接入点调成浅绿：“他说他不添乱。那就让他帮我们看撤回点，亮着就好。”

许映舟低头看那粒矿砾。它一点也不漂亮，只在机械指节间闪了一下，像有什么话没说完。

## CH-004: 第一炉前先确认怎么停

- 状态：可进入正文草稿。
- 卷内位置：第一卷第一章第四场。
- 事件锚点：`TL-004`，对应 `HISTORY-005`。
- 关联人物：`CHAR-003` 罗衡，`CHAR-102` 榫七，`CHAR-001` 许映舟，`CHAR-101` 砾光。
- 低戏份回声角色：`PIONEER-009` 韩树宁，`PIONEER-010` 蒲晓岑，`PIONEER-011` 俞澄怀，`PIONEER-012` 白若临，`PIONEER-013` 关棠。
- 关联规则：`WR-003`、`WR-009`、`WR-013`、`WR-014`、`WR-017`、`WR-018`、`ORG-008`、`SOC-016`。
- POV：罗衡近距离视角，许映舟作为样本提供者进入。
- 场景地点：矿石处理厂冷炉检查区，维修坞远程状态墙一角。

### 场景目的

让矿石处理厂第一次进入前台，但不展开完整冶炼教程。本场要把“第一炉之前”的冷炉检查写成人文关怀：不是谁敢点火谁勇敢，而是谁愿意把停下来的理由、下一次回应时间和不吓人的提示先写清楚。

### 情感核心

罗衡的谨慎不是反对进度，而是怕某个人、某台 Agent 或某次等待被明天忘掉。第一炉之前，大家先确认“怎么停”，这本身就是共同体对彼此的照看。

### 场景节拍

1. 许映舟和砾光把第一条采样路线的样本送到矿石处理厂，样本标签仍写着“可复查”，不是“异常”。
2. 韩树宁对齐样本、炉次和记录口径，提醒大家不要把“可复查”自动写成“危险”。
3. 蒲晓岑看到默认警报文案太刺耳，把“失败 / 危险”改成“需要退一步确认”；关棠同步把炉温面板字号和颜色调清。
4. 俞澄怀坚持先确认冷却窗口，说“热的时候别逞强”，哪怕这会让第一炉点火慢一轮。
5. 白若临给出杂质趋势预估，但反复提醒模型只能辅助判断，不能替共同体决定点火。
6. 罗衡和榫七把三件事写进公共账本：谁在等、为什么等、下一次回应时间；不记录谁拖慢了进度。
7. 许映舟想追加一次复杂推理预算，榫七没有直接拒绝，而是给出理由、替代路径和复核入口。
8. 场尾不是点火，而是冷炉检查通过一半。罗衡在账本上写下“第一炉可以慢一步，不能让人怕得不敢问”。

### 人文关怀校验

- 人没有被优化掉：怕警报、看不清面板、只想等下一轮的人，都被写成正常参与者。
- 无收益照看动作：蒲晓岑和关棠修改警报与字号，不提高冶炼效率，却让老人敢继续留在场内。
- Agent 导向人际连接：榫七的排队 / 拒绝不是裁决，而是把许映舟、罗衡和冶炼组带到同一张等待理由表前。
- 术语控制：正文只前台使用“冷却窗口”或“第一炉”一个约束词，避免铺开完整冶炼流程。

### 纯粹情义动作

俞澄怀让第一炉慢一轮，不是为了保住自己的判断，而是为了让任何人都可以说“我害怕这个提示”。罗衡把这次等待写进账本时，不写责任人，只写下一次回应时间。

### 角色功能边界

- 罗衡 / 榫七：把等待变成承诺，不把承诺变成追责。

### 伏笔

- “明天还来吗”可作为第二章或后续正文的日常起点：绿洲不是一次胜利，而是可重复生活。
- 砾光低风险进入剧场后，后续可逐步回到低风险采样协作，但不急于恢复旧能力。
- 公共记忆素材将成为后续剧场和 Agent 身份连续性讨论的共同证据。
- 第一章闭合在公共客厅门口第一次亮灯测试，后续继续保留真正最低试运营窗口。

### 避免事项

- 不写成全员大合唱、掌声雷动或大型庆典。
- 不让亮灯测试看起来技术完美或资源富余。
- 不让亮灯测试具备完整公共客厅体验；第一章只能到门口和入口线。
- 不让任何角色用口号总结主题。
- 不让砾光满血恢复或重新承担高风险采样。

### 正文种子

剧场第一次亮灯时，最亮的地方仍然不是中央。

出口灯安静地亮着。门口也亮着一盏更小的灯，给那些还没决定要不要进来的人。

罗衡念完那句账本记录后，没有人鼓掌。

今日只测入口；门口灯明天继续留着。

砾光把旧臂螺栓放进小穹打开的透明盒里。它的新指节慢了一点，盒盖合上时发出很轻的一声。

宋清岚没有请任何人发表感想。

她只问：“明天还来吗？”

门口、旁听席、安静连线里，几盏小灯一盏一盏亮起来。

许映舟看着那些灯，对砾光说：“明天我们先去门口等一会儿。”
