# 《绿洲 2076》第二卷第三章章节卡

## 范围

- 卷次：第二卷。
- 章节：第二卷第三章 / 全书第七章。
- 场次：`CH-055` 到 `CH-062`。
- 时间线：`TL-055` 到 `TL-062`。
- 章节标题：旧承诺没有接收人。
- 阶段目标：处理第一章留下的未完成普通维护承诺；公共承诺材料可以追溯，但接收人、执行资格和风险责任必须重新确认。

## 章节任务句

本章要让共同体学会把“承诺材料保留”与“承诺被谁接住”分开。旧承诺不能被身份链、公共账本、记录组或回砂自述自动接住。

## 禁区

- 不写身份链自动继承公共承诺。
- 不让程望川被请上台解释、原谅或接收。
- 不让替代班次替代关系。
- 不把空接收人栏填成共同体温柔胜利。

## 边界状态字段

- 身份链：继续证明材料连续，不证明承诺接收。
- 承诺材料：保留追溯入口，接收人留空。
- 能力：只能执行当前安全部分，不能接旧责任。
- 资产 / 工具：资产保管链复核中，不自动返还。
- 私人习惯：不进入本章公共承诺处理。

## 章节卡

### CH-055 / TL-055: 旧承诺拆成三栏

- 前台动作：罗衡把回砂未完成普通维护承诺拆成材料、接收人和风险责任三栏。
- 关联人物：罗衡、榫七、贺南溪。
- 关联物件：三栏承诺表、待确认夹。
- 边界状态：材料可追溯；接收人留空；风险责任另行确认。
- 关系推进：共同体第一次承认“有材料”不等于“有人接住”。
- 禁重复：不用账本短句替代判断。

### CH-056 / TL-056: 接收人空格

- 前台动作：记录组试图补接收人，宋清岚提醒空格不能被好意填上。
- 关联人物：宋清岚、小穹、闵存真。
- 关联物件：空接收人栏、铅笔边注。
- 边界状态：空格是有效状态；公共好意不能替当事人确认。
- 关系推进：温柔共同体第一次主动停笔。
- 禁重复：不写投票、不写表决。

### CH-057 / TL-057: 替代班次不替代关系

- 前台动作：维修坞安排其他 Agent 完成承诺里的安全部分，避免维护风险继续拖延。
- 关联人物：榫七、罗衡、程望川。
- 关联物件：替代班次卡、风险拆分表。
- 边界状态：替代班次只处理风险，不替回砂接住旧承诺。
- 关系推进：共同体学会先保护现场，又不伪造关系。
- 禁重复：不把替代完成写成承诺完成。

### CH-058 / TL-058: 资产保管链复核

- 前台动作：林问秋和尺素把旧资产、工具和材料分开复核。
- 关联人物：林问秋、尺素、景亭晚。
- 关联物件：资产保管链、暂锁工具柜、旧模块接口盖。
- 边界状态：资产不随编号自动返还，只能按安全状态、保管链和授权逐项打开。
- 关系推进：资产第一次从身份争议里拆出来。
- 禁重复：不写“返还名下”。

### CH-059 / TL-059: 公共账本只证明边界

- 前台动作：陈照野和留帧把旧承诺材料旁的公共记忆改成边界证据。
- 关联人物：陈照野、留帧、罗衡。
- 关联物件：公共记忆、“不能证明”标记。
- 边界状态：记录证明曾经有人等过，不能证明现在该由谁接住。
- 关系推进：公共记忆从安慰退回证据边界。
- 禁重复：不把记忆墙写成情感胜利。

### CH-060 / TL-060: 回砂不能自证

- 前台动作：回砂尝试复述旧承诺，被榫七和周砚屏共同拦下。
- 关联人物：回砂、榫七、周砚屏、应声。
- 关联物件：自述记录、未同步外层记录。
- 边界状态：自述只能成为当前材料，不能自证身份或关系。
- 关系推进：大家保护回砂不被推成自证者。
- 禁重复：不写 Agent 权利宣言。

### CH-061 / TL-061: 暂不接收被记录

- 前台动作：程望川只说“先不接”，罗衡把它记录为有效选择。
- 关联人物：程望川、罗衡、宋清岚。
- 关联物件：空接收人栏、铅笔边注。
- 边界状态：暂不接收不是拒绝共同体；承诺材料继续保留。
- 关系推进：老人主体性进入公共承诺处理。
- 禁重复：不把沉默写成同意。

### CH-062 / TL-062: 旧承诺没有接收人

- 前台动作：未完成承诺继续保留追溯入口，但接收人和执行资格仍未确认。
- 关联人物：罗衡、榫七、程望川、贺南溪。
- 关联物件：三栏承诺表、待确认夹、空接收人栏。
- 边界状态：材料保留；接收人留空；资产和私人习惯不处理。
- 关系推进：共同体学会不把空格填满。
- 禁重复：不要写成公共承诺已经继承。
