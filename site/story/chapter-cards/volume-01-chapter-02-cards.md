# 《绿洲 2076》第一卷第二章章节卡 v0.1

## 使用规则

本文件接续 `volume-01-cards.md` 的 `CH-001` 到 `CH-012`。第二章不重做第一章的接入、事故和亮灯测试，而是推进第一卷第二阶段：稳定冶炼、基础零件自产、普通维护件进入维修坞，并继续守住低重力星光剧场 / 活动厅的卷末最低试运营窗口。

- 本章可以出现“自给雏形”，但不能写成完整工业独立。
- 第二炉可以成功，但只能是小批量、可复验、低等级可用材料，不是工业大捷。
- 剧场只能继续准备和保留窗口，不正式最低试运营。
- 每场仍需有一个无收益照看动作，让工业推进落回人和关系。
- 每场正文最多让 1-2 个技术词进入前台。

## 第二章总目标：第二天也有人来

第二章从第一章“明天还来吗”的回应开始。第一章证明大家愿意再见；第二章要证明这个“再见”不是一次性情绪，而能变成第二天的班次、第二炉的复查、第二批零件、普通维护和被继续保留的剧场窗口。

章内工业目标：

1. 砾光以低风险状态回到采样线，不恢复高风险能力。
2. 第二炉通过改排气、改提示、改等待口径，产出第一批小批量可用金属粉 / 低等级锭料。
3. 基础零件厂用自家材料打印第一批普通结构件。
4. Agent 维修坞用自家材料完成一次普通维护件更换。

章内情感目标：

1. 让“明天还来吗”变成真实班次，而不是章末漂亮句子。
2. 让砾光的低风险回归不被写成英雄归来，而是共同体愿意慢慢等。
3. 让自家金属进入剧场的一枚小支架，但不提前消费卷末剧场正式试运营。
4. 让低戏份老人继续短暂反复出现，形成共同生活纹理。

## CH-013: 第二天先去门口等一会儿

- 状态：可进入正文草稿。
- 卷内位置：第一卷第二章第一场。
- 事件锚点：`TL-013`，对应 `HISTORY-008`、`HISTORY-007`。
- 关联人物：`CHAR-001` 许映舟，`CHAR-101` 砾光，`CHAR-002` 宋清岚，`CHAR-103` 小穹。
- 低戏份回声角色：`PIONEER-030` 梁明玥，`PIONEER-036` 孟行远，`PIONEER-041` 冉书禾。
- 关联规则：`SOC-006`、`SOC-015`、`SOC-016`、`WR-013`、`WR-014`、`WR-018`。
- POV：许映舟近距离视角。
- 场景地点：低重力星光剧场 / 活动厅门口；安静连线入口；次日采样班次板。

### 场景目的

把第一章末尾的“明天还来吗”落成第二天的具体动作。许映舟和砾光没有直接回采矿前线，也没有把剧场当成正式开放空间，而是先去门口等一会儿，确认昨天停在门口的人、只听不说的人和维修后的砾光都还被算作在场。

### 情感核心

真正难的不是第一晚几盏灯亮起来，而是第二天仍有人愿意按时回来。许映舟发现，绿洲的生活不是靠一次感动维持，而是靠下一次回应时间、门口灯、低风险班次和不催促的等待慢慢接上。

### 场景节拍

1. 地球端早晨，许映舟接入砾光。砾光右臂仍是低风险状态，面板明确“不进入高风险采样”。
2. 她没有先打开采矿路线，而是按昨晚约定去剧场门口等一会儿。
3. 小穹保留门口灯，但提示“仅门口预演，不开放正式试运营”；梁明玥把公告里的“欢迎参加”改成“可以只来确认灯还在”。
4. 孟行远确认安静连线稳定，昨天只听声音的人上线后没有被点名。
5. 冉书禾把公共账本的短句从昨晚记录改成今天的班次提示：门口灯保留，采样班次低风险开放。
6. 砾光问许映舟是否进入采样线。许映舟先看见门口灯亮着，才说：“去吧，今天慢一点。”
7. 场尾过渡到采矿班次：第二章不是从“胜利后继续庆祝”开始，而是从一个能被重复的早晨开始。

### 人文关怀校验

- 人没有被优化掉：昨天只停在门口的人、只听声音的人，第二天仍被系统和公共账本记得。
- 无收益照看动作：保留门口灯、改公告、更新班次提示都不直接提高产量，却让重逢不是一次性热闹。
- Agent 导向人际连接：小穹和砾光没有替代老人关系，而是把许映舟带回宋清岚维护的公共入口，再带向采样班次。
- 术语控制：正文只前台使用“低风险状态”“班次”两个词。

### 纯粹情义动作

许映舟遵守昨晚那句“先去门口等一会儿”。她不是为了完成任务，而是为了让没有进场的人知道：有人真的记得这个约定。

### 伏笔

- 门口灯将成为卷末最低试运营时的回收物。
- “低风险班次开放”引出砾光回采样线，但不恢复旧能力。
- 冉书禾的账本可读性会在后续第二炉和打印队列中继续出现。

### 避免事项

- 不写成剧场正式开放。
- 不让砾光突然恢复高风险采样。
- 不把第二天写成情绪余韵散文，必须接回采样和冶炼建设线。

### 正文种子

第二天，门口那盏小灯还亮着。

许映舟没有立刻去采样线。砾光的新右臂垂在身侧，状态栏安静地写着：低风险协作开放。

小穹把门口提示调低了一点：可以只来确认灯还在。

许映舟站了一会儿。安静连线里，有一个昨天只听声音的人亮了一下，又很快暗回去。

她没有叫对方名字，只对砾光说：“走吧。今天慢一点。”

## CH-014: 低风险路线不抢回旧速度

- 状态：可进入正文草稿。
- 卷内位置：第一卷第二章第二场。
- 事件锚点：`TL-014`，对应 `HISTORY-007`。
- 关联人物：`CHAR-001` 许映舟，`CHAR-101` 砾光。
- 低戏份回声角色：`PIONEER-001` 戚云梁，`PIONEER-002` 唐见微，`PIONEER-004` 祝闻笙，`PIONEER-008` 邵青禾。
- 关联规则：`WR-010`、`WR-011`、`WR-014`、`WR-018`、`SOC-005`、`SOC-016`。
- POV：砾光贴近视角，许映舟为远程操作者。
- 场景地点：矿场低风险复采路线；采样撤回点；第二炉样本暂存箱。

### 场景目的

让砾光回到采样线，但只做低风险复采。本场不能写成“受伤伙伴英雄归来”，而要写成共同体接受慢速度：撤回点更密、样本更少、动作更慢，但每一步都能被复查，为第二炉稳定冶炼提供可信样本。

### 情感核心

许映舟想确认砾光“还能不能像以前一样”，戚云梁和邵青禾让她看见：新的共同体习惯不是抢回旧速度，而是让受损后的伙伴有一条不必逞强的路。

### 场景节拍

1. 戚云梁把第二条路线切成更短的小段，每段都有撤回点。
2. 许映舟看到路线效率下降，差点想要求恢复第一章前的采样节奏。
3. 砾光主动提示右臂低负载限制，只建议采集轻样本，不建议深入矿缝。
4. 祝闻笙把地图上的“限制区域”改成“稍后再来”，避免让砾光和许映舟觉得自己被判定为不可用。
5. 唐见微盯住边缘样本，提醒大家第二炉需要看挥发杂质分布，不能只拿最漂亮的矿石。
6. 邵青禾把旁听者安排为“撤回点确认人”，让不能上场的人继续参与。
7. 场尾采样箱没有装满，只装了三类清楚标记的样本：稳定样本、边缘样本、待复查样本。

### 人文关怀校验

- 人没有被优化掉：砾光的慢、许映舟的犹豫、旁听者的确认位置都被纳入路线。
- 无收益照看动作：祝闻笙把“限制区域”改成“稍后再来”，保护被限制者的尊严。
- Agent 导向人际连接：砾光的限制提示引出采矿组共同调整路线，而不是让许映舟独自承受恢复焦虑。
- 术语控制：正文只前台使用“撤回点”“低风险复采”。

### 纯粹情义动作

戚云梁宁愿少采一箱，也不让砾光证明自己“还和以前一样”。这不是效率判断，而是对一个受损伙伴的照看。

### 伏笔

- 三类样本将进入 `CH-015` 的第二炉前检查。
- “稍后再来”将成为后续绿洲处理未完成事项的温柔口径。
- 唐见微对边缘样本的坚持，会帮助第二炉避免只追好看数据。

### 避免事项

- 不让砾光逞强或被写成不服输。
- 不让采矿组为了第二炉进度牺牲安全。
- 不把低风险路线写得过度悲伤；它是新的工作节奏。

### 正文种子

戚云梁把路线切短以后，采样箱空了一半。

许映舟盯着那片空位，手指动了一下。砾光先开口：“右臂低负载，不建议深入矿缝。”

祝闻笙把地图上那块灰色区域重新命名。她删掉“限制”，改成“稍后再来”。

戚云梁说：“今天能回来，比装满更重要。”

许映舟慢慢松开了采样夹。

## CH-015: 第二炉先把排气说清楚

- 状态：可进入正文草稿。
- 卷内位置：第一卷第二章第三场。
- 事件锚点：`TL-015`，对应 `HISTORY-007`。
- 关联人物：`CHAR-003` 罗衡，`CHAR-102` 榫七，`CHAR-006` 周砚屏，`CHAR-106` 应声。
- 低戏份回声角色：`PIONEER-009` 韩树宁，`PIONEER-010` 蒲晓岑，`PIONEER-011` 俞澄怀，`PIONEER-012` 白若临，`PIONEER-013` 关棠。
- 关联规则：`WR-009`、`WR-014`、`WR-017`、`WR-018`、`SOC-016`。
- POV：罗衡近距离视角。
- 场景地点：矿石处理厂第二炉前检查区；公共状态墙。

### 场景目的

让第二炉不是“再试一次就成功”，而是带着第一炉留下的教训重新设置：排气、除渣、提示语、等待时间和复核入口都被改过。技术推进的重点不是炫工艺，而是共同体如何让第二次尝试不伤人。

### 情感核心

罗衡意识到，账本不仅记录谁在等，也记录大家为什么敢再试一次。第二炉的勇气不来自“这次一定成”，而来自每一步都能停、能退、能解释。

### 场景节拍

1. 韩树宁把第一炉日志、退炉残片和第二批样本对齐，不允许大家跳过失败记录。
2. 白若临给出挥发杂质趋势，强调这次只降低不确定性，不承诺成功。
3. 俞澄怀坚持排气和冷却窗口先过一轮空载检查。
4. 蒲晓岑把警报提示改成“排气复核中”，不再用刺眼失败词。
5. 关棠调状态墙字号，让远端接入厅也能看清“可以暂停”。
6. 周砚屏和应声把第二炉状态分成三行：准备、可暂停、下一次回应时间。
7. 罗衡把第二炉写入公共账本：不是补偿第一炉失败，而是一次可停下来的复查。

### 人文关怀校验

- 人没有被优化掉：害怕再试的人可以旁听，可以暂停，可以等下一次回应。
- 无收益照看动作：关棠调字号、蒲晓岑改提示、周砚屏拆状态，都是为了让等待不伤人。
- Agent 导向人际连接：榫七提供检查序列，但决定如何向大家解释，由罗衡、周砚屏和冶炼值守组共同完成。
- 术语控制：正文只前台使用“排气”“复核”。

### 纯粹情义动作

罗衡把“第二炉”旁边写上“可停”。他不是给工程留后路，而是给害怕再看一次失败的人留后路。

### 伏笔

- 第二炉的排气复核将支撑 `CH-016` 的小批量可用材料。
- 状态墙三行模板会在普通维护件更换时回收。
- “不是补偿失败”帮助正文避免把第二章写成打脸式成功。

### 避免事项

- 不把第二炉写成热血复仇。
- 不让模型或算法替共同体保证成功。
- 不堆冶炼教程，只写它如何影响等待和安全感。

### 正文种子

罗衡在“第二炉”三个字后面停了很久。

榫七已经列出排气、除渣、冷却和复核顺序。白若临的趋势图比昨天平稳，却没有人说“这次稳了”。

蒲晓岑把状态墙上的红色提示换成一行小字：排气复核中，可以暂停。

罗衡点点头，在账本里补了一句：这不是补偿昨天。是允许大家再试一次。

## CH-016: 第一盘可用金属不许大声宣布

- 状态：可进入正文草稿。
- 卷内位置：第一卷第二章第四场。
- 事件锚点：`TL-016`，对应 `HISTORY-007`。
- 关联人物：`CHAR-001` 许映舟，`CHAR-101` 砾光，`CHAR-006` 周砚屏，`CHAR-106` 应声。
- 低戏份回声角色：`PIONEER-010` 蒲晓岑，`PIONEER-011` 俞澄怀，`PIONEER-012` 白若临，`PIONEER-015` 苏亦乔，`PIONEER-041` 冉书禾。
- 关联规则：`WR-008`、`WR-009`、`WR-014`、`WR-018`、`SOC-016`。
- POV：许映舟近距离视角。
- 场景地点：矿石处理厂小批量出料区；第二炉材料暂存台。

### 场景目的

完成第二章的第一个硬工业推进：第二炉产出第一盘小批量可用金属粉 / 低等级锭料。但本场要压住胜利口径：这只是“可复验可用”，不是高纯度、不是量产、不是完整自给闭环。

### 情感核心

许映舟第一次看见绿洲从矿石里真的取出能继续使用的材料。她想为砾光高兴，也想为第一炉松一口气，但共同体选择先轻声确认、贴好标签、留给下一班继续，而不是大声宣布成功。

### 场景节拍

1. 第二炉退料声音很轻，不像第一炉那声错响。
2. 俞澄怀等冷却窗口完整结束，才允许靠近暂存台。
3. 白若临标注“低等级可用，需复验”，不允许写“稳定量产”。
4. 苏亦乔把公共说明写成一句普通话：这批材料能先做最基础的小件。
5. 周砚屏和应声把状态墙改成“第二炉小批量可用 / 待复验 / 下一班继续”，不写“成功”。
6. 许映舟让砾光用左臂轻触暂存盒，右臂仍保持低负载距离。
7. 冉书禾把材料标签字号调大，给远端接入厅的老人也能看清。
8. 场尾没有掌声，只有几个接入点亮了一下，像大家确认自己还在。

### 人文关怀校验

- 人没有被优化掉：没有要求所有人为第二炉兴奋，也允许有人只确认标签就退出。
- 无收益照看动作：苏亦乔改说明、冉书禾调字号、周砚屏压住“成功”口径，都保护了第一炉失败后的等待者。
- Agent 导向人际连接：砾光轻触材料不是展示恢复，而是让许映舟和冶炼组共同确认“昨天没有白等”。
- 术语控制：正文只前台使用“可复验”“低等级可用”。

### 纯粹情义动作

周砚屏没有把“成功”两个字挂上状态墙。她知道有人仍记得第一炉那声错响，所以先把可用材料放在一个不会刺眼的位置。

### 伏笔

- 第一盘材料将进入 `CH-017` 的普通结构件打印。
- “低等级可用”继续守住 V1 边界。
- 砾光只用左臂轻触，为旧臂手感重建留下慢节奏。

### 避免事项

- 不写成冶炼大捷或全员庆祝。
- 不写高纯度、量产、全材料自给。
- 不让砾光右臂承担动作。

### 正文种子

第二炉出料时，没有人先说成功。

暂存盒里只有一小盘暗银色粉末，边缘还混着几粒需要复验的粗颗粒。许映舟看了很久，才让砾光用左臂轻轻碰了一下盒盖。

应声把状态墙上的“成功”删掉，换成三行：小批量可用。待复验。下一班继续。

许映舟忽然觉得，这样也很好。
