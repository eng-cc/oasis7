# 《绿洲 2076》第一卷第三章章节卡 v0.1

## 使用规则

本文件接续 `volume-01-chapter-02-cards.md` 的 `CH-013` 到 `CH-020`。第三章不再证明“能不能继续”，而是证明“能不能轮换”：冶炼、打印、维修和剧场筹备不靠少数人硬撑，而能被下一班老人和对应 Agent 接住。

- 本章可以写出更稳定的基础维护能力，但仍不能写成完整工业自给。
- 工业胜利必须落到班次、休息、交接、普通维护和公共生活窗口。
- 剧场可以完成安全扶手、出口灯复验和安静连线复验，但不能正式最低试运营。
- 不把“老人多干一点”写成热血；休息、旁听和安静退出仍属于共同体。
- 每场正文最多让 1-2 个技术词进入前台。

## 第三章总目标：轮班表上也有人休息

第三章从第二章“能继续”推进到“能轮换”。第二章证明第二炉、普通支架和普通维护都能跑通一次；第三章要证明这些不是靠情绪和临时加班撑出来的，而能进入可复验、可交接、可休息的日常节奏。

章内工业目标：

1. 第三炉完成复验，确认小批量材料可以重复产出。
2. 建立基础维护材料库和第一套基础维护包。
3. Agent 维修坞用维护包完成连续两台值勤 Agent 的基础维护。
4. 剧场完成第一段安全扶手和出口灯复验，但不正式开放。

章内情感目标：

1. 让“休息”成为被写进排程的正当位置。
2. 让砾光从被照看的受损者，变成能在低风险范围内陪别人交接的伙伴。
3. 让先锋队里的回声角色和对应 Agent 继续真实参与，不变成岗位名册。
4. 让公共快乐不是抢资源，而是被持续维护的生活窗口。

## CH-021: 轮班表上先留休息格

- 状态：可进入正文草稿。
- 卷内位置：第一卷第三章第一场。
- 事件锚点：`TL-021`，对应 `HISTORY-007`。
- 关联人物：`CHAR-003` 罗衡，`CHAR-102` 榫七，`CHAR-006` 周砚屏，`CHAR-106` 应声。
- 低戏份回声角色：`PIONEER-008` 邵青禾，`PIONEER-021` 夏青岑，`PIONEER-041` 冉书禾。
- 关联规则：`WR-014`、`WR-017`、`WR-018`、`SOC-015`、`SOC-016`、`SOC-017`。
- POV：罗衡近距离视角。
- 场景地点：公共轮班表；地球端接入厅早班提示；安静连线入口。

### 场景目的

把第二章连续推进后的新问题放到前台：大家看见第二炉可用、普通维护跑通，反而想多排班、多上线、多抢进度。第三章第一场要先把“休息格”写进轮班表，确认绿洲不是靠老人透支热情维持的项目。

### 情感核心

罗衡发现最难写进账本的不是维修件，而是“今天不上线也算守约”。休息不是拖慢绿洲，而是让明天还能有人来。

### 场景节拍

1. 第二章之后，公共轮班表突然被填满，采样、冶炼、打印、维修和剧场复验都有人想多报一段。
2. 榫七提示连续在线会增加 Agent 大脑运转、模块维护和地球端老人疲劳风险，但不替大家决定。
3. 邵青禾发现有人把“我休一下”删掉，改成“我可以补位”，她把这句话还原成“休息”。
4. 周砚屏和应声把轮班表状态改成“休息已确认”，避免休息者以为自己缺席。
5. 夏青岑给下一班交接标签加一行：上一班已经做到这里，不需要接班人证明自己更努力。
6. 冉书禾把公共账本字号调大，让“休息格”不是灰掉的空白，而是可见的一格。
7. 罗衡写下本章第一条公共承诺：轮班不是排名，休息也是让明天继续的一部分。

### 人文关怀校验

- 人没有被优化掉：不上线、少上线、只旁听的人被写进轮班表，而不是变成缺席。
- 无收益照看动作：保留休息格不增加产量，却保护老人和 Agent 的长期节奏。
- Agent 导向人际连接：榫七的风险提示引出罗衡、周砚屏、邵青禾一起重写轮班表。
- 术语控制：正文只前台使用“轮班表”“休息格”。

### 纯粹情义动作

邵青禾把“我可以补位”改回“我休一下”。她不是拒绝建设，而是替那位老人承认：不用证明自己有用，也仍然是共同体的一员。

### 伏笔

- “休息已确认”将回收为第三章末尾的章结句。
- 连续在线风险为后续 Agent 维护包和普通维护排程埋线。
- 轮班不是排名，将支撑打印队列和剧场窗口的非竞争口径。

### 避免事项

- 不把老人写成过劳奉献。
- 不让休息成为被照护的软弱标签。
- 不写成效率制度宣讲；必须落成一个人被允许休息的动作。

### 正文种子

罗衡第一次看见轮班表全满时，心里不是高兴。

每一格都亮着，像绿洲终于有了力气。但邵青禾盯着其中一格看了很久，把“我可以补位”删掉，重新写回四个字：我休一下。

应声没有把那格调暗。

它只补了一行：休息已确认。

罗衡看着那行字，才在账本上落笔。

## CH-022: 第三炉只证明能重复

- 状态：可进入正文草稿。
- 卷内位置：第一卷第三章第二场。
- 事件锚点：`TL-022`，对应 `HISTORY-007`。
- 关联人物：`CHAR-006` 周砚屏，`CHAR-106` 应声，`CHAR-003` 罗衡，`CHAR-102` 榫七。
- 低戏份回声角色：`PIONEER-009` 韩树宁，`PIONEER-010` 蒲晓岑，`PIONEER-011` 俞澄怀，`PIONEER-012` 白若临，`PIONEER-015` 苏亦乔。
- 关联规则：`WR-008`、`WR-009`、`WR-014`、`WR-017`、`WR-018`、`SOC-016`。
- POV：周砚屏近距离视角。
- 场景地点：矿石处理厂第三炉复验区；公共状态墙；材料复验暂存台。

### 场景目的

第三炉不追求更高产量或更漂亮结果，只证明第二炉的小批量可用材料可以被重复。场景重点是“重复”如何让大家安心，而不是“成功”如何刺激大家兴奋。

### 情感核心

周砚屏发现，最让人松一口气的状态不是“突破”，而是“和上次一样可以复验”。重复不是无聊，它是共同体可以不靠运气生活的第一点证据。

### 场景节拍

1. 韩树宁把第二炉和第三炉日志放在同一张表里，只标差异，不写优劣。
2. 白若临说第三炉目标是复验，不是优化纯度。
3. 俞澄怀坚持按完整冷却窗口等完，哪怕大家已经有经验。
4. 蒲晓岑把提示从“再次成功？”改成“第三炉复验中”，避免给值守者压力。
5. 第三炉产出与第二炉相近的小批量低等级可用材料。
6. 苏亦乔把对外说明写成“重复一次”，不写“稳定量产”。
7. 周砚屏和应声把状态墙写成：可重复一次，仍需复验，下一炉不加速。
8. 罗衡把第三炉记录入账，不记哪个班次更快，只记等待和复验时间。

### 人文关怀校验

- 人没有被优化掉：第三炉值守者不被要求证明比上一班更强。
- 无收益照看动作：不写“再次成功”，保护刚建立的信心不被胜利话术压住。
- Agent 导向人际连接：应声的状态墙帮助冶炼组、罗衡和旁听者共同理解“重复”的价值。
- 术语控制：正文只前台使用“复验”“可重复一次”。

### 纯粹情义动作

苏亦乔把说明里的“稳定”删掉，只留下“重复一次”。她怕一个太大的词，让下一班老人不敢接手。

### 伏笔

- 第三炉材料将进入基础维护材料库。
- “下一炉不加速”守住后续轮班和休息格。
- 重复一次的口径为卷末自给能力成立做铺垫。

### 避免事项

- 不写成第三炉大成功。
- 不让算法模型承诺稳定量产。
- 不让值守者为了证明自己而压缩冷却窗口。

### 正文种子

第三炉的出料量和第二炉差不多。

这一次，没人失望。周砚屏甚至觉得“差不多”三个字比“更好”更让人安静。

苏亦乔把公共说明里的“稳定”删掉，只留下：重复一次。

应声在状态墙上补了一行：下一炉不加速。

## CH-023: 材料库第一排不写谁的名字

- 状态：可进入正文草稿。
- 卷内位置：第一卷第三章第三场。
- 事件锚点：`TL-023`，对应 `HISTORY-007`。

- POV：林问秋近距离视角。

### 场景目的

建立基础维护材料库，让第二炉和第三炉的小批量可用材料进入统一管理。但材料库不能变成“谁采的、谁炼的、谁贡献多”的荣誉墙。本场要把材料归入公共用途，而不是个人功劳。

### 情感核心

林问秋想给第一排材料写清来源，宁知远提醒她：来源可以记录，但前台不写人的名字。绿洲要记住事实，不把事实变成排名。

### 场景节拍

1. 魏照临给第二炉和第三炉材料批次编号。

4. 宁知远提醒前台这样会被读成班次比较。
5. 尺素把标签改成“公共材料 A-01 / A-02”，追溯信息进入后台记录。
6. 贺南溪把谁改过什么写进后台追溯记录，只留事实，不生成前台排行。
7. 冉书禾检查字号和颜色，让“待复验”不被藏起来。
8. 罗衡把材料库第一排写入账本：公共材料，不绑定个人贡献，不生成排名。

### 人文关怀校验

- 人没有被优化掉：参与过冶炼的人被事实记录，但不被拿来比较。
- 无收益照看动作：隐藏人名不提高材料性能，却保护共同体关系。
- Agent 导向人际连接：尺素和榫七把追溯与前台展示分开，贺南溪把后台事实留住，让林问秋和罗衡达成非排名口径。
- 术语控制：正文只前台使用“材料库”“待复验”。

### 纯粹情义动作

宁知远没有让大家忘记谁做过事，只是把名字从前台移到后台。他说事实要留，排名不要长出来。

### 伏笔

- 材料库将为基础维护包提供材料。
- 前台不写人名的规则会在剧场素材署名时回收。
- “待复验”提示延续低压力真实口径。

### 避免事项

- 不写个人贡献榜。
- 不把公共材料库写成财富仓库。
- 不让林问秋显得冷冰冰，她只是先按旧产品习惯想追溯清楚。

### 正文种子

林问秋原本写的是“第二炉组”。

宁知远看了一眼，没急着反对。他等她把“第三炉组”也写完，才说：“追溯要留。名字别放在第一排。”

尺素把标签重排成两行：公共材料 A-01。待复验。

罗衡看着空出来的人名栏，忽然觉得那一排材料安静了很多。

## CH-024: 第一套维护包少一个漂亮词

- 状态：可进入正文草稿。
- 卷内位置：第一卷第三章第四场。
- 事件锚点：`TL-024`，对应 `HISTORY-007`。
- 关联人物：`CHAR-004` 林问秋，`CHAR-104` 尺素，`CHAR-003` 罗衡，`CHAR-102` 榫七。
- 低戏份回声角色：`PIONEER-016` 方其远，`PIONEER-017` 盛小满，`PIONEER-021` 夏青岑，`PIONEER-022` 傅安石。

- POV：林问秋近距离视角。
- 场景地点：基础零件厂 V1；维护包装配台；公共需求板。

### 场景目的

让基础零件厂从单件打印进入“基础维护包”阶段。维护包只能包含支架、线缆夹、限位件、垫片等普通结构件，不能暗示复杂维修能力全面成熟。

### 情感核心

第一套维护包如果被命名得太漂亮，会让人以为绿洲已经能解决所有损耗。林问秋学会给它少一个漂亮词，只叫“基础维护包 A”，让下一班敢打开、敢使用、敢继续补。

### 场景节拍

1. 盛小满列出维护包的最小验收范围：能替换普通磨损，不处理核心问题。
2. 方其远发现按钮写着“生成维护包”，改成“装配维护包”，避免显得一键万能。
3. 林问秋想命名为“绿洲第一套自给包”，被尺素提醒太满。
4. 傅安石把公共说明改成“基础维护包 A：普通结构件，待复验”。
5. 夏青岑在包里放入交接卡，写清每件东西不能用在哪里。
6. 榫七确认维护包不能用于砾光右臂进一步复健，只能用于普通维护。
7. 罗衡把维护包入账，不写“自给完成”，只写“可重复装配一次”。

### 人文关怀校验

- 人没有被优化掉：下一班不用证明自己懂全部技术，只需按交接卡继续。
- 无收益照看动作：把名字改小、把不能用在哪里写清楚，保护使用者不背负过高期待。
- Agent 导向人际连接：尺素和榫七把维护包边界说清，引导林问秋、罗衡和零件组共同守住真实口径。
- 术语控制：正文只前台使用“维护包”“待复验”。

### 纯粹情义动作

夏青岑把“不能用于砾光右臂复健”写进第一张交接卡。她知道许映舟会看见，但这比含糊的希望更能让下一班安心。

### 伏笔

- 基础维护包将进入 `CH-025` 的连续普通维护。
- “装配维护包”而非“生成维护包”延续非万能边界。
- 维护包 A 未来可成为卷末维修坞稳定运行证据之一。

### 避免事项

- 不写成完整自给包。
- 不让维护包处理核心大脑、复杂执行器或高风险复健。
- 不把命名写成产品发布。

### 正文种子

林问秋写下“绿洲第一套自给包”时，自己也停了一下。

尺素没有直接删，只把“自给”两个字淡下去。

方其远在旁边把按钮从“生成维护包”改成“装配维护包”。夏青岑往盒子里放第一张交接卡，最上面一行写得很直白：不能用于砾光右臂复健。

林问秋看了一会儿，把名字改成：基础维护包 A。
