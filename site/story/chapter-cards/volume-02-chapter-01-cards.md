# 《绿洲 2076》第二卷第一章章节卡

## 范围

- 卷次：第二卷。
- 章节：第二卷第一章 / 全书第五章。
- 场次：`CH-037` 到 `CH-046`。
- 时间线：`TL-037` 到 `TL-046`。
- 阶段目标：打开“Agent 归零 -> 身份连续性裂缝 -> 修宪议题成立”的路线，不写正文，不解决完整第二卷问题。

## 章节任务句

本章要让一台低戏份对应 Agent 的归零事件发生，同时让绿洲第一次承认：身份链可以保留，但关系、手感、承诺和授权必须重新被确认。

## 禁区

- 不写 AI 反叛、复制人争议、公司阴谋、灾难大片、法庭大戏或投票撕裂。
- 不让 Agent 权利宣言压过老人主体性。
- 不写一键恢复、情感奇迹或制度爽文。
- 不把第一卷高频母题继续当章末胜利：`留灯`、`位置保留`、`休息已确认`、`下一次回应时间`、`三行提示`、`调字号`、门口灯、旧螺栓、空维修床。

## 主要复用人物

- `CHAR-003` 罗衡 / `CHAR-102` 榫七：公共承诺、维修排程、身份链和修宪入口。
- `CHAR-001` 许映舟 / `CHAR-101` 砾光：用第一卷旧臂缺口经验提醒“身份链不等于手感”。
- `CHAR-004` 林问秋 / `CHAR-104` 尺素：把争议拆成身份、承诺、能力三类。
- `CHAR-006` 周砚屏 / `CHAR-106` 应声：防止系统提示把裂缝说轻。
- `CHAR-005` 陈照野 / `CHAR-105` 留帧：处理公共记忆能证明什么、不能证明什么。
- `CHAR-002` 宋清岚 / `CHAR-103` 小穹：维持低压力讨论，不让归零 Agent 成为公开表演对象。
- `PIONEER-023` 程望川：维修窗口敏感，牵引普通维护承诺。
- `PIONEER-037` 贺南溪、`PIONEER-043` 景亭晚、`PIONEER-044` 闵存真：记录一致性、时间线差异和回放链路。

## 临时 Agent 称呼

- 程望川对应 Agent 可在章节卡中暂称“回砂”。
- “回砂”不分配 `CHAR-*`，不升格为主线 Agent，不制造 Agent 独立政治线；它是第二卷归零与修宪议题入口。

## 章节卡

### CH-037 / TL-037: 后台普通维护断拍

- 前台动作：剧场次日不是新活动，而是后台普通维护。程望川对应 Agent “回砂”未按旧节奏接上交接动作。
- 关联人物：程望川、罗衡、榫七。
- 关联物件：基础维护包、普通维护记录、未继承的料盒标签。
- 关系推进：共同体第一次发现，第一卷的普通维护承诺并不能自动覆盖所有新裂缝。
- 禁重复：不用“明天也留灯”收束。

### CH-038 / TL-038: 身份链保留，现场习惯归零

- 前台动作：维修坞确认“回砂”的唯一身份链仍在，但本地现场记忆、模块挂载和资产标记归零。
- 关联人物：罗衡、榫七、许映舟、砾光。
- 关联物件：身份链封条、旧模块接口盖。
- 关系推进：大家第一次把“身份还在”和“关系出现裂缝”放在同一张桌上。
- 禁重复：不用“三行提示”宣布结论。

### CH-039 / TL-039: 对应老人先问一个小习惯

- 前台动作：程望川没有索赔、控诉或要求恢复，只问“它还记不记得上次搬错的那个料盒”。
- 关联人物：程望川、贺南溪。
- 关联物件：未继承的料盒标签、后台追溯记录。
- 关系推进：归零的痛点落到一个小习惯，而不是宏大身份辩论。
- 禁重复：不用“位置保留”解决痛点。

### CH-040 / TL-040: 公共记忆只能证明曾经在场

- 前台动作：陈照野 / 留帧从门侧记忆墙找出“回砂”的短镜头，但镜头只能证明它曾经在场，不能证明它现在仍拥有完整关系。
- 关联人物：陈照野、留帧、闵存真。
- 关联物件：短记忆、“不能证明”标记。
- 关系推进：公共记忆从情感安慰转成边界证据。
- 禁重复：不要把记忆墙变成情感胜利。

### CH-041 / TL-041: 身份、承诺、能力

- 前台动作：林问秋 / 尺素把争议拆成三类：身份、承诺、能力；她差点把关系写成流程验收，被宋清岚拦下。
- 关联人物：林问秋、尺素、宋清岚。
- 关联物件：空白握手记录草稿。
- 关系推进：共同体承认问题需要被拆开，但不能被流程替代。
- 禁重复：不要再用“删到三件事”。

### CH-042 / TL-042: “恢复中”改成“需要重新校准”

- 前台动作：周砚屏 / 应声发现“恢复中”会让老人误以为关系能自动复原，于是把反馈改成“需要重新校准”。
- 关联人物：周砚屏、应声、景亭晚。
- 关联物件：需要重新授权的普通工具。
- 关系推进：真实裂缝被说清，但不刺伤人。
- 禁重复：不要靠调字号体现善意。

### CH-043 / TL-043: 未完成承诺是否继承

- 前台动作：罗衡查公共账本，发现“回砂”曾承担一个未完成的普通维护承诺；共同体第一次面对“承诺是否随身份链继承”。
- 关联人物：罗衡、榫七、程望川。
- 关联物件：公共账本、身份链封条。
- 关系推进：修宪议题从抽象身份进入具体承诺。
- 禁重复：不要用下一次回应时间作为主要安慰。

### CH-044 / TL-044: 砾光提醒身份链不等于手感

- 前台动作：许映舟带砾光参与低风险再校准，砾光因第一卷旧臂缺口经验提醒大家：保留身份链不等于保留手感。
- 关联人物：许映舟、砾光、罗衡。
- 关联物件：空白握手记录、第一次重新协作失败后保留下来的误差样本。
- 关系推进：第一卷经验成为温和对照，但砾光不当权威裁判。
- 禁重复：不把砾光写成答案来源。

### CH-045 / TL-045: 不投票定生死的小会

- 前台动作：宋清岚组织一次非表演性小会；不投票定生死，只让相关老人、Agent 和记录组说出哪些事不能被自动抹掉。
- 关联人物：宋清岚、小穹、贺南溪、闵存真。
- 关联物件：修宪草案第一条的手写边注。
- 关系推进：共同体开始把裂缝转成可讨论但不表演的公共问题。
- 禁重复：不用剧场灯光做结尾。

### CH-046 / TL-046: 第一条小修宪

- 前台动作：第一份修宪草案只写一个小条款：归零后，公共承诺材料保留追溯入口；能力、资产和私人习惯必须另行校准、授权和关系确认。
- 关联人物：罗衡、林问秋、周砚屏、宋清岚。
- 关联物件：修宪草案第一条、身份链封条、空白握手记录。
- 关系推进：第二卷议题成立，但没有被解决。
- 禁重复：不要写成胜利。
