# 《绿洲 2076》第二卷第五章章节卡

## 范围

- 卷次：第二卷。
- 章节：第二卷第五章 / 全书第九章。
- 场次：`CH-071` 到 `CH-078`。
- 时间线：`TL-071` 到 `TL-078`。
- 章节标题：铅笔条款试运行。
- 阶段目标：第一条仍不正式通过，只进入一次窄范围试运行；每一次确认都允许暂停和撤回。

## 章节任务句

本章要让共同体学会用未完成的规则生活：公共承诺材料保留追溯入口；工具、资产、能力、私人习惯分层重授权；卷尾只给一个有限的重新协作入口，不写成制度胜利。

## 禁区

- 不写修宪完成、共识达成、第一条通过、正式生效或公告庆祝。
- 不把“材料可追溯”写成“关系已确认”。
- 不把试运行扩展到所有 Agent 或外层记录。
- 不用第一卷灯、位置、短提示或剧场试运营式收束。

## 边界状态字段

- 身份链：材料追溯入口。
- 承诺材料：试运行中可保留、可暂停、可撤回。
- 能力：当前能力逐项校准。
- 资产 / 工具：分层授权，默认暂锁。
- 私人习惯：关系确认留给当事人，不写入默认条款。

## 章节卡

### CH-071 / TL-071: 铅笔条款草案正文

- 前台动作：第一条从手写边注移动到草案正文，但仍用铅笔标注“试运行”。
- 关联人物：林问秋、尺素、罗衡。
- 关联物件：未盖章草案、铅笔边注。
- 边界状态：没有编号、盖章或正式公告；条款只是试运行文本。
- 关系推进：共同体允许规则以不确定状态存在。
- 禁重复：不写“第一条通过”。

### CH-072 / TL-072: 分层确认清单

- 前台动作：林问秋和尺素把条款拆成材料追溯、工具授权、资产保管、能力校准、私人习惯五层。
- 关联人物：林问秋、尺素、周砚屏。
- 关联物件：分层确认清单、未同步外层记录。
- 边界状态：每层都允许暂停和撤回；私人习惯不进入默认确认。
- 关系推进：规则开始保护差异，而不是压平成流程。
- 禁重复：不把清单写成验收表。

### CH-073 / TL-073: 试运行只开一个窗口

- 前台动作：罗衡只开放一个低风险试运行窗口，不同步到所有 Agent 或外层记录。
- 关联人物：罗衡、榫七、程望川。
- 关联物件：试运行窗口、暂锁工具柜。
- 边界状态：低规格、窄范围、可撤回；资产和旧承诺不自动打开。
- 关系推进：共同体不把个案处理升级成制度大胜。
- 禁重复：不写全站公告。

### CH-074 / TL-074: 未盖章页角

- 前台动作：周砚屏和应声把提示写成“试运行中 / 可暂停 / 可撤回”。
- 关联人物：周砚屏、应声、景亭晚。
- 关联物件：未盖章页角、试运行提示。
- 边界状态：禁用“恢复”“通过”“完成”；提示只说明边界。
- 关系推进：系统第一次用不完成的话保护人。
- 禁重复：不靠调字号体现善意。

### CH-075 / TL-075: 一次有限托付

- 前台动作：程望川允许回砂递交一枚新的排气阀复查夹，但不恢复旧资产包，也不接收旧承诺。
- 关联人物：程望川、回砂、榫七。
- 关联物件：排气阀复查夹、单次授权条。
- 边界状态：局部托付成立；资产、旧承诺和私人习惯仍分层处理。
- 关系推进：关系没有复原成原样，但出现一个小的重新开始。
- 禁重复：不写原谅或接纳宣言。

### CH-076 / TL-076: 误认被及时撤回

- 前台动作：记录组一度把“材料可追溯”写成“关系已确认”，被景亭晚撤回。
- 关联人物：景亭晚、贺南溪、闵存真、罗衡。
- 关联物件：撤回记录、错误痕迹、分层确认清单。
- 边界状态：错误保留为试运行警示；材料追溯不等于关系确认。
- 关系推进：共同体学会承认自己也会误认。
- 禁重复：不把撤回写成责备。

### CH-077 / TL-077: 小规则没有胜利词

- 前台动作：宋清岚收束试运行复盘，不安排投票、庆祝或公告，只让相关人确认下一次仍可暂停。
- 关联人物：宋清岚、小穹、罗衡、程望川。
- 关联物件：复盘页、未盖章草案。
- 边界状态：条款仍试运行；下一次可以暂停；共同体没有胜利词。
- 关系推进：低压力不是让人快乐表态，而是允许不完成。
- 禁重复：不写剧场式收束。

### CH-078 / TL-078: 从一个小动作重新开始

- 前台动作：回砂和程望川完成一次极小的重新协作入口；关系没有复原成原样，修宪也没有完成。
- 关联人物：程望川、回砂、罗衡、宋清岚、周砚屏。
- 关联物件：排气阀复查夹、未盖章草案、铅笔边注。
- 边界状态：有限托付成立；条款仍未通过；资产、旧承诺和私人习惯仍允许分层暂停。
- 关系推进：共同体学会不说谎、不催促、不误认。
- 禁重复：不要写成第二卷完整胜利。
