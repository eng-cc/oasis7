# 《绿洲 2076》长篇总纲 v0.3

## 一句话主线

五十年后，生活在地球的老人们用养老金在小行星带建设绿洲，通过低延迟量子通信接入有机器身体的 Agent，一起采矿、建厂、维修、娱乐和交朋友，把晚年资金变成继续创造美好生活的底层燃料。

## 主题答案

《绿洲 2076》最想表达的是：老人不只是被照护、被安排、慢慢退场的人。只要社会不再用利益冲突、效率排名和生存焦虑定义他们，他们仍然可以快乐地生产、游戏、建设、陪伴和创造未来。它也给年轻读者一个未来自我想象：五十年后，我仍然可以被世界需要，仍然可以拥有关系、身体感和创造力。

“纯粹关系”在本故事中指不以利益交换、贡献排名或照护资格为前提的关系。老人、Agent 和设施一起承担真实物理限制，但这些限制不被写成谁赢谁输，而被写成共同规划、慢慢等待、彼此照看的生活节奏。

## 已确认背景

- 老人本人生活在地球。
- 绿洲位于小行星带，由 Agent 机器身体、采矿设施、能源系统、工厂、维修坞、娱乐设施和链上共识记录组成。
- 老人通过低延迟量子通信接入绿洲 Agent。量子通信本身不消耗绿洲币。
- Agent 有机器身体，有弱独立人格，像伙伴、电子宠物和半自主分身；它们听老人指挥，也能根据现场情况提出建议。
- Agent 大脑运转、高级推理、长时间代理、模块部署、维护排程和公共设施运行会消耗绿洲币 / Oasis Coin（OC）。
- 绿洲币不是财富排名，也不决定老人是否配得照护；它是智能运行、模块部署和公共建设预算的结算层。
- Agent 是关系媒介，不是真人关系替代品；它帮助老人进入人与人、人与社区、人与设施的长期关系。
- Agent 初始本体是无差别标准机器人，带模块化接口和默认生存模块包；矿场、维修、公共设施、影像和排程能力来自后续挂载或接入的外部生产力模块组合，不存在专门做剧场的 Agent。

## 第一卷定位

第一卷写绿洲从“养老金启动项目”走向“初步自给自足”。核心危机不是资源竞技，而是启动期必须尽快完成基础工业闭环；如果做不到，初始绿洲币预算、地球补给窗口和 Agent 维护排程都会压缩建设余裕，第一座娱乐设施也会被迫延期。失败不会影响老人照护资格，也不会让任何人失去尊严；真正的代价是维修延期、Agent 降级运行、公共活动推迟，以及大家必须重新协商等待。

第一卷目标：

1. 建成矿石处理厂，能把采来的矿石冶炼成可用金属。
2. 建成基础零件厂，能用金属材料 3D 打印基础零件。
3. 建成 Agent 维修坞，让绿洲可以自产基础维护材料，完成常规维修。
4. 在结尾试运营第一座低重力星光剧场 / 活动厅，作为情感胜利。

第一卷 V1 能力边界：

- 开局已有基础能源塔、量子通信接入、编译坞 / 装配坞、有限仓储、少量备件、默认 Agent 生存模块包和生产力模块池；缺口是稳定金属自给、基础零件自产、Agent 常规维修闭环和可安全反复使用的公共活动空间。
- 矿石处理厂 V1 只做到采样、分选、预处理、冶炼、除渣 / 排气、铸锭或粉末化等基础流程。
- 基础零件厂 V1 只能打印基础结构件、支架、外壳、低负载连接件和部分机械臂段替换件，不能打印芯片、高性能电池、精密传感器、复杂执行器或 Agent 核心大脑。
- Agent 维修坞 V1 能做诊断、模块替换、标定和基础机械修复，不能重造身份链，也不能让归零风险消失。
- 剧场 / 活动厅 V1 是最低试运营公共客厅：可安全进入、可旁听、可安静退出、可播放公共记忆、可举办小型活动，不是完整成熟剧院。

## 第一卷建设路线

1. 接入与晨会：老人从地球的家庭接入舱或社区接入厅上线，先参加绿洲晨会，再进入采矿、冶炼、维修或剧场筹备班次。
2. 第一阶段：完成矿石采集和矿石处理厂启动，让绿洲第一次能稳定冶炼可用金属。
3. 中段事故：第一炉矿石因挥发杂质导致冶炼失败，并损伤许映舟对应 Agent 砾光的操作臂。社区被迫用尚未完全稳定的基础零件厂打印第一批维修件。
4. 第二阶段：基础零件厂稳定运行，Agent 维修坞完成第一次常规维修，绿洲开始具备基础维护材料自给能力。
5. 结尾：低重力星光剧场 / 活动厅完成最低试运营，只读一条短账本、播放一段短记忆，再让大家一起坐一会儿，成为第一卷的情感胜利。

建设线按群像协作处理。第一批先锋队是 50 位地球端老人，每位老人对应一台绿洲端通用 Agent；采矿、矿石处理厂、基础零件厂和维修坞都由他们中的多位老人、多台 Agent 和多组生产力模块共同推进。六位主线老人和六台对应主线 Agent 只承担叙事焦点、关键取舍和情感锚点；其余 44 位老人及其对应低戏份 Agent 可以真实负责测绘、搬运、值守、仓储、校准、质检、排班、安全复核、对外说明和活动支持，不需要每个人都有完整人物弧线。老人背景可以覆盖互联网前端、后端、运维、算法、运营、产品和市场，且允许多人背景重复；这些背景不决定绿洲分工，只用于提供思维习惯、说话方式、协作偏好、风险敏感点和处理失败的不同反应，不用于制造职业排名。

章节写法上，每个工业进展都要落回某段关系、承诺或公共生活：它让谁能继续等，哪台 Agent 能被修回，哪场活动没有被取消，哪位只旁听的老人仍被算作在场。每场戏最多让 1-2 个技术概念进入前台，其余技术通过等待、反馈、排程和人与人的回应来表现。

### 人文关怀与纯粹情义校验

第一卷章节卡必须把“人文关怀”和“纯粹情义”落成可见动作，而不是只写价值判断。

- 每章至少出现一个“人没有被优化掉”的动作：允许退出、保留旁听席、解释等待理由、给出下一次回应时间、把不能上手的人仍算作在场。
- 每个工业节点后必须有一个无收益、无绩效、无互利回报的照看动作，例如等人讲完、替人留位置、记住一个偏好、陪一段沉默、把失败痕迹留下来。
- 每 1-2 个 Agent 场景后，应导向一次人与人的连接：公共排程、安静连线、共同等待、承诺记录、活动入口或下一次重逢。
- OC 账本只记录等待对象、等待理由、下次回应时间、旁听 / 陪伴入口和公共承诺，不记录个人贡献、人情债或谁牺牲更多。
- 术语密度要低。同一场戏里尽量只让一个技术 / 项目词进入前台，避免连续堆叠 `需求`、`版本`、`验收`、`排程`、`V1`、`OC`。

第一卷友情阶段对照：

| 阶段 | 工业线事件 | 情义动作 |
| --- | --- | --- |
| 晨会 | 首次接入与分组 | 记名字，给只听不说的人留旁听席。 |
| 采矿 | 第一次共同作业 | 记住对方的慢半拍、习惯和不愿添乱的说法。 |
| 事故 | 第一炉失败与砾光受损 | 先确认人和 Agent 是否被接住，再追日志和责任。 |
| 维修等待 | 打印维修件与排程 | 不能上手的人也陪在场，贴交接标签，讲一个不催人的玩笑。 |
| 剧场开放 | 公共客厅第一次亮灯 | 约定下次再见，把失败痕迹放进可反复看见的位置。 |

## 第一卷情感胜利

第一卷结尾不以“产量第一”或“战胜对手”为胜利，而以一次共同生活的开始为胜利：老人们通过 Agent 进入第一次真正最低试运营的低重力星光剧场 / 活动厅。首场只保留三件事：读一条短账本、播放一段短记忆、一起坐一会儿。它不是一次性庆典或项目发布会，而是之后反复重逢的公共客厅；它证明绿洲不只是工厂，也是老人和 Agent 可以慢慢生活、彼此陪伴、共同保存记忆的地方。

## 第一卷叙事禁区

- 不写成 AI 反叛。
- 不写成公司阴谋。
- 不写成老人苦难文学。
- 不写成资源竞技或贫富排名。
- 不写成赛博黑暗风。

危机可以来自建设难度、维护排程、预算消耗、设施故障、等待、误解、不同生活节奏，以及对 Agent 身份的不同理解。
