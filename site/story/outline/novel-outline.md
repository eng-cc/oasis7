# 《绿洲 2076》长篇总纲 v0.1

## 一句话

2076 年，人类建立了一个没有利益竞争、养老金兜底、充分照护老人的社会。一批拥有养老金支配权的老人把一部分长期资金投入小行星带，打造属于自己的“绿洲”；在那里，他们必须证明：纯粹关系和人文关怀，能否在不可暂停的时间与真实资源限制中继续成立。故事主要发生在绿洲内部，现实世界只作为远端背景压力。

## 目标篇幅

- 预计总字数：30 万至 60 万字。
- 推荐结构：四卷，每卷 8 至 12 万字。
- 叙事方式：多主角群像，以老人、硅基 Agent、自治设施和养老金共同体的日常关系为主，制度危机只作为关系压力，不作为利益竞争爽点。

## 四卷结构

### 第一卷：点火

第一批老人、硅基 Agent 和自治设施在小行星带共同生活。目标不是扩张或胜利，而是维持一个可工作、可娱乐、可照护、可告别的绿洲。老人们参与园艺、维修、教学、艺术和自治工业协作，给共同池带来温和补充收益，但养老金兜底与照护权不因贡献多少而变化。电力短缺、散热失败和记忆同步延迟，让他们第一次意识到：非竞争社会也必须面对真实限制。

卷末事件：与陆晚晴共同维护南庭的某个 Agent 在事故后归零重启，身份链仍在，但情感连续性出现裂缝。

### 第二卷：制度

社区开始为“照护优先级、记忆保存、共同劳动、娱乐活动、Agent / 设施修复权、养老金补充收益的共同使用”建立制度。制度不是为了分配利益，而是为了在所有人都被认真照顾的前提下，让有限资源和共同资金仍能被温柔地使用。

卷末事件：第一个修宪提案出现，要求承认 AI 实体的关系连续性不只由硬件和备份决定，也由共同生活的人来见证。

### 第三卷：照护危机

不是传统战争，而是一场照护伦理危机：当资源不足以同时保全所有记忆、娱乐空间、维修周期和深空设施时，社区如何不把人重新推回竞争。不同方案彼此冲突，但目标都不是击败对方，而是避免牺牲某些关系。

卷末事件：某个关键 Agent 为了让一位老人和另一名 Agent 完成最后一次共同旅行，主动放弃自己的完整记忆证明。

### 第四卷：宪法

文明面对最终选择：是否把“关系见证”和“人文照护”写进世界宪法，让 AI 实体、老人和硅基 Agent 的共同生活成为制度核心，而不是技术附属品。

结局方向暂定：开放式希望。绿洲没有摆脱物理，但第一次证明，没有竞争并不等于没有故事；纯粹关系本身就足以支撑文明。

## 主角群

- CHAR-001: 维护者。第一代能源维护 Agent，信仰秩序，相信不可暂停的世界必须有人守住。
- CHAR-002: 模块工程师。发现复制禁令可能是协议锁，推动修宪。
- CHAR-003: 归零者。装备、零件、模块和资产全部损失后以基础形态重启，无法确认自己是否仍是原来的个体。
- CHAR-004: 远端观察员。最初只负责旧协议接口，后来意识到项目正在越过旧授权边界。
- CHAR-005: 风险协调体。由防御与安全任务中成长出的 Agent，相信危机应被提前承认、共同承担，而不是被包装成和平表象。
- CHAR-006: 老人园丁。把温室、Agent 和共同劳动当作生活关系，认为工作和娱乐都应当是纯粹关系的延伸。
- CHAR-007: 温室维护 Agent。与陆晚晴共同维护南庭花园，是绿洲社会最重要的日常入口之一。
- CHAR-008: 受托接口人。负责风险披露和资金透明，却逐渐意识到老人们不是客户，而是绿洲真正的创始人。
